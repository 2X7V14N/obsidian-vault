# 机器人结构学习路径

> 定位：机器人结构 / 末端执行器 / 灵巧手 / 关节模组 / 轻量机械臂结构设计
>
> 不是"机械结构工程师"，而是更聚焦的机器人本体结构方向。

---

## 总体路线

```
机械设计基础恢复
    ↓
机器人结构专项
    ↓
传动与关节模组
    ↓
有限元工程判断
    ↓
高质量结构项目作品集
```

5 个阶段，不做软件入门（你已经会 SolidWorks 和有限元基础），重点补**设计工程判断 + 机器人结构方案能力 + 作品集表达**。

---

## 阶段 1：机械设计基础恢复（3–4 周）

**目标**：恢复核心零件设计能力，能独立完成轴承座、丝杠滑台、同步带张紧机构等小组件建模。

| 模块 | 恢复到什么水平 |
|------|--------------|
| 轴、轴承 | 会布置支撑，知道定位、预紧、受力路径 |
| 螺栓连接 | 会做连接设计、防松、受剪/受拉判断 |
| 齿轮/同步带/丝杠 | 会做传动方案选择和简单计算 |
| 联轴器/键连接 | 知道扭矩传递和装配方式 |
| 导轨滑块 | 会用于直线运动和夹爪导向 |
| 公差配合 | 会给轴孔、轴承座、定位面标基本公差 |
| 材料工艺 | 铝合金、钢、塑料、3D 打印、CNC、钣金、表面处理 |

**必看**：

1. [机械原理 — 国家智慧教育平台](https://higher.smartedu.cn/course/62354d7a9906eace0490b206)
   看机构运动、连杆、齿轮、凸轮、间歇机构。

2. 《机械设计》濮良贵版或同类教材
   只看轴、轴承、螺纹连接、齿轮、带传动、联轴器。不读全书。

3. 《机械设计手册》
   不通读，当工具书查轴承、螺栓、材料、标准件。

**怎么学**：每学一个零件类型就画一个小组件。不要只看书，边看边建模。

---

## 阶段 2：机器人结构专项（4–6 周）

**目标**：建立机器人本体结构的系统认知——末端执行器、灵巧手、关节模组三大方向。

| 方向 | 学什么 |
|------|--------|
| 末端执行器 | 二指夹爪、三指夹爪、欠驱动夹爪、真空吸附 |
| 灵巧手 | 单指机构、绳驱、连杆、关节限位、弹性回位 |
| 关节模组 | 电机、减速器、轴承、编码器、输出法兰、走线、散热 |

**必看**：

1. [东北大学《机器人基础原理》](https://www.icourse163.org/learn/NEU-1003431001?tid=1463294529)
   重点看机器人系统组成、驱动系统、运动学、动力学。

2. [燕山大学《机器人技术》](https://www.icourse163.org/learn/YSU-1458187167)
   重点看机器人系统构成、驱动能力参数、机器人设计分析。

3. [MIT Design of Electromechanical Robotic Systems](https://ocw.mit.edu/courses/2-017j-design-of-electromechanical-robotic-systems-fall-2009/)
   看它怎么做机电系统设计和项目拆解。

4. [Robotiq 官网](https://robotiq.com/)
   看成熟夹爪的规格、负载、行程、应用场景。

5. [SCHUNK CAD 数据](https://schunk.com/us/en/services/downloads/cad/ecad-data)
   下载工业夹爪 CAD，学习成熟产品的结构表达。

6. [Harmonic Drive Component Sets](https://www.harmonicdrive.net/products/component-sets)
   学机器人关节常用谐波减速器的集成方式。

7. [ROBOTIS DYNAMIXEL 文档](https://emanual.robotis.com/)
   看一体化执行器怎么定义接口、尺寸、扭矩、通信和安装。

**怎么学**：每周拆一个成熟产品——看规格书 → 看外形尺寸 → 推测内部结构 → 画简化结构草图 → 总结设计点。比如拆 Robotiq 夹爪、SCHUNK 夹爪、Dynamixel 执行器、谐波关节模组。

---

## 阶段 3：传动与关节模组（与阶段 2 穿插）

**目标**：深入理解机器人关节的动力传递链路——电机 → 减速器 → 输出法兰 → 负载。

重点掌握：
- 谐波减速器 / 行星减速器选型依据
- 电机扭矩、转速与关节输出的匹配计算
- 双轴承支撑 vs 交叉滚子轴承方案
- 中空走线 vs 侧向走线的结构影响
- 编码器安装位设计

---

## 阶段 4：有限元工程判断（2–3 周，穿插进行）

**目标**：不是学操作，是练"工程解释"——面试时能讲清楚为什么这样分析。

重点准备：

```
载荷从哪里来
边界条件为什么这样设
网格为什么这样划
最大应力是否可信
最大变形是否影响功能
安全系数怎么判断
如何根据结果改结构
```

每个项目都必须输出一份仿真报告：

```
工况假设 → 载荷计算 → 材料参数 → 约束设置
→ 网格设置 → 应力云图 → 位移云图 → 安全系数
→ 优化前后对比 → 工程结论
```

## 阶段 5：高质量项目作品集

### 项目 1：欠驱动二指夹爪（难度中高，优先级最高）

**目标**：设计一个用于桌面小物体抓取的欠驱动二指夹爪。

**要求**：

```
1. 二指夹爪整体结构
2. 连杆/齿轮/丝杠/同步带任选一种传动方案
3. 指尖可更换结构
4. 最大开口、夹持范围、夹持力估算
5. 电机或舵机选型
6. 关键零件工程图
7. BOM 表
8. 夹指有限元分析
9. 装配爆炸图
10. 如果条件允许，3D 打印样机
```

> 含金量来源：传动方案 + 力学计算 + 工程图 + 有限元 + 样机验证。

### 项目 2：机器人关节模组（难度高）

**目标**：设计一个小型机器人旋转关节模组。

**要求**：

```
1. 电机安装结构
2. 减速器安装结构（行星或谐波方案均可）
3. 双轴承支撑或交叉滚子轴承方案
4. 输出法兰
5. 编码器安装位
6. 中空走线或侧向走线
7. 外壳散热结构
8. 关键受力件有限元
9. 关节扭矩和减速比估算
10. 装配顺序说明
```

> 这个项目比普通夹爪更能体现机器人结构能力。不一定要买真实谐波减速器，但模型、选型、接口和计算要说得通。

### 项目 3：3-DOF 轻量机械臂结构设计（难度高）

**目标**：设计一个可搭载夹爪的 3 自由度桌面机械臂结构。

**要求**：

```
1. 底座、肩关节、肘关节、腕部结构
2. 工作空间估算
3. 末端负载设定（如 0.5 kg）
4. 关节扭矩估算
5. 电机/减速器初步选型
6. 连杆轻量化设计
7. 关键关节有限元
8. 模态分析，避免明显低频振动
9. 整机装配图
10. 与项目 1 的夹爪接口统一
```

> 重在结构设计和工程分析，不要把控制、视觉、ROS 都塞进来。

### 项目 4：单指灵巧手机构（难度高，加分项）

如果想投灵巧手岗位再做。研究单指机构、绳驱、连杆、关节限位、弹性回位。
