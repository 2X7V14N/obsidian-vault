## Transformer 架构详解

### 1. 问题引入与核心思想
- **示例句子**：“用毒毒毒蛇，毒蛇会不会被毒毒死”
  - 这句话包含六个“毒”字，但不同位置的“毒”字词性不同（如第一个“毒”是名词，第二个是动词），含义复杂。
- **核心挑战**：计算机需要理解句子中每个字在特定位置的含义，这不能仅通过单个字判断，必须从整体关联性入手。
- **核心思想**：句子中的每个字都与其他字相互关联、互为整体。Transformer 的目标就是找出并利用这种关联。

### 2. 输入预处理与编码
- **分词（Tokenization）**：
  - 使用分词工具（如 **BPE**）将输入句子拆分为最小的语义单位 **token**。
  - 示例分词结果：`[用, 毒, 毒, 毒蛇, 毒蛇, 会不会, 被, 毒, 毒, 死]`。
- **词向量编码**：
  - 每个 token 被编码为一个 **512维** 的词向量。
- **位置编码（Positional Encoding）**：
  - 由于模型同时接收所有 token，无法感知顺序，因此需要为每个词向量添加一个位置编码，以注入序列顺序信息。
- **初始输入矩阵**：
  - 经过上述处理，得到一个形状为 `[序列长度, 512]` 的向量组，记为 `X`。

### 3. 核心机制：自注意力（Self-Attention）
**目标**：让句子中的每个 token 相互计算，以找出彼此间的关联。
- **计算 Q, K, V 向量**：
  - 为每个 token 的词向量，分别乘上三个权重矩阵 `W_Q`, `W_K`, `W_V`，得到 **查询向量（Query, Q）**、**键向量（Key, K）** 和 **值向量（Value, V）**。
  - **Q（查询）**：代表当前词“想要关注什么”。
  - **K（键）**：代表该词“能为其他词提供什么信息”（可视为标签或索引）。
  - **V（值）**：代表该词“实际包含的信息内容”，是真正被检索和聚合的信息本身。
- **注意力分数计算**：
  - 用每个 token 的 Q 向量，与句子中所有 token（包括自身）的 K 向量做 **点积（Dot Product）** 相似度计算。
  - 为防止梯度爆炸，将计算结果除以一个常数 $\sqrt{d_K}$（其中 $d_K$ 为 K 向量的维度）。
  - 公式：`Attention Scores = (Q * K^T) / sqrt(d_K)`
- **注意力权重**：
  - 对上述分数应用 **softmax** 函数，将其归一化到 0~1 之间，得到 **注意力权重**。
  - 这组权重表示当前词与其他每个词的关联程度。
- **输出向量 Z**：
  - 将每个 token 的 V 向量与其对应的注意力权重进行加权求和，得到一组新的向量，记为 `Z`。
  - `Z` 中的每个向量都包含了该 token 对句子中其他 token 语义的理解。
- **比喻**：想象一个 token 带着疑问（Q）进入图书馆，根据书籍索引（K）匹配度决定阅读哪些书的内文（V），最终带走整合后的知识。

### 4. 多头自注意力（Multi-Head Self-Attention）
- **局限性**：单头自注意力只能让一个词产生一种关注和理解，但实际语义是多方面的（如动宾关系、指代关系等）。
- **机制**：
  - 将初始输入向量 `X` 的 512 维拆分为 **8 个头**，每个头处理一个 64 维的子向量。
  - 每个头独立进行自注意力计算。
  - 最后将 8 个头的计算结果进行拼接，重新合并为一个 `[序列长度, 512]` 维的向量。
- **优势**：允许模型从多个不同的表示子空间（不同的“头”）捕捉信息，从而整合复杂的语义关系。
- **地位**：多头自注意力机制是 Transformer 架构中最核心的模块。

### 5. 编码器（Encoder）结构
多层堆叠结构，用于深入理解输入语言。每层包含以下组件：
1.  **多头自注意力层**
2.  **残差连接（Residual Connection）与层归一化（Layer Normalization）**
    - 解决深层网络中的 **梯度消失** 问题。残差连接通过将层的输出改为 $F(X) + X$，提供一条直通的梯度通路。
    - 层归一化将向量中的数值保持在稳定范围内（如 0~1），防止数值波动过大。
3.  **前馈神经网络（Feed-Forward Network, FFN）**
    - 对每个位置的向量应用相同的两层全连接网络，中间使用 **ReLU** 等激活函数。
    - 目的：引入非线性，使模型能够拟合任意复杂的函数。
4.  **残差连接与层归一化**
- **输出**：经过 N 层这样的结构后，得到编码器的输出向量 `X_out`。

### 6. 解码器（Decoder）结构
负责根据编码器的理解，逐步生成输出序列（如翻译结果）。其工作原理可概括为“**瞻前顾后**”。
- **输入**：
  1.  **编码器输出 `X_out`**（用于“瞻前”）。
  2.  **已生成的 token 序列**（用于“顾后”，逐词生成，每生成一个新词都作为输入）。
- **核心组件**（从下到上）：
  1.  **掩码多头自注意力层（Masked Multi-Head Self-Attention）**：
      - 与编码器的自注意力计算方式类似，但增加了 **掩码（Mask）**。
      - **目的**：在训练时，确保模型只能根据已生成的 token 预测下一个词，而“看不到”未来的 token（即答案序列中尚未生成的部分）。
      - **实现方式**：在计算注意力分数时，对于未来位置（索引 `j > i`），将其分数设置为一个极大的负数（如 `-1e9`），使其 softmax 后的权重趋近于零。
  2.  **残差连接与层归一化**
  3.  **交叉注意力层（Cross-Attention）**：
      - 与自注意力类似，但 **Q 来自解码器上一层的输出**，而 **K 和 V 则来自编码器的输出 `X_out`**。
      - **目的**：将编码器理解到的源语言语义信息与解码器已生成的目标语言信息进行融合，实现输入与输出的对齐。
  4.  **前馈神经网络（FFN）**
  5.  **残差连接与层归一化**
- **输出**：经过 N 层结构后，得到解码器的输出向量 `Y_out`。

### 7. 输出层（Linear & Softmax）
- **线性变换**：
  - 将解码器输出向量 `Y_out`（维度为 512）乘以一个权重矩阵 `W`（形状为 `[512, vocab_size]`），并加上偏置向量 `B`（形状为 `[vocab_size]`），得到向量 `logits`。
  - `logits` 的每个值代表词表中对应单词的得分。
- **概率分布**：
  - 对 `logits` 应用 **softmax** 函数，将其转化为概率分布 `prob`。
- **预测输出**：
  - 使用 `argmax` 从 `prob` 中找出概率最大的 token 作为当前步的预测输出。
- **循环生成**：重复上述过程，直到模型输出 **结束符（EOS）** 或达到最大长度。

### 8. 架构变体与意义
- **原始 Transformer**：包含 **编码器** 和 **解码器**，专注于序列到序列的任务（如机器翻译）。
- **现代大语言模型（如 GPT）**：通常 **仅包含解码器**，专注于文本生成任务。
- **历史意义**：Transformer 的出现让自然语言处理乃至整个人工智能领域迈上了新台阶。它搭建了一座从语言到智能的桥梁，是 AI 发展史上浓墨重彩的一笔。
