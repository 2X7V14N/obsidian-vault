# 机器人感知学习路径（抓取/操作感知）

> 按顺序做，每步分三块：**学什么 / 看什么 / 做什么**。

---

## 第 1 步：OpenCV 传统视觉 ✅ 已完成

- **学**：HSV、Mask、形态学、轮廓、minAreaRect
- **看**：
  - [OpenCV Bootcamp 官方免费课](https://opencv.org/university/free-opencv-course/)（图像读取、颜色空间、阈值、形态学、轮廓）
  - [OpenCV 官方教程](https://docs.opencv.org/4.x/d9/df8/tutorial_root.html)（查 contourArea / minAreaRect / findContours）
- **做**：OpenCV 抓取位姿估计 V1（稳定处理 20–50 张图）

---

## 第 2 步：相机标定与 Homography

- **学**：相机模型、内外参、把 (u,v) 转成真实坐标 (X,Y)
- **看**：
  - [First Principles of Computer Vision — Shree Nayar](https://www.youtube.com/@FirstPrinciplesofComputerVision)（Camera Model / Camera Calibration / Homography / Perspective Projection）
  - [OpenCV 相机标定官方教程](https://docs.opencv.org/4.x/dc/dbb/tutorial_py_calibration.html)（配视频做棋盘格标定）
  - [OpenCV 透视变换 / Homography 官方教程](https://docs.opencv.org/4.x/da/d6e/tutorial_py_geometric_transformations.html)（getPerspectiveTransform / warpPerspective）
- **做**：相机标定 + 桌面坐标映射，产出 Pixel(u,v) → World(X mm, Y mm)

---

## 第 3 步：深度学习基础 + 目标检测

> 从原计划第 6 步提前到这里——DL 是感知核心，要早学。

- **学**：MLP、CNN、PyTorch 训练流程（Tensor / Autograd / Dataset / 训练循环）
- **看**：
  - [李沐《动手学深度学习》](https://courses.d2l.ai/zh-v2/)（线性网络 → MLP → CNN → 现代 CNN）
  - [PyTorch 官方入门教程](https://docs.pytorch.org/tutorials/beginner/introyt/introyt_index.html)（Tensor / Autograd / Dataset / Training Loop）
  - [Ultralytics YOLO 文档](https://docs.ultralytics.com/)
- **做**：YOLO 桌面物体检测 + 第 2 步坐标映射，产出 物体类别 → 像素框 → 桌面真实坐标

---

## 第 3.5 步：轻量 ROS2（浅尝，不深挖）

> 目的：早点接触 ROS，把第 3 步的检测跑成一个节点。**只做到能跑就收手**，tf2 和复杂 launch 留到第 7 步。

- **学**：workspace、package、node、topic、publisher / subscriber（就这些，别扩展）
- **看**：
  - [Articulated Robotics — ROS2 Tutorials](https://www.youtube.com/playlist?list=PLunhqkrRNRhYYCaSTVP-qJnyUPkTxJnBt)（workspace / package / node / topic）
  - [ROS2 Humble 官方教程](https://docs.ros.org/en/humble/Tutorials.html)（只看 Beginner: CLI tools 和 Beginner: Client libraries）
- **做**：把一个 OpenCV / 检测节点跑起来——订阅图像 → 发布结果。**到此为止。**

---

## 第 4 步：RGB-D 与 PCL 点云处理（进入 3D）

- **学**：点云 I/O、VoxelGrid、PassThrough、RANSAC 平面分割、欧式聚类、ICP
- **看**：
  - [PCL 官方教程](https://pcl.readthedocs.io/projects/tutorials/en/latest/)（I/O / VoxelGrid / PassThrough / RANSAC / Euclidean Cluster）
  - [Point Cloud Library 官网](https://pointclouds.org/)（查类和函数）
  - [Cyrill Stachniss YouTube](https://www.youtube.com/@CyrillStachniss)（Point Cloud / RANSAC / ICP）
- **做**：桌面点云分割，产出 桌面平面 → 物体点云簇 → 物体 3D 中心点（**这部分用 C++ 写**）

---

## 第 5 步：学习式抓取检测（把第 3、4 步合起来升级）

- **学**：从 2D 检测升级到 3D / 学习式抓取姿态估计
- **看**：GG-CNN、Contact-GraspNet 论文与开源代码（GitHub 搜 `GG-CNN`、`contact_graspnet`）
- **做**：复现一个学习式抓取检测，产出 点云/RGB-D → 抓取位姿（**拉开差距的关键项目**）

---

## 第 6 步：机器人坐标系与手眼标定

- **学**：旋转矩阵、齐次变换、相机→桌面→机械臂基坐标的转换链
- **看**：
  - [Modern Robotics — Foundations of Robot Motion](https://modernrobotics.northwestern.edu/nu-gm-book-resource/foundations-of-robot-motion/)（第 3 章 Rigid-Body Motions，只挑这章）
  - [3.1.1 Rotation Matrices](https://modernrobotics.northwestern.edu/nu-gm-book-resource/3-1-1-rotation-matrices-part-1-of-2/)
  - [3.3.1 Homogeneous Transformation Matrices](https://modernrobotics.northwestern.edu/nu-gm-book-resource/3-3-1-homogeneous-transformation-matrices/)
  - [OpenCV Hand-Eye Calibration 文档](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)（搜 calibrateHandEye）
- **做**：Camera-to-Robot 坐标变换 Demo，产出 图像坐标 → 桌面坐标 → 机器人基坐标

---

## 第 7 步：ROS2 补齐（工程化）

> 把第 3.5 步没深挖的补上，为总集成做准备。

- **学**：launch、tf2、参数、多节点通信
- **看**：
  - [Articulated Robotics — ROS2 Tutorials](https://www.youtube.com/playlist?list=PLunhqkrRNRhYYCaSTVP-qJnyUPkTxJnBt)（launch / 进阶部分）
  - [ROS2 tf2 官方教程](https://docs.ros.org/en/humble/Tutorials/Intermediate/Tf2/Tf2-Main.html)
- **做**：把检测/3D/坐标链各模块都包成规范节点，用 tf2 管理坐标系

---

## 第 8 步：串成完整抓取 Pipeline（总集成）

- **做**：相机 → 检测/3D → 坐标链 → 抓取位姿，串成能演示的完整系统，上 GitHub、写清 README
- 这是你简历里最核心的项目

---

## 第 9 步（选学）：SLAM 入门

> 抓取/操作感知非核心，时间够再碰。

- **学**：视觉里程计、前端/后端、位姿图
- **看**：
  - [高翔《视觉 SLAM 十四讲》代码 slambook2](https://github.com/gaoxiang12/slambook2)（B 站搜"视觉 SLAM 十四讲 高翔"配套视频）
  - [Cyrill Stachniss SLAM 讲座](https://www.youtube.com/@CyrillStachniss)（SLAM / Graph-Based SLAM / ICP / Pose Graph）
  - [Modern Robotics 官方课程](https://modernrobotics.northwestern.edu/)（坐标变换不清楚时回看）
- **做**：跑通视觉里程计 / 点云建图 demo，理解原理即可
