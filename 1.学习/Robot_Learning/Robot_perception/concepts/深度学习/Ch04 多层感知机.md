# Ch04 多层感知机

> 来源：《动手学深度学习 2.0》第 4 章（4.1~4.9 完整）

第 3 章用线性回归和 Softmax 回归展示了深度学习的全套训练流程，但它们有一个共同的名字——**线性模型**。现实世界的关系很少是纯线性的：体温升高对死亡率的影响不是单调的（37°C 两侧方向相反），图像中一个像素的含义取决于它周围的像素是什么。第 4 章要回答的核心问题是：**如何让神经网络超越线性？** 答案只有三个字——**激活函数**。在仿射变换之间插入非线性，让模型从"单层"走向"多层"，从"线性神经网络"迈入真正的**深度网络**。

---

## 4.1 多层感知机：打破线性的壁垒

### 线性模型的"天花板"

线性回归和 Softmax 回归都有一个隐含的强假设：**输出是输入的仿射函数**。这个假设带来两个根本限制：

**限制一：单调性**。任何特征的增大要么总是增大输出（权重为正），要么总是减小输出（权重为负）。有时这成立——收入越高，贷款违约概率越低——但即使在这个例子中，关系也是非线性的：收入从 0 到 5 万带来的还款概率变化，远大于从 100 万到 105 万。取对数预处理可以缓解，但治标不治本。

**限制二：无法捕捉特征交互**。区分猫和狗的图像，不能只靠单独评估每个像素的强度。决定一个像素是否属于"猫耳朵"边缘，取决于它周围像素的值——**上下文决定一切**。线性模型对每个特征独立加权求和，永远无法表达"如果像素 A 亮且像素 B 暗，则该区域是边缘"这种交互逻辑。

> **倒置图像测试**：将一张猫的图片水平翻转，对人类来说它仍然是猫。但对一个纯线性模型来说，每个像素位置被赋予了固定的权重——翻转到另一侧的像素会使用"错误"的权重，模型可能完全失效。这说明线性模型依赖的"固定位置、独立作用"假设在图像任务中根本站不住脚。

### 隐藏层：堆叠的威力

解决方案直观而优雅：**在网络中插入隐藏层**。输入 $\mathbf{X}$ 先映射到一个中间表示 $\mathbf{H}$，再从 $\mathbf{H}$ 映射到输出 $\mathbf{O}$。前 $L-1$ 层负责**学习表示**，最后一层负责**基于表示做决策**——表示和预测器被联合优化。

有 $d$ 个输入、$h$ 个隐藏单元、$q$ 个输出的单隐藏层 MLP 的数学形式为：

$$
\begin{aligned}
\mathbf{H} &= \mathbf{X} \mathbf{W}^{(1)} + \mathbf{b}^{(1)} \\
\mathbf{O} &= \mathbf{H} \mathbf{W}^{(2)} + \mathbf{b}^{(2)}
\end{aligned}
$$

其中 $\mathbf{W}^{(1)} \in \mathbb{R}^{d \times h}$，$\mathbf{b}^{(1)} \in \mathbb{R}^{1 \times h}$，$\mathbf{W}^{(2)} \in \mathbb{R}^{h \times q}$，$\mathbf{b}^{(2)} \in \mathbb{R}^{1 \times q}$。两层都是全连接的：每个输入影响每个隐藏单元，每个隐藏单元影响每个输出。

![[attachments/mlp.svg]]

### 致命缺陷：纯线性的堆叠 = 还是线性

等等——看上面的公式。$\mathbf{H}$ 是 $\mathbf{X}$ 的仿射函数，$\mathbf{O}$ 是 $\mathbf{H}$ 的仿射函数。仿射函数的仿射函数**仍然是仿射函数**。展开就能证明：

$$
\mathbf{O} = (\mathbf{X} \mathbf{W}^{(1)} + \mathbf{b}^{(1)}) \mathbf{W}^{(2)} + \mathbf{b}^{(2)} = \mathbf{X} \underbrace{\mathbf{W}^{(1)} \mathbf{W}^{(2)}}_{\mathbf{W}} + \underbrace{\mathbf{b}^{(1)} \mathbf{W}^{(2)} + \mathbf{b}^{(2)}}_{\mathbf{b}} = \mathbf{X}\mathbf{W} + \mathbf{b}
$$

无论堆多少层纯线性变换，始终能等价成一个单层。**没有非线性，深度就没有意义。** 这是初学者最容易被"多层"二字迷惑的地方——加层不自动等于更强大，你需要一个关键要素。

### 激活函数：注入非线性

**激活函数（Activation Function）** 是那个关键要素。它是一个非线性的函数 $\sigma(\cdot)$，在每次仿射变换后应用于每个隐藏单元。引入它后，MLP 的真正形式是：

$$
\begin{aligned}
\mathbf{H} &= \sigma(\mathbf{X} \mathbf{W}^{(1)} + \mathbf{b}^{(1)}) \\
\mathbf{O} &= \mathbf{H} \mathbf{W}^{(2)} + \mathbf{b}^{(2)}
\end{aligned}
$$

现在 $\sigma$ 的存在使得 $\mathbf{O}$ 无法展开成 $\mathbf{X}$ 的单次仿射变换——非线性打破了这个代数等价性。激活函数的输出叫**活性值（Activations）**，它的名字暗示了其生物来源：神经元要么"激发"要么"抑制"。

激活函数按元素、按行操作——不必关心同一行其他元素的值。这是它与 Softmax（需要整行的和做分母）的关键区别。大多数激活函数（ReLU、Sigmoid、Tanh）都满足这个性质。

> **继续堆叠**：$\mathbf{H}^{(1)} = \sigma_1(\mathbf{X} \mathbf{W}^{(1)} + \mathbf{b}^{(1)})$，$\mathbf{H}^{(2)} = \sigma_2(\mathbf{H}^{(1)} \mathbf{W}^{(2)} + \mathbf{b}^{(2)})$，$\ldots$，一层叠一层。每一层学习越来越抽象的表示——从边缘到形状到物体部件。

### 通用近似定理

有一个令人安心的理论保证：**即使只有一个隐藏层，只要有足够多的隐藏单元，MLP 可以逼近任何连续函数**。这被称为**通用近似定理（Universal Approximation Theorem）**。

但这不意味着我们应该只用一个隐藏层。用一个类比：C 语言可以表达任何可计算程序，但没人愿意用 C 语言手写一个网页浏览器——"能表达"和"容易学"是两回事。**深度（更多层）比宽度（更多隐藏单元）更高效**：深层网络可以用指数级更少的参数表示某些函数。这一洞见是现代深度学习走向"深"而非"宽"的核心驱动力。

## 4.2 三大激活函数

激活函数是 MLP 区别于线性模型的关键。这三种覆盖了 90% 以上的实际使用场景。

### ReLU：现代深度学习的默认选择

**修正线性单元（Rectified Linear Unit, ReLU）** 的定义极其简单：

$$
\text{ReLU}(x) = \max(x, 0)
$$

正数原样通过，负数一律归零。图像上它是一条折线——$x < 0$ 段为水平线，$x \geq 0$ 段为 45° 斜线。这被称为**分段线性**。

**为什么 ReLU 统治了深度学习？** 原因全在梯度上：正区域的导数恒为 1，负区域的导数恒为 0。恒为 1 意味着梯度在反向传播经过很多层时不会衰减——这直接解决了困扰深度学习数十年的**梯度消失问题**（Sigmoid 和 Tanh 的导数在远离 0 时趋近于 0，多层堆叠后梯度几乎消失，模型无法学习）。梯度要么完整通过（正区域），要么完全阻断（负区域）——这种"开关"行为在实践中表现出极好的优化性质。

当 $x = 0$ 时 ReLU 严格来说不可导。实践中我们默认使用左导数 0——"如果边界条件很重要，你大概率在研究数学而非工程"。

**变体 pReLU**：为负区域添加一个可学习的斜率 $\alpha$：$\text{pReLU}(x) = \max(0, x) + \alpha \cdot \min(0, x)$。当 $\alpha$ 为一个小正数时，负区域也能通过少量梯度，避免了"ReLU 死亡"问题（某些神经元永远输出 0，再也无法激活）。

### Sigmoid：挤压到 (0, 1)

$$
\text{sigmoid}(x) = \frac{1}{1 + e^{-x}}
$$

Sigmoid 将任意实数平滑地压缩到 $(0, 1)$ 区间——输入趋近 $+\infty$ 时输出趋近 1，输入趋近 $-\infty$ 时输出趋近 0。它是逻辑回归和早期神经网络的主力激活函数，源于对生物神经元"激发/不激发"的平滑建模。

它的导数有漂亮的闭式形式：$\text{sigmoid}'(x) = \text{sigmoid}(x)(1 - \text{sigmoid}(x))$。最大值在 $x=0$ 处，为 0.25。无论输入往正方向还是负方向远离 0，导数都迅速趋近 0——梯度被"挤压"到几乎消失。这就是**梯度消失**的根源。

现在 Sigmoid 在隐藏层中已经较少使用，被 ReLU 取代。但它仍有一席之地：**二元分类的输出层**——Sigmoid 将单个 logit 映射为概率，本质上就是二分类版的 Softmax。在 LSTM/GRU 等门控架构中，Sigmoid 也被用于控制信息流的"遗忘/记忆"开关。

### Tanh：挤压到 (-1, 1)

$$
\tanh(x) = \frac{1 - e^{-2x}}{1 + e^{-2x}}
$$

Tanh 和 Sigmoid 形状相似，但输出范围是 $(-1, 1)$ 且**关于原点中心对称**。这意味着它输出均值为 0——对下一层来说，输入数据被自动中心化了，有助于训练稳定性。导数：$\tanh'(x) = 1 - \tanh^2(x)$，最大值在 $x=0$ 处为 1（比 Sigmoid 的 0.25 好很多）。

Tanh 的一个有用恒等式：$\tanh(x) + 1 = 2 \cdot \text{sigmoid}(2x)$，表明它本质上是 Sigmoid 的缩放和平移版本。和 Sigmoid 一样，Tanh 在隐藏层中已被 ReLU 取代，但仍在某些循环网络架构中有用。

### 选择指南

| 激活函数 | 输出范围 | 隐藏层推荐 | 原因 |
|---------|:-------:|:--------:|------|
| **ReLU** | $[0, \infty)$ | ✅ 首选 | 导数恒 1 避免梯度消失，计算最快 |
| **Sigmoid** | $(0, 1)$ | ❌ 不推荐 | 导数最大 0.25，深层梯度消失严重 |
| **Tanh** | $(-1, 1)$ | ⚠️ 偶尔 | 零中心优于 Sigmoid，但仍有梯度消失 |

> **一句话记住**：ReLU 在正区间导数为 1 → 梯度不衰减 → 深层网络可训练。Sigmoid/Tanh 远端导数趋近 0 → 梯度消失 → 深层网络学不动。

## 4.3 从零开始实现

现在用 Fashion-MNIST 验证 MLP 是否比纯线性 Softmax 回归更强。架构：$784 \to 256 \text{ (ReLU)} \to 10$。隐藏层宽度取 256（$2^8$），这是经验惯例——2 的幂次在 GPU 内存对齐和矩阵运算上有微妙的效率优势。

### 第一步：初始化参数

两层全连接 → 四个参数张量：

```python
num_inputs, num_outputs, num_hiddens = 784, 10, 256

W1 = nn.Parameter(torch.randn(num_inputs, num_hiddens, requires_grad=True) * 0.01)
b1 = nn.Parameter(torch.zeros(num_hiddens, requires_grad=True))
W2 = nn.Parameter(torch.randn(num_hiddens, num_outputs, requires_grad=True) * 0.01)
b2 = nn.Parameter(torch.zeros(num_outputs, requires_grad=True))

params = [W1, b1, W2, b2]
```

这里用 `nn.Parameter` 而非裸张量——它告诉 PyTorch 这些是"模型参数"，在保存模型或传给优化器时自动被识别和管理。乘以 0.01 是因子缩放，因为我们用 `randn` 生成标准正态样本。

### 第二步：实现 ReLU

从零写 ReLU 只要一行：

```python
def relu(X):
    a = torch.zeros_like(X)
    return torch.max(X, a)
```

### 第三步：定义模型

展平 → 隐藏层（含 ReLU）→ 输出层。注意输出层**不加** Softmax——因为损失函数 `CrossEntropyLoss` 自带 LogSumExp 稳定版 Softmax：

```python
def net(X):
    X = X.reshape((-1, num_inputs))       # 28×28 → 784
    H = relu(X @ W1 + b1)                 # 隐藏层 + ReLU
    return H @ W2 + b2                    # 输出层，不加 Softmax！
```

### 第四步：损失与训练

完全复用 Ch03 的 `CrossEntropyLoss` 和 `train_ch3`——MLP 的训练循环和 Softmax 回归一模一样：

```python
loss = nn.CrossEntropyLoss(reduction='none')
num_epochs, lr = 10, 0.1
updater = torch.optim.SGD(params, lr=lr)
d2l.train_ch3(net, train_iter, test_iter, loss, num_epochs, updater)
```

这就是"训练模板"概念的力量——同样的 `train_ch3`，同样的四步循环，同样在 Fashion-MNIST 上，只是在 Softmax 回归的线性层前面插入了一个带 ReLU 的隐藏层。**唯一新增的代码就是 `relu` 函数和 `W2, b2` 两组参数。**

## 4.4 框架的简洁实现

和从零实现相比，框架版只改了一处——模型的层叠方式：

```python
net = nn.Sequential(
    nn.Flatten(),            # 28×28 → 784
    nn.Linear(784, 256),     # 隐藏层：784 → 256
    nn.ReLU(),               # ← 这才是关键：非线性激活
    nn.Linear(256, 10)       # 输出层：256 → 10
)

def init_weights(m):
    if type(m) == nn.Linear:
        nn.init.normal_(m.weight, std=0.01)

net.apply(init_weights)
```

`nn.ReLU()` 作为一个独立的"层"插入到 `Sequential` 中——它没有参数，只是对前一层输出做逐元素的 $\max(0, x)$。这种设计让你可以用搭积木的方式配置网络：`nn.Linear` 负责仿射变换，`nn.ReLU` 负责非线性激活，两者交替堆叠。

`net.apply(init_weights)` 对每个子层递归调用初始化函数——这是一种模块化的参数初始化策略，比在构造时逐个指定要灵活得多。当网络变深（几十上百层）时，这种"事后统一初始化"的模式会成为默认做法。

训练代码和 Softmax 回归的 3.7 节完全一致——同样的 `CrossEntropyLoss`，同样的 `optim.SGD(lr=0.1)`，同样的 `train_ch3`：

```python
batch_size, lr, num_epochs = 256, 0.1, 10
loss = nn.CrossEntropyLoss(reduction='none')
trainer = torch.optim.SGD(net.parameters(), lr=lr)
train_iter, test_iter = d2l.load_data_fashion_mnist(batch_size)
d2l.train_ch3(net, train_iter, test_iter, loss, num_epochs, trainer)
```

## 4.5 模型选择、欠拟合与过拟合

前四节教你搭建了 MLP，但搭好之后呢？你调隐藏层宽度、加更多层、换激活函数——训练集上的损失持续下降，但测试精度反而在某个点之后开始恶化。这就是**过拟合**（Overfitting），机器学习的核心难题。第 4.5 节将建立理解这一现象的理论框架。

### 训练误差 vs 泛化误差

机器学习的目标不是记住训练数据，而是在**从未见过的数据上表现良好**。

> 一个生动的例子：假设我们要从基因数据中预测痴呆状态。基因可以唯一确定每个个体。一个"记住"所有训练患者的模型会说："那是鲍勃！他有痴呆症！"——但在面对新患者时毫无用处。我们需要的不是"记住鲍勃"，而是"发现痴呆和基因之间的泛化模式"。

正式地说：**训练误差**是模型在训练数据上的表现；**泛化误差**是模型在从原始分布中抽取的无限多新样本上误差的期望。问题在于——泛化误差永远无法精确计算（"无限多样本"是虚构的），我们只能用独立的测试集来**估计**它。

有一个贴切的考试类比：一个学生死记硬背往年考题的答案（过拟合训练数据），另一个人理解背后的原理。前者在旧题上表现完美，但在真正考试（新题）上可能一塌糊涂。后者才能在面对从未见过的题目时仍然给出合理的回答。

> **查表法的局限**：考虑 $28 \times 28$ 的灰度图像，每个像素 256 个取值 → $256^{784}$ 种可能的图像。这个数字远超宇宙中的原子总数。不可能记住所有输入-输出对——必须**泛化**。

### 独立同分布假设

监督学习建立在一个关键假设之上：训练数据和测试数据是**独立同分布（i.i.d.）**的——从同一个分布中独立抽取，抽取过程没有"记忆"。这意味着第 2 个样本和第 200 万个样本之间的相关性，并不比第 2 个和第 3 个样本更强。

这个假设在现实中几乎从不完美成立：
- 用加州大学旧金山分校的患者数据训练的死亡风险模型，应用到马萨诸塞州综合医院——分布不同。
- 微博话题分类——新闻周期造成时间依赖性，违反独立性。
- 用大学生的脸训练人脸识别，部署到养老院——年龄分布完全不同。

好消息是，**轻微违反 i.i.d. 假设，模型通常仍能工作得很好**。人脸识别、语音识别、机器翻译都有实用价值，尽管没有任何真实应用完全满足 i.i.d.。但严重违反时（大学生 → 老人的人脸识别），模型会彻底失效。

> 解释深层神经网络泛化性能的理论基础，至今仍是学习理论领域最杰出的学者们未能完全攻克的难题。我们依赖的是大量经验法则和启发式技术——而这正是后续"正则化"章节的主题。

### 模型复杂性：什么让模型容易过拟合？

三个关键因素主导了泛化能力：

1. **可调整参数的数量**（自由度）。参数越多 → 模型越灵活 → 越容易过拟合。一个 20 阶多项式可以完美通过 20 个数据点，但它拟合的是噪声而不是规律。
2. **权重的取值范围**。权重越大 → 模型对输入的微小变化越敏感 → 越容易过拟合。这就是权重衰减（$L_2$ 正则化）的工作原理——惩罚大权重。
3. **训练样本的数量**。样本越少 → 越容易过拟合。过拟合一个只有 2 个样本的数据集，一条直线就够了；过拟合 100 万个样本，需要极其灵活的模型。

统计学家有一条经验法则：**能轻易解释任意事实的模型是复杂的；表达能力有限但仍能很好解释数据的模型更有用**。这和波普尔的"可证伪性"标准一脉相承——好的理论不仅要能拟合已有数据，还要有明确的、可以被证明是错的具体预测。

### 验证集：绝不能碰测试数据

选择模型（如比较不同隐藏层数、隐藏单元数、激活函数的 MLP）时，必须判断哪个配置泛化能力最好。但有一个铁律：

> **在确定所有超参数之前，永远不要碰测试集。**

为什么？如果你用测试集来选模型，你就相当于在"过拟合测试数据"——模型选择的决策里泄露了测试集的信息。过拟合训练集还有测试集来救场；过拟合测试集就无药可救了。

解决方案：将数据**三分为训练集、验证集、测试集**。训练集用于学参数（$\mathbf{W}, \mathbf{b}$），验证集用于选超参数（隐藏层数、学习率等），测试集只在最后评估一次。但现实中，验证集和测试集的边界常常模糊——本书实验报告的"测试精度"实际上大多是验证集精度。

**$K$ 折交叉验证**用于数据稀缺的场景：将训练数据分成 $K$ 个不重叠的子集，每次用 $K-1$ 份训练、1 份验证，轮换 $K$ 次取平均。这是在小样本条件下最可靠的模型选择方法。

### 欠拟合 vs 过拟合

两者可以通过训练误差和验证误差的关系来诊断：

- **欠拟合（Underfitting）**：训练误差和验证误差**都很高**，差距很小。模型太简单，连训练数据都学不好。解法：增加模型复杂度（更多层、更多隐藏单元）。
- **过拟合（Overfitting）**：训练误差**远低于**验证误差。模型太复杂，记住了训练数据的噪声。解法：正则化、更多数据、早停、Dropout。

> **过拟合不一定总是不好的**。在深度学习中，最好的预测模型在训练集上的表现往往远好于验证集。最终我们关心的是**验证误差本身**（而不是训练误差和验证误差之间的差距）。只要验证误差在下降，训练误差比它低多少并不重要。

### 多项式回归实验：一个直观演示

以下实验用多项式拟合来直观演示欠拟合和过拟合。真实数据由三阶多项式 $y = 5 + 1.2x - 3.4\frac{x^2}{2!} + 5.6\frac{x^3}{3!} + \epsilon$（$\epsilon \sim \mathcal{N}(0, 0.1^2)$）生成。我们用不同阶数的多项式去拟合——这就控制了模型复杂度。

特征用了 $\frac{x^i}{i!}$ 而非 $x^i$ 来避免高阶项数值爆炸（$i=20$ 时 $x^{20}$ 可能极大），除以 $i!$ 天然抑制了高阶项的尺度——这是实践中处理多项式特征的常见技巧，和神经网络的 Batch Normalization 有异曲同工之妙。

**三阶拟合（正常）**：用阶数匹配数据生成过程的前 4 个特征（1, $x$, $x^2/2!$, $x^3/3!$）。训练和测试损失都降得很低，学到的权重接近于真实值 $[5, 1.2, -3.4, 5.6]$。这就是"模型容量刚好匹配问题复杂度"的理想状态。

**一阶拟合（欠拟合）**：只给前 2 个特征（1 和 $x$）。训练损失居高不下——线性模型根本无法表达三阶多项式的弯曲。训练和测试损失都很高且几乎相等——模型能力不足，再多数据也没用。

**全 20 阶拟合（过拟合）**：用全部 20 个特征。训练损失极低（模型有足够的自由度几乎完美拟合每个训练点），但测试损失很高——高阶项在训练集上学到了噪声的随机波动，而这些波动在新数据上毫无意义。需要将 epoch 数增加到 1500 才收敛（每一阶的系数都需要更多轮训练）。最终学到的参数：前 4 阶接近真实值，后 16 阶是接近于 0 的噪声——但它们的存在就让模型足够灵活去拟合训练集的随机噪声。

这三种情况恰好对应了模型复杂度和泛化误差之间的经典 U 型曲线：从左到右依次是欠拟合（高偏差）→ 最佳 → 过拟合（高方差）。

## 4.6 权重衰减：惩罚复杂度

4.5 节诊断了过拟合的病因——模型太复杂、参数太多、数据太少。现在进入治疗阶段。第一种药方是**权重衰减（Weight Decay）**，也叫 $L_2$ 正则化——深度学习中最经典、最广泛使用的正则化技术。

### 动机：比丢弃特征更精细的刀

过拟合的一个朴素解法是限制特征数量。在多项式回归中，限制阶数相当于限制特征——但一刀切太粗暴了。阶数从 2 到 3 的小幅变化就能让模型复杂度暴涨：给定 $k$ 个变量，阶数为 $d$ 的单项式个数是 $C_{k-1+d}^{k-1} = \frac{(k-1+d)!}{d!(k-1)!}$。我们需要一把更精细的刀——不是直接砍掉特征，而是**让所有特征都保留，但约束参数的规模**。

### 原理：在损失函数里加一个惩罚项

核心思想很简单：在所有函数中，$f = 0$（所有输入都输出 0）某种意义上是最简单的。通过线性函数 $f(\mathbf{x}) = \mathbf{w}^{\top}\mathbf{x}$ 的权重向量的 $L_2$ 范数 $\|\mathbf{w}\|^2$ 来衡量其到"零"的距离——权重越小，函数越简单。

原来的训练目标是最小化训练标签上的预测损失：

$$
L(\mathbf{w}, b) = \frac{1}{n} \sum_{i=1}^{n} \frac{1}{2} (\mathbf{w}^{\top}\mathbf{x}^{(i)} + b - y^{(i)})^2
$$

加上惩罚项后，目标变成：

$$
L(\mathbf{w}, b) + \frac{\lambda}{2} \|\mathbf{w}\|^2
$$

$\lambda$ 是一个非负超参数，控制惩罚的力度：$\lambda = 0$ 回到无正则化；$\lambda$ 越大，约束越紧。除以 2 纯属数学便利——求导时指数 2 会和 1/2 抵消，让梯度表达式更干净。

> **为什么平方 $L_2$ 而不是标准 $L_2$？** 去掉平方根意味着惩罚变为每个权重分量平方的和，导数计算变得极其简单——和的导数等于导数的和。这是工程便利压倒数学纯洁性的典型案例。

### 权重衰减的名字从哪来

对加了 $L_2$ 惩罚的损失做 SGD，权重更新公式为：

$$
\mathbf{w} \leftarrow (1 - \eta\lambda)\mathbf{w} - \frac{\eta}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \mathbf{x}^{(i)}(\mathbf{w}^{\top}\mathbf{x}^{(i)} + b - y^{(i)})
$$

和普通 SGD 相比，多了前面的 $(1 - \eta\lambda)$ 因子：每次更新，权重先被**衰减**一个固定比例（$1 - \eta\lambda < 1$），再按梯度方向移动。这就是"权重衰减"这个名字的来历——优化算法在每一步都在把权重往 0 拉。

### $L_1$ vs $L_2$

- **$L_2$ 正则化**（权重衰减/岭回归）：对大权重施加巨大的惩罚（因为平方）。结果：权重在大量特征上均匀分布，对单个变量的观测误差更稳健。
- **$L_1$ 正则化**（套索回归）：倾向于将权重集中在一小部分特征上，将其余权重清零。这是**特征选择**——自动挑出最重要的特征。

### 高维实验：20 个样本 vs 200 个特征

用 $y = 0.05 + \sum_{i=1}^{200} 0.01x_i + \epsilon$ 生成数据，只用 20 个训练样本。这是一个极端的高维小样本场景——200 个参数 vs 20 个样本，过拟合几乎是必然的。

**从零实现只需一行改动**——在损失函数后加 `lambd * l2_penalty(w)`：

```python
def l2_penalty(w):
    return torch.sum(w.pow(2)) / 2

# 训练循环中唯一的变化：
l = loss(net(X), y) + lambd * l2_penalty(w)
```

实验结果鲜明：
- `lambd = 0`：训练误差降得很低但测试误差很高（严重过拟合），$w$ 的 $L_2$ 范数约为 13
- `lambd = 3`：训练误差略有上升但测试误差大幅下降，$w$ 的 $L_2$ 范数被压到约 0.36

**正则化让训练误差变差但测试误差变好**——这就是泛化能力提升的代价。在训练集上做优化和在未知数据上做预测，目标开始分道扬镳。

### 框架实现

PyTorch 优化器直接支持权重衰减，按参数组区分：

```python
trainer = torch.optim.SGD([
    {"params": net[0].weight, 'weight_decay': wd},  # 权重衰减
    {"params": net[0].bias}                          # 偏置不衰减
], lr=lr)
```

关键细节：**偏置通常不参与正则化**。偏置只控制函数的垂直平移，和复杂度关系不大。默认情况下 PyTorch 同时衰减权重和偏置，需要显式分组排除。

## 4.7 暂退法（Dropout）：打破共适应性

权重衰减从"惩罚大权重"的角度限制复杂度。Dropout 走了一条完全不同的路——在训练时**随机丢弃神经元**，强制网络不依赖任何单个神经元。

### 偏差-方差权衡的视角

线性模型有**高偏差、低方差**：只能表示一小类函数，但在不同随机样本上的结果很稳定。深度神经网络在另一端——**低偏差、高方差**：能学习特征之间的任意交互（如"尼日利亚"和"西联汇款"同时出现 = 垃圾邮件），但极易过拟合。

2017 年，研究人员在**随机标签**的图像上训练深度网络——标签和图像内容毫无关系的 10 类分类问题，直觉上人类无法做到的映射，神经网络却可以完美拟合训练集。测试精度只有 ~10%（等于随机猜），泛化差距高达 90%。这就是神经网络的"记忆容量"——它能记住任何数据，但如果不知道什么是噪声，它会把噪声也当成信号来拟合。

### 核心思想：向网络内部注入噪声

Dropout 的思想源于 Bishop（1995）发现的联系：**对输入加噪声训练，等价于 Tikhonov 正则化**——要求函数光滑。Srivastava 等人（2014）把这一思路推广到网络的内部层：在训练时，计算每一层之前，随机将一部分神经元置为零。

数学上，每个隐藏单元 $h$ 以概率 $p$ 被替换为随机变量 $h'$：

$$
h' = \begin{cases} 0 & \text{概率 } p \\ \frac{h}{1-p} & \text{其他} \end{cases}
$$

除以 $1-p$ 是关键的 **"无偏"设计**：保证了被保留神经元的期望值不变（$E[h'] = h$），这样在测试时停用 Dropout 后，输出值不需要额外缩放。

> **类比：有性繁殖 vs 无性繁殖**。原论文的作者提出了一个生物学的类比：无性繁殖（无 Dropout）让后代和亲代高度相似，但微小的基因缺陷会代代放大——类似于神经元之间的"共适应性"。有性繁殖（有 Dropout）通过基因重组成打破共适应的特征组合——每次训练迭代，网络都被迫用不同的神经元子集去解决问题，防止任何单个神经元变得"不可或缺"。

![[attachments/dropout2.svg]]

### 从零实现：一个掩码就够了

```python
def dropout_layer(X, dropout):
    assert 0 <= dropout <= 1
    if dropout == 1:
        return torch.zeros_like(X)
    if dropout == 0:
        return X
    mask = (torch.rand(X.shape) > dropout).float()  # 随机生成 0/1 掩码
    return mask * X / (1.0 - dropout)                # 保留的除以 (1-p)
```

应用到两个隐藏层的 MLP，在激活函数之后插入：

```python
H1 = self.relu(self.lin1(X))
if self.training:
    H1 = dropout_layer(H1, dropout1)      # dropout1 = 0.2
H2 = self.relu(self.lin2(H1))
if self.training:
    H2 = dropout_layer(H2, dropout2)      # dropout2 = 0.5
```

**惯例：靠近输入层的 Dropout 概率更低（如 0.2），靠近输出层的更高（如 0.5）。** 输入层的信息更原始、更宝贵，丢弃太多会切断信息流；深层特征更抽象，冗余度更高，可以更激进地丢弃。

### 框架实现：一行 `nn.Dropout`

```python
net = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 256), nn.ReLU(),
    nn.Dropout(0.2),                         # ← 就这一行
    nn.Linear(256, 256), nn.ReLU(),
    nn.Dropout(0.5),
    nn.Linear(256, 10))
```

`nn.Dropout` 自动感知 `model.train()` vs `model.eval()`——训练时随机丢弃，测试时原样通过。这是 PyTorch 模块化设计中"层自己管理状态"的优雅示范。

### 权重衰减 vs Dropout

两者都防过拟合，但路径完全不同：

| 技术 | 机制 | 作用对象 | 比喻 |
|------|------|---------|------|
| 权重衰减 | 惩罚大权重 → 简化函数 | 参数空间 | 限制每个神经元的"音量" |
| Dropout | 随机丢弃 → 打破依赖 | 激活值空间 | 让每个神经元学会"独当一面" |

这两者通常**叠加使用**，效果不会互相抵消——权重衰减让模型整体偏向简单，Dropout 让每个特征在不同子网络中都有用武之地。

## 4.8 前向传播、反向传播与计算图

前 7 节使用深度学习框架时，我们一直调用 `.backward()` 获取梯度——像一个黑箱。4.7 节打开这个黑箱，解释 PyTorch 的自动微分引擎内部到底发生了什么。

### 前向传播：按顺序计算并存储

前向传播就是从输入到输出，依次计算每一层的中间变量并**保存在内存中**（反向传播需要它们）。以带 $L_2$ 正则化的单隐藏层 MLP 为例：

$$
\begin{aligned}
\mathbf{z} &= \mathbf{W}^{(1)} \mathbf{x} & &\text{(1) 线性变换} \\
\mathbf{h} &= \phi(\mathbf{z})             & &\text{(2) 激活函数} \\
\mathbf{o} &= \mathbf{W}^{(2)} \mathbf{h}  & &\text{(3) 输出层} \\
L &= l(\mathbf{o}, y)                      & &\text{(4) 损失} \\
s &= \frac{\lambda}{2}(\|\mathbf{W}^{(1)}\|_F^2 + \|\mathbf{W}^{(2)}\|_F^2) & &\text{(5) 正则化} \\
J &= L + s                                 & &\text{(6) 目标函数}
\end{aligned}
$$

**计算图**可视化这个依赖链：正方形 = 变量，圆形 = 操作符，箭头 = 数据流向。从输入 $\mathbf{x}$ 出发，经过矩阵乘法、激活、再矩阵乘法，最终汇聚到目标函数 $J$。

![[attachments/forward.svg]]

### 反向传播：沿计算图逆向求梯度

反向传播的本质是**链式法则的工程实现**——从输出端的目标函数 $J$ 开始，沿着计算图逆向遍历，依次计算每个中间变量和每个参数的梯度。每一步只依赖于已经算出的"更靠后"的梯度，恰好可以按序求解。

以 $\mathbf{W}^{(2)}$ 的梯度为例，它来自两条路径之和——损失路径和正则化路径：

$$
\frac{\partial J}{\partial \mathbf{W}^{(2)}} = \underbrace{\frac{\partial J}{\partial \mathbf{o}} \mathbf{h}^{\top}}_{\text{损失贡献}} + \underbrace{\lambda \mathbf{W}^{(2)}}_{\text{正则化贡献}}
$$

$\frac{\partial J}{\partial \mathbf{o}} = \frac{\partial L}{\partial \mathbf{o}}$ 是损失对 logit 的梯度（对 CrossEntropyLoss 就是 $\hat{y} - y$），乘以 $\mathbf{h}^{\top}$ 是链式法则中"局部梯度 × 上游梯度"的标准形式。

再往上一层，$\mathbf{W}^{(1)}$ 的梯度需要穿过更多步骤：

$$
\begin{aligned}
\frac{\partial J}{\partial \mathbf{h}} &= \mathbf{W}^{(2)\top} \frac{\partial J}{\partial \mathbf{o}}  &
&\text{(6) 梯度穿过输出层} \\
\frac{\partial J}{\partial \mathbf{z}} &= \frac{\partial J}{\partial \mathbf{h}} \odot \phi'(\mathbf{z}) &
&\text{(7) 梯度穿过激活函数} \\
\frac{\partial J}{\partial \mathbf{W}^{(1)}} &= \frac{\partial J}{\partial \mathbf{z}} \mathbf{x}^{\top} + \lambda \mathbf{W}^{(1)} &
&\text{(8) 到达第一个参数}
\end{aligned}
$$

步骤（7）中 $\odot$ 是按元素乘法——因为 $\phi$（如 ReLU）是逐元素操作的，它的梯度也是逐元素的。

### 训练比预测更吃显存的根本原因

前向传播中所有中间变量（$\mathbf{z}$, $\mathbf{h}$, $\mathbf{o}$, $\mathbf{W}^{(1)}$, $\mathbf{W}^{(2)}$）都必须保存在内存中，直到反向传播使用完毕才能释放。这意味着：

- 显存占用 ≈ 批大小 × 层数 × 每层中间变量大小
- **更大的批大小**（batch_size）让梯度估计更稳定，但也需要更多显存
- **更深的网络**（更多层）意味着更长的中间变量链条

这是"GPU 显存不够用"（OOM, Out of Memory）问题的根本原因，也是混合精度训练、梯度检查点（checkpointing）等技术存在的理由——它们都在做"用时间换空间"的权衡。

### 自动微分：为什么你从来不用手算梯度

在自动微分之前，改一下网络架构就意味着重推一整页偏导数。PyTorch 的 `autograd` 引擎在每次前向传播时动态构建计算图（Define-by-Run），调用 `.backward()` 时自动沿图逆向传播梯度。你只需要写前向代码，梯度自动算好。这是深度学习框架最核心的贡献——把研究者从微积分手册中解放出来。

## 4.9 数值稳定性与模型初始化

4.2 节介绍了 ReLU 如何缓解梯度消失，4.8 节揭示了反向传播中梯度如何层层相乘。4.9 节将这两者结合，系统地解释**深层网络的数值稳定性问题及其初始化方案**。

### 梯度消失和梯度爆炸

考虑一个有 $L$ 层的深层网络。第 $l$ 层参数的梯度是 $L-l$ 个雅可比矩阵的连乘：

$$
\partial_{\mathbf{W}^{(l)}} \mathbf{o} = \mathbf{M}^{(L)} \cdot \ldots \cdot \mathbf{M}^{(l+1)} \cdot \mathbf{v}^{(l)}
$$

其中 $\mathbf{M}^{(i)} = \partial_{\mathbf{h}^{(i-1)}} \mathbf{h}^{(i)}$。如果每个矩阵的"缩放因子"都大于 1，连乘后梯度呈指数增长——**梯度爆炸**，参数更新步长过大，模型发散。如果都小于 1，连乘后梯度趋近于 0——**梯度消失**，参数几乎不更新，网络无法学习。

一个生动的演示：取一个 $4 \times 4$ 随机高斯矩阵，连续乘 100 个同样的随机矩阵。结果：矩阵元素从 ~1 量级膨胀到 $\sim 10^{23}$ 量级——100 层深度的梯度放大效应就是如此剧烈。

### Sigmoid 为什么被淘汰

回到 4.2 节画过的 Sigmoid 图像——当输入远离 0 时，Sigmoid 的导数趋近于 0，最大值也仅有 0.25。在深层网络中，$L-l$ 个最大值 0.25 的矩阵连乘 = $0.25^{L-l}$，指数级衰减。这就是为什么在 ReLU 之前，深度网络的训练几乎是不可能的——Sigmoid 和 Tanh 在每一层都把梯度压缩一次，10 层以上的网络根本学不动。

> ReLU 的 $\max(0, x)$ 在正区域导数为恒等（=1），连乘不衰减。这是它成为"深度网络救世主"的数学原因——不是因为它比 Sigmoid 更"像神经元"，而是因为它的梯度不消失。

### 对称性：为什么不能全初始化为零

假设把隐藏层所有权重初始化为同一个值 $c$。前向传播时，所有隐藏单元收到相同输入、做相同计算、输出相同激活。反向传播时，所有参数收到完全相同的梯度。更新后，它们仍然完全相同——对称性永远不会被打破，$n$ 个隐藏单元等价于 1 个。

这就是为什么**随机初始化是必需的**——它打破神经元之间的对称性，让不同的隐藏单元可以学习不同的特征。注意 Dropout 也能打破对称性，但那是训练过程中的随机性，不能替代初始化。

### Xavier 初始化：从方差分析出发

假设全连接层 $o_i = \sum_{j=1}^{n_\text{in}} w_{ij} x_j$，其中 $w_{ij}$ 均值为 0、方差为 $\sigma^2$，$x_j$ 均值为 0、方差为 $\gamma^2$，且相互独立。可以推导出：

$$
\text{Var}[o_i] = n_\text{in} \sigma^2 \gamma^2
$$

要保持方差不变（即 $\text{Var}[o_i] = \gamma^2$），需要 $n_\text{in} \sigma^2 = 1$，即 $\sigma = \frac{1}{\sqrt{n_\text{in}}}$。

但从反向传播的角度，类似的推理给出 $n_\text{out} \sigma^2 = 1$，即 $\sigma = \frac{1}{\sqrt{n_\text{out}}}$。前向需要 $\frac{1}{\sqrt{n_\text{in}}}$，反向需要 $\frac{1}{\sqrt{n_\text{out}}}$——不可能同时满足。**Xavier 初始化**取调和平均的妥协：

$$
\sigma = \sqrt{\frac{2}{n_\text{in} + n_\text{out}}}
$$

对应的高斯分布 $\mathcal{N}\left(0, \sqrt{\frac{2}{n_\text{in} + n_\text{out}}}\right)$ 或均匀分布 $U\left(-\sqrt{\frac{6}{n_\text{in} + n_\text{out}}}, \sqrt{\frac{6}{n_\text{in} + n_\text{out}}}\right)$。

尽管推导中假设了"没有非线性"，Xavier 在实践中工作得很好。对于使用 ReLU 的网络，**He 初始化**（$\sigma = \sqrt{\frac{2}{n_\text{in}}}$）考虑了 ReLU 将一半输出置零的效应，通常效果更好。

### 现代框架的默认行为

PyTorch 的 `nn.Linear` 默认使用 He 初始化（`kaiming_uniform_`），这是经过大量实验验证的可靠默认值。之前章节中手动用 `nn.init.normal_(m.weight, std=0.01)` 是因为网络很浅（2~3 层），标准初始化也能工作。层数一旦超过 10，初始化方案的选择就变得至关重要——选错了可能根本训练不起来。

## 4.10 环境和分布偏移

前面的所有章节都在一个理想化假设下运行：训练数据和测试数据来自**同一个分布**（i.i.d.）。4.5 节讨论过当这个假设不成立时的问题，但只是开了个头。4.10 节是 4.5 的延伸——它问的是：**当模型被部署到真实世界后，如果世界变了，会发生什么？**

### 分布偏移的三种形态

训练数据来自分布 $p_S(\mathbf{x}, y)$，测试数据来自分布 $p_T(\mathbf{x}, y)$。如果没有关于 $p_S$ 和 $p_T$ 之间关系的假设，学习是不可能的——极端情况下输入分布不变但标签全部翻转（猫变狗、狗变猫），你无法将这种情况与完全没有变化的情况区分开。

**协变量偏移（Covariate Shift）**：输入分布 $P(\mathbf{x})$ 变了，但标签函数 $P(y \mid \mathbf{x})$ 不变。这是最广泛研究的一类偏移，在认为 $\mathbf{x}$ 导致 $y$ 时是自然假设。例子：训练集是真实猫狗照片 → 测试集是卡通猫狗图片。猫"看起来像猫"的规律没变，但像素分布完全不同了。

![[attachments/cat-dog-train.svg]]
![[attachments/cat-dog-test.svg]]

**标签偏移（Label Shift）**：标签边缘概率 $P(y)$ 变了，但 $P(\mathbf{x} \mid y)$ 不变。在认为 $y$ 导致 $\mathbf{x}$ 时是合理假设。例子：疾病的流行率随时间波动，但疾病引起的症状规律不变。

**概念偏移（Concept Shift）**：标签本身的定义变了。例子："软饮"在美国不同地区叫 soda / pop / coke——同一个词对应不同的概念，不同的词对应同一个概念。

![[attachments/popvssoda.png]]

### 真实的失败案例

**医学诊断的协变量偏移**：一家初创公司用老年男性患者的血液样本（+疾病）和大学生志愿者的血液样本（-健康）训练疾病检测器。分类器很快学会了完美区分——但不是检测疾病，而是检测"你是 70 岁还是 20 岁"。年龄、激素水平、体力活动……无数与疾病无关的协变量差异主导了分类边界。花了一大笔钱，模型完全不能用。

**自动驾驶的路沿检测**：用游戏渲染引擎生成的合成数据训练——渲染引擎中所有路沿都是同一种简单纹理。模型学到了"找这种纹理"，在虚拟测试中表现完美，但在真实道路上灾难性失败。类似的故事：美军用清晨拍的森林照片（无坦克）和中午拍的森林照片（有坦克）训练坦克检测器——分类器学会了区分有阴影的树和没阴影的树。

**非平稳分布的温水煮青蛙**：训练好的垃圾邮件过滤器起初工作完美，但垃圾邮件发送者在不断进化——新模板、新话术、新绕过策略。2009 年训练的广告模型不知道 iPad 是什么。圣诞帽推荐系统到了 2 月还在推荐圣诞帽。分布不是跳变，而是缓慢漂移——模型如果不持续更新，精度会不知不觉地衰退。

### 协变量偏移的纠正

当我们有来自源分布 $q(\mathbf{x})$ 的训练数据，但测试时面对的是目标分布 $p(\mathbf{x})$（且 $p(y \mid \mathbf{x}) = q(y \mid \mathbf{x})$ 不变），可以用**重要性加权**来纠正。每个训练样本被赋予一个权重：

$$
\beta_i = \frac{p(\mathbf{x}_i)}{q(\mathbf{x}_i)}
$$

这个比率可以用对数几率回归来估计：训练一个二元分类器区分"源分布样本"和"目标分布样本"，如果某个源样本和目标样本难以区分（分类器给出的概率接近 0.5），说明它在两个分布中都"不太奇怪"——权重接近 1。反之，如果一个源样本很容易被识别为"来自源分布"（很可能在目标分布中极少出现或不存在），就大幅降低它的权重。

### 学习范式的光谱

4.10 节最后给出了一个超越标准监督学习的视角——真实世界的机器学习问题分布在从"批量学习"到"在线学习"到"强化学习"的光谱上。

**批量学习**：训练一次，部署后永不更新。猫门检测器就是典型——智能猫门的视觉系统装好后就固定了。

**在线学习**：每个新数据点到来就更新一次模型。股票预测、新闻推荐——世界在变，模型必须跟着变。

**老虎机（Bandit）**：在线学习的特例，只有有限个动作可选（如"展示广告 A 还是 B"）。可以得到更强的理论保证。

**强化学习**：环境会记住你的行为并据此改变。你的决策不仅影响当下的奖励，还影响未来的状态。自动驾驶、围棋、星际争霸都是典型。这也是最危险的场景——预测性警务系统用"高犯罪率社区"的数据训练，派更多警察去这些社区，发现更多犯罪，数据又"证实"了之前的预测……形成灾难性的正反馈循环。

### 从预测到决策的伦理跳跃

当模型从"预测"升级为"自动化决策"时，精度不再是合适的评价标准。把一张图片错误分类为 A 可能是无害的，错误分类为 B 可能是种族歧视——两种错误的代价完全不同，但精度指标一视同仁。这引出了机器学习中最棘手的问题：公平性、问责制、透明度——**不是"能不能做到"的技术问题，而是"该不该做"的价值判断**。

## 小结

第 4 章从"线性"到"非线性"再到"泛化与控制"，完整地覆盖了从搭建第一个 MLP 到理解深层网络训练全貌的知识链路。

**架构基础**：
- 纯仿射堆叠 = 还是仿射变换。激活函数（ReLU）是打破线性的唯一钥匙。
- MLP 公式：$\mathbf{O} = (\sigma(\mathbf{X} \mathbf{W}^{(1)} + \mathbf{b}^{(1)})) \mathbf{W}^{(2)} + \mathbf{b}^{(2)}$。训练模板 `train_ch3` 从 Ch03 到 Ch04 复用不变。

**正则化技术**：
- **权重衰减**（$L_2$ 正则化）：在损失中加 $\frac{\lambda}{2}\|\mathbf{w}\|^2$，每一步 SGD 把权重往 0 拉。$L_1$ 能自动特征选择，$L_2$ 让权重均匀分布更稳定。
- **Dropout**：训练时随机丢弃神经元（除以 $1-p$ 保持无偏），测试时原样通过。打破神经元间的"共适应性"，让每个神经元都能独当一面。
- 两者叠加使用效果更好——权重衰减约束参数空间，Dropout 扰动激活空间。

**训练机理**：
- **前向传播**：从输入到输出顺序计算并存储中间变量。
- **反向传播**：链式法则的工程实现——从输出端逆向遍历计算图，逐层传播梯度。`autograd` 自动化了这一过程。
- **训练比预测更吃显存**：中间变量必须保留到反向传播完成才能释放。

**数值稳定性**：
- **梯度消失/爆炸**：$L-l$ 个雅可比矩阵连乘——都 < 1 → 指数消失，都 > 1 → 指数爆炸。Sigmoid 导数最大 0.25，深层必然消失；ReLU 正区域导数恒 1，从根源解决。
- **Xavier 初始化**：$\sigma = \sqrt{\frac{2}{n_\text{in} + n_\text{out}}}$，折中前向和反向的方差需求。ReLU 网络用 He 初始化（$\sqrt{2/n_\text{in}}$）效果更佳。
- **随机初始化**是必须的——全相同初值导致对称性永远无法打破，$n$ 个神经元退化为 1 个。

**泛化与部署**：
- **过拟合**（训练误差 ≪ 验证误差）vs **欠拟合**（两者都很高）。模型选择必须通过验证集，绝不能碰测试数据。
- **分布偏移**是真实部署的头号杀手——协变量偏移（输入分布变）、标签偏移（标签频率变）、概念偏移（标签含义变）。医学诊断、自动驾驶、垃圾邮件过滤器中都有血的教训。
- 从"预测"到"决策"的跳跃引入了伦理问题：精度不是唯一标准，错误类型之间的代价不对称，反馈循环可能放大偏见。
