# Ch03 线性神经网络

> 来源：《动手学深度学习 2.0》第 3 章（3.1~3.7 线性回归 + Softmax 回归 完整内容）+ PyTorch 基础核心问答

第 3 章是深度学习实战的真正起点。前两章铺好了工具（张量、预处理、线性代数），现在终于开始训练真正的模型。本章分两条主线：**线性回归**回答了"预测多少"的回归问题，**Softmax 回归**回答了"预测哪个"的分类问题。两者本质上都是**单层全连接神经网络**，区别只在于输出层——一个是标量，一个是概率向量。掌握了这两种模型，你就掌握了深度学习训练的全套流程：模型定义 → 损失函数 → 梯度下降 → 训练循环。

## 3.1 线性回归：从理论到神经网络

### 线性模型

线性回归的核心假设只有一个：**目标值可以表示为输入特征的加权和**。给定 $d$ 个特征 $x_1, \ldots, x_d$，预测值 $\hat{y}$ 为：

$$
\hat{y} = w_1 x_1 + w_2 x_2 + \cdots + w_d x_d + b
$$

用向量形式简洁表达：$\hat{y} = \mathbf{w}^{\top}\mathbf{x} + b$。其中 $\mathbf{w}$ 是**权重**（weight），$b$ 是**偏置**（bias）。权重决定了每个特征对预测的贡献方向与大小，偏置保证了当所有特征为 0 时模型仍有表达能力——它在几何上就是一个**平移**，和加权和一起构成对输入特征的**仿射变换**。

对于整个数据集 $\mathbf{X} \in \mathbb{R}^{n \times d}$（$n$ 个样本，$d$ 个特征），预测值向量为 $\hat{\mathbf{y}} = \mathbf{X}\mathbf{w} + b$。这就是你将在每一章反复看到的模式：矩阵乘法 + 偏置 + 广播。

![[attachments/fit-linreg.svg]]

现实中，即使特征与标签之间存在真正的线性关系，观测也不可能完美。因此我们在模型中显式加入**噪声项** $\epsilon$：$y = \mathbf{w}^{\top}\mathbf{x} + b + \epsilon$。通常假设 $\epsilon \sim \mathcal{N}(0, \sigma^2)$，即噪声服从均值为 0 的正态分布——这个假设远比看起来深刻，后面会展开。

### 损失函数：平方误差

我们需要一个量化"预测有多糟"的指标。回归问题最常用的是**平方误差**（Squared Error）：

$$
l^{(i)}(\mathbf{w}, b) = \frac{1}{2} \left(\hat{y}^{(i)} - y^{(i)}\right)^2
$$

前面的 $\frac{1}{2}$ 纯粹是为了求导方便——导数的常数系数会变成 1。在整个训练集上取均值，得到**均方误差（MSE）**：

$$
L(\mathbf{w}, b) = \frac{1}{n} \sum_{i=1}^n \frac{1}{2} \left(\mathbf{w}^{\top}\mathbf{x}^{(i)} + b - y^{(i)}\right)^2
$$

训练的目标就是找到使 $L$ 最小的参数：$\mathbf{w}^*, b^* = \arg\min L(\mathbf{w}, b)$。

### 解析解：线性回归的"特权"

线性回归是深度学习中少数存在**解析解**（analytical solution）的问题。将偏置合并到权重矩阵中，目标变为最小化 $\|\mathbf{y} - \mathbf{X}\mathbf{w}\|^2$。令梯度为零，直接解出：

$$
\mathbf{w}^* = (\mathbf{X}^{\top}\mathbf{X})^{-1} \mathbf{X}^{\top} \mathbf{y}
$$

这就是著名的**正规方程**（Normal Equation）。但别高兴太早——现实中的深度学习模型几乎没有解析解。正因为如此，我们需要一种更通用的方法。

### 梯度下降：通用解法

**梯度下降（Gradient Descent）** 是深度学习优化的主力算法。核心思想极朴素：站在当前位置，朝下坡最陡的方向（负梯度）迈一小步；重复此过程直到收敛。形式化地说：

$$
(\mathbf{w}, b) \leftarrow (\mathbf{w}, b) - \eta \cdot \nabla_{(\mathbf{w}, b)} L(\mathbf{w}, b)
$$

其中 $\eta$ 是**学习率（Learning Rate）**——控制步长大小。太大可能震荡甚至发散，太小则收敛缓慢。

但每次计算梯度都要遍历整个数据集，代价太大。**小批量随机梯度下降（Minibatch SGD）** 解决了这个问题：每次只随机抽取一个小批量 $\mathcal{B}$（比如 32 个样本），用这个子集估计梯度然后更新。数学上：

$$
(\mathbf{w}, b) \leftarrow (\mathbf{w}, b) - \frac{\eta}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \nabla l^{(i)}(\mathbf{w}, b)
$$

> **为什么除以 $|\mathcal{B}|$？** 因为损失是小批量样本的总和——批量越大，梯度累加值越大。除以批量大小相当于做了归一化，使学习率不依赖于批量大小的选择。这是一个容易被忽视但至关重要的细节。

这里引出了几个贯穿全书的核心概念：

- **批量大小（Batch Size）**：每次更新用的样本数。太小→梯度估计噪声大；太大→计算开销大且可能泛化变差。
- **学习率 $\eta$**：最关键的**超参数**——不是模型学出来的，而是人手设定的。调它是深度学习最痛苦也最见功力的技能。
- **迭代周期（Epoch）**：遍历完整个训练集一次。
- **泛化（Generalization）**：在未见过的数据上表现良好——这才是机器学习的终极目标，而不是在训练集上把损失压到零。

### 从概率视角理解：正态分布与极大似然

为什么选择平方误差？这不是随意的——它有一条优美的概率解释。

假设噪声 $\epsilon$ 服从正态分布 $\mathcal{N}(0, \sigma^2)$，那么给定输入 $\mathbf{x}$，观测到标签 $y$ 的**似然**（likelihood）为：

$$
P(y \mid \mathbf{x}) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{1}{2\sigma^2}(y - \mathbf{w}^{\top}\mathbf{x} - b)^2\right)
$$

对整个数据集，**极大似然估计**（MLE）要求我们选择使所有样本出现概率乘积最大的参数。取负对数后，最大化似然等价于**最小化负对数似然**：

$$
-\log P(\mathbf{y} \mid \mathbf{X}) = \sum_{i=1}^n \frac{1}{2}\log(2\pi\sigma^2) + \frac{1}{2\sigma^2} \left(y^{(i)} - \mathbf{w}^{\top}\mathbf{x}^{(i)} - b\right)^2
$$

在 $\sigma$ 固定的前提下，第一项是常数可以忽略，第二项中 $\frac{1}{2\sigma^2}$ 也只是缩放因子。于是**最小化平方误差 = 在高斯噪声假设下的极大似然估计**。这不是巧合——损失函数的选择隐含了对数据生成过程的假设。如果噪声是拉普拉斯分布，最优损失就变成 $L_1$（绝对值误差）。

> **实践启示**：当你的数据中有很多离群点时，MSE 会因为平方放大效应而过度惩罚它们。此时 $L_1$ 损失（MAE）或 Huber 损失可能更合适。理解这个概率视角，你才能在面对真实数据时做出正确的损失函数选择。

### 矢量化：让代码快一个数量级

一个容易被初学者跳过的关键细节：**永远不要用 Python for 循环做数值计算**。对两个 10000 维向量做加法，for 循环耗时 0.17 秒，而矢量化 `a + b` 只需要 0.0004 秒——**快了 400 倍**。

矢量化之所以有效，是因为底层调用了经过深度优化的 BLAS 线性代数库，利用了 CPU 的 SIMD 指令甚至 GPU 的并行能力。在深度学习中，这个加速差距还会被训练循环的迭代次数进一步放大。养成**矢量化优先**的编码习惯，是写出高效深度学习代码的第一准则。

### 线性回归 = 单层神经网络

换个角度看线性回归：输入 $x_1, \ldots, x_d$ 通过加权和汇聚到一个输出神经元 $o_1$。这就是一个**单层全连接网络**——输入层 $d$ 个节点，输出层 1 个节点，每个输入与输出直接相连。

![[attachments/singleneuron.svg]]

线性回归发明于 1795 年，比计算神经科学早得多。但麦库洛奇和皮茨 1943 年提出人工神经元模型时，正是以线性加权和作为起点——这与生物神经元的工作方式惊人一致：树突接收来自其他神经元的信号 $x_i$，通过突触权重 $w_i$ 进行缩放和抑制，所有加权信号在细胞核内汇聚为 $y = \sum x_i w_i + b$，再经过非线性处理后沿轴突发送出去。

![[attachments/neuron.svg]]

当然，今天的深度学习更倚重数学和计算机科学，而非神经科学。就像飞机受鸟类启发，但空气动力学才是真正的驱动力。

## 3.2 从零开始实现

理解了理论之后，亲手从零实现一遍是不可替代的学习过程。这一节只用张量和自动求导，不借助框架的任何高层 API。整个流程可以概括为六个步骤。

### 第一步：生成合成数据

我们用已知的真实参数反推数据，这样训练后可以量化地评估模型学到了多少：

```python
import torch

def synthetic_data(w, b, num_examples):
    """生成 y = Xw + b + 噪声"""
    X = torch.normal(0, 1, (num_examples, len(w)))   # 从标准正态采样特征
    y = torch.matmul(X, w) + b                         # 无噪声的线性预测
    y += torch.normal(0, 0.01, y.shape)                # 叠加微小高斯噪声
    return X, y.reshape((-1, 1))

true_w = torch.tensor([2, -3.4])   # 两个特征的权重：正相关和负相关
true_b = 4.2
features, labels = synthetic_data(true_w, true_b, 1000)
```

这里有 1000 个样本，每个样本有 2 个特征。真实参数 $\mathbf{w} = [2, -3.4]$ 和 $b = 4.2$ 就是我们的"标准答案"——训练结束后可以对比模型学到了什么。

### 第二步：构建数据迭代器

训练时需要不断随机抽取小批量。迭代器封装了打乱样本和分批的逻辑。其核心技巧是**打乱索引（Indices），而非打乱数据本身**——生成 0 到 $N-1$ 的索引列表，打乱它，按 `batch_size` 切片取出索引，再用这批索引去特征和标签中同时取数。这样既节省了内存（不需要移动大块数据），又绝对保证了特征和标签的严格对齐：

```python
import random

def data_iter(batch_size, features, labels):
    num_examples = len(features)
    indices = list(range(num_examples))
    random.shuffle(indices)                               # 打乱索引
    for i in range(0, num_examples, batch_size):
        batch_indices = torch.tensor(
            indices[i: min(i + batch_size, num_examples)])
        yield features[batch_indices], labels[batch_indices]  # 索引同时取特征和标签
```

> **为什么每轮都要打乱？** 如果模型每次看到数据的顺序完全一样，它就会去死记硬背"数据的出现顺序"而非真正的规律——这被称为**排序偏置**，是过拟合的一种形式。随机打乱有三层意义：（1）**消除排序偏置**，避免连续看到同一类数据导致参数剧烈震荡；（2）**满足独立同分布假设**，保证每个小批量梯度能代表整体数据的真实梯度方向；（3）**注入健康的噪声**，每一轮的 Batch 组合不同，微小的震动有助于模型跳出局部极小值陷阱。测试集则不需要打乱——因为评测时不更新参数，按顺序评测更方便对账对齐。

### 第三步：初始化模型参数

权重从正态分布 $\mathcal{N}(0, 0.01)$ 随机初始化，偏置初始化为 0。`requires_grad=True` 告诉 PyTorch 要追踪这些参数的梯度：

```python
w = torch.normal(0, 0.01, size=(2, 1), requires_grad=True)
b = torch.zeros(1, requires_grad=True)
```

> **为什么不能全初始化为 0？** 如果所有权重相同，反向传播时所有神经元收到相同的梯度更新，它们将永远保持相同——模型退化为只有一个有效神经元。随机初始化打破对称性，是神经网络能够学习的关键前提。

### 第四步：定义模型与损失

模型：输入特征与权重的矩阵-向量积 + 偏置（广播自动处理标量→向量的扩展）。

```python
def linreg(X, w, b):
    return torch.matmul(X, w) + b
```

损失：平方误差。注意 `y.reshape(y_hat.shape)` 确保 `y` 和预测值 `y_hat` 的形状一致——这是广播机制正确工作的前提。

```python
def squared_loss(y_hat, y):
    return (y_hat - y.reshape(y_hat.shape)) ** 2 / 2
```

### 第五步：定义优化器

小批量 SGD 的 PyTorch 实现。`torch.no_grad()` 告诉框架这一段计算不需要构建计算图（因为只是参数更新，不求导），既节省内存又加速。`param.grad.zero_()` **清零梯度**——这是最容易忘记的一步，如果不清零，梯度会默认累加（这是 PyTorch 的设计选择，在某些场景如 RNN 中有用）。

```python
def sgd(params, lr, batch_size):
    with torch.no_grad():
        for param in params:
            param -= lr * param.grad / batch_size
            param.grad.zero_()
```

### 第六步：训练循环

把以上五个步骤串起来——这就是深度学习训练的经典模板，看过一遍就永远不会忘：

```python
lr = 0.03
num_epochs = 3
net = linreg
loss = squared_loss

for epoch in range(num_epochs):
    for X, y in data_iter(batch_size, features, labels):
        l = loss(net(X, w, b), y)      # 1. 前向传播：计算预测 + 损失
        l.sum().backward()              # 2. 反向传播：计算梯度
        sgd([w, b], lr, batch_size)    # 3. 参数更新
    with torch.no_grad():
        train_l = loss(net(features, w, b), labels)
        print(f'epoch {epoch + 1}, loss {float(train_l.mean()):f}')
```

输出示例：
```
epoch 1, loss 0.042790
epoch 2, loss 0.000162
epoch 3, loss 0.000051
```

验证模型的恢复精度：
```
w的估计误差: tensor([-1.3804e-04,  5.7936e-05])
b的估计误差: tensor([0.0006])
```

三个 epoch 后，模型学到的参数与真实值相差不到万分之一。线性回归确实是一个"容易"的问题——但不要被这个简单性迷惑了。在后面的章节中，同样的训练模板将驱动 ResNet、Transformer 等复杂模型，**训练循环的结构一模一样，只是 `net` 和 `loss` 换掉而已**。

## 3.3 框架的简洁实现

当你理解了从零实现的每个细节后，框架的高层 API 不再是"黑魔法"，而是帮你省去重复劳动的趁手工具。

### DataLoader：一行替代 data_iter

```python
from torch.utils import data

dataset = data.TensorDataset(features, labels)
data_iter = data.DataLoader(dataset, batch_size=10, shuffle=True)
```

这里 `TensorDataset` 扮演了一个关键角色——它像一个**订书机**，把特征矩阵和标签向量按行死死钉在一起，生成一个统一的数据集对象。如果没有这一步，特征和标签就是两堆独立的纸，后续打乱时很容易导致"试卷和成绩错位"的灾难。绑定之后，`DataLoader` 再帮你搞定打乱、分批和多线程预取——同样的接口适用于任何数据和模型。

在训练前，通常会用 `next(iter(data_iter))` 做一次**"探针检查"**——提前确认 $X$ 和 $y$ 的形状是否完全对齐、数据类型是否是 `float32`、有没有奇怪的 NaN 或无穷大。这能避免跑了几个小时后才因为形状报错而前功尽弃。

一个容易让初学者困惑的细节：为什么要写 `iter(data_iter)` 而不能直接 `next(data_iter)`？这里有一个绝妙的比喻——**书与书签**：

- **DataLoader（可迭代对象）** 就像一本 500 页的书。书是静态的，不会自己翻页，也不记录读到哪里。
- **`iter(书)`** 就像插进去的**书签**，或者伸出一根指向第一页的手指。它把静态数据变成了动态流。
- **`next(手指)`** 就是翻页——吐出当前页的内容，自动把手指往后挪一页。

更深一层看，这个设计支持了**多轮训练**：如果 DataLoader 本身就是一个迭代器，读完第一遍（Epoch 1）就空了，第二轮就没数据了。而作为"可迭代对象"，每一轮训练开始时框架会隐式调用 `iter()` 生成一个全新的书签从头开始读，数据源源不断。

### nn.Linear：一行替代 linreg

```python
from torch import nn

net = nn.Sequential(nn.Linear(2, 1))
```

`nn.Linear(2, 1)` 就是线性回归模型的完整数学表达——2 个输入特征，1 个输出预测值。它不仅代表了公式 $y = Xw + b$，更关键的是**在后台自动帮你创建并初始化了 $w$ 和 $b$ 两个参数**。一行代码替代了从零实现中手动定义参数矩阵、写矩阵乘法的所有工作。

`nn.Sequential` 是一个**流水线容器**（组装盒），把网络层按顺序装进去——这里虽然只有一层，但为后续扩展为多层网络培养了手感。你可以通过 `net[0].weight` 和 `net[0].bias` 直接访问内部参数。

参数初始化：

```python
net[0].weight.data.normal_(0, 0.01)  # 权重 N(0, 0.01)
net[0].bias.data.fill_(0)            # 偏置 = 0
```

### MSELoss + SGD：各一行

```python
loss = nn.MSELoss()                                     # 均方误差
trainer = torch.optim.SGD(net.parameters(), lr=0.03)   # SGD 优化器
```

`net.parameters()` 自动收集模型中的所有可学习参数，不劳你手动管理和传递。

这里 `trainer` 虽然只是一个变量名，但它的角色贯穿整个训练。借用**下山找最低点**的比喻：

- **模型（net）** 是下山的人。
- **损失（loss）** 是高度计，告诉你当前位置有多高。
- **反向传播（backward）** 是测倾斜度，告诉你哪个方向是下坡。
- **trainer（优化器）** 就是**你的腿**——它负责执行 `trainer.step()`，真正迈出更新参数 $w, b$ 的那一步。

所以 `trainer` 不是一个被动的"记录器"，而是训练过程中唯一能做"物理操作"的角色。

### 训练循环：和从零实现一模一样

```python
num_epochs = 3
for epoch in range(num_epochs):
    for X, y in data_iter:
        l = loss(net(X), y)         # 1. 前向传播：预测并计算误差
        trainer.zero_grad()         # 2. 梯度清零：抹除上一轮残留的梯度
        l.backward()                # 3. 反向传播：自动求导，算出每个参数的梯度
        trainer.step()              # 4. 参数更新：根据梯度和学习率修改 w 和 b
    print(f'epoch {epoch + 1}, loss {loss(net(features), labels):f}')
```

和从零实现的区别只有两步：`trainer.zero_grad()` 替代手动 `param.grad.zero_()`，`trainer.step()` 替代手动 SGD 更新。其余逻辑完全一致。这就是框架的力量——不是让训练变"简单"，而是让你专注于模型设计而非重复性工程。

### 深入理解梯度清零

训练循环中最容易被忽视、也是最容易出错的一步，就是 `trainer.zero_grad()`。初学者常有两个疑问：为什么梯度存在参数上而不是损失上？为什么非要用 `trainer` 来清零？

**梯度存在哪里？** PyTorch 将梯度存储在每个参数的 `.grad` 属性中（如 `w.grad`、`b.grad`），而非损失变量 $l$ 里。$l$ 只是一个标量数字（比如 0.5），本身没有地方存梯度——所以它根本没有 `zero_grad()` 方法。训练循环中 `l.backward()` 做的事，就是把损失对各参数的导数自动写入对应的 `.grad` 属性。如果不手动清零，每次 `backward()` 的梯度会**累加**到旧值上——这在某些场景（如 RNN 的时序展开）是有意为之，但对普通训练来说会直接导致训练发散。

**为什么用 `trainer.zero_grad()`？** 你可能会想：为什么不用 `net.parameters().zero()` 或 `net.zero_grad()`？答案是 `net.parameters()` 返回的是一个**生成器（Generator）**——也就是一个名单，本身没有 `.zero()` 方法。如果用 `net.zero_grad()`，它其实也在做同样的事（内部就是一个 for 循环遍历参数清零）。但习惯上用 `trainer.zero_grad()` 有两个额外优势：在复杂网络（如 GAN 或部分冻结参数的迁移学习）中，`trainer` 可以**只清零"归它管"的那部分参数**的梯度，避免误伤不需要更新的层。这是一个随着模型变复杂后你自然会感激的设计。

## 3.4 Softmax 回归：从回归到分类

线性回归回答了"预测多少"——房价多少、温度多高。但现实中有大量问题是问**"预测哪个"**的：这封邮件是垃圾还是正常？这张图是猫、狗还是鸡？这就是**分类问题**，而 Softmax 回归是分类模型中最基础也最优美的一个。

与线性回归相比，Softmax 回归只改了三个地方：输出从一个标量变成多个类别的概率向量；损失从平方误差换成交叉熵；评估指标从 MSE 换成精度。其余的一切——线性层、梯度下降、训练循环——全部复用。

### 问题的重塑：独热编码

分类的标签表示有一个优雅的工具：**独热编码（One-hot Encoding）**。假设有三类 $\{猫, 鸡, 狗\}$，标签 $y$ 不是整数 $1$、$2$、$3$，而是一个三维向量：

$$
y \in \{(1, 0, 0),\ (0, 1, 0),\ (0, 0, 1)\}
$$

$(1,0,0)$ 表示"猫"，$(0,1,0)$ 表示"鸡"，$(0,0,1)$ 表示"狗"。这种做法虽然看似浪费空间，但它避免了无意义的"顺序"假设——猫和鸡之间不存在"大于"或"小于"的关系。如果直接用整数标签 $1,2,3$，模型可能会错误地认为"类别 $3$ 离类别 $1$ 比类别 $2$ 更远"——这在没有自然顺序的分类任务中是完全没有道理的。

只有在类别间存在天然顺序时（如 $\{婴儿, 儿童, 青少年, 成人, 老人\}$），用单个整数做回归才有意义。

### 模型架构：多输出线性层

既然要预测 $q$ 个类别的概率，输出就不该是一个标量，而应该是 $q$ 个值。对于 $d$ 个输入特征和 $q$ 个输出类别，模型将权重从 $\mathbf{w} \in \mathbb{R}^d$ 扩展为 $\mathbf{W} \in \mathbb{R}^{d \times q}$，偏置从 $b$ 扩展为 $\mathbf{b} \in \mathbb{R}^q$：

$$
\mathbf{o} = \mathbf{W}^{\top} \mathbf{x} + \mathbf{b}
$$

$\mathbf{o}$ 是一个长度为 $q$ 的向量，每个分量 $o_j$ 叫**未归一化预测**（logit）——它还不是概率，只是一个"打分"。

> **全连接层的参数开销**：一个 $d$ 输入、$q$ 输出的全连接层需要 $\mathcal{O}(dq)$ 个参数。对于高维输入（比如 $224 \times 224 \times 3 = 150528$ 像素的图像），即使只有 1000 个类别，参数量也是 $1.5 \times 10^8$ 级别——这也是为什么后续章节必须引入卷积层来大幅削减参数。

用矩阵形式同时处理一个小批量 $\mathbf{X} \in \mathbb{R}^{n \times d}$：

$$
\mathbf{O} = \mathbf{X} \mathbf{W} + \mathbf{b}
$$

$\mathbf{O} \in \mathbb{R}^{n \times q}$ 的每一行是一个样本的 $q$ 个 logits。Softmax 运算将按行对每行独立进行归一化。

### Softmax 运算：从 Logits 到概率

线性层输出的 $\mathbf{o}$ 有三个问题阻止它直接作为概率：（1）分量可能为负；（2）分量之和不一定为 1；（3）缺乏概率校准——当模型输出 0.5 时，我们期望真正有一半样本属于该类。

**Softmax 函数**解决了全部三个问题。它将 logits 映射为概率分布：

$$
\hat{y}_j = \text{softmax}(\mathbf{o})_j = \frac{\exp(o_j)}{\sum_{k=1}^q \exp(o_k)}
$$

这个公式做了两件事：先用 $\exp$ 保证所有分量非负，再除以总和保证全部分量加起来等于 1。因为 $\exp$ 是单调递增的，Softmax **不改变 logits 的大小顺序**——$\arg\max_j \hat{y}_j = \arg\max_j o_j$，预测时取最大 logit 对应的类别即可。

> **为什么叫 Softmax？** 它是对"硬性最大值"（Hardmax，即只保留最大值将其设为 1、其他全为 0）的"软化"版本。$\exp$ 函数让较大的值"脱颖而出"但又保持了一定的平滑性，使得梯度能够正常传播。温度参数 $T$ 可以调节这种"软硬程度"：$\text{softmax}(\mathbf{o}/T)$，$T \to 0$ 趋近于 hardmax，$T \to \infty$ 趋近于均匀分布。

### 交叉熵损失：分类的默认选择

Softmax 回归使用**交叉熵损失（Cross-Entropy Loss）**，这是分类问题中最常用的损失函数，正如平方误差之于回归。

对于单个样本，设其真实标签的独热向量为 $\mathbf{y}$（只有一个分量为 1），预测概率为 $\hat{\mathbf{y}}$，交叉熵损失定义为：

$$
l(\mathbf{y}, \hat{\mathbf{y}}) = -\sum_{j=1}^q y_j \log \hat{y}_j
$$

由于 $\mathbf{y}$ 是独热向量，这个求和本质上是取**真实类别对应的 $\log$ 概率的负值**：$l = -\log \hat{y}_{真实类别}$。解释极为直观——模型对正确答案赋予的概率越高，损失越小；如果概率接近 1，损失趋近于 0；如果概率接近 0，损失趋向无穷。

从概率视角看，交叉熵等价于**极大似然估计**：假设标签服从多项分布，最大化整个数据集的似然 $P(\mathbf{Y} \mid \mathbf{X}) = \prod P(\mathbf{y}^{(i)} \mid \mathbf{x}^{(i)})$ 取负对数后，恰好就是交叉熵损失的和。这和线性回归中"最小化 MSE = 高斯噪声下的 MLE"完全平行——只需要换一个概率分布假设（多项→高斯），损失函数自然切换。

#### 交叉熵的梯度：极其简洁

交叉熵配合 Softmax 有一个被低估的优点：**梯度形式极度简洁**。将交叉熵损失对 logit $o_j$ 求导：

$$
\frac{\partial l}{\partial o_j} = \text{softmax}(\mathbf{o})_j - y_j = \hat{y}_j - y_j
$$

换句话说，梯度就是**预测概率减去真实标签**。这几乎是最简单的梯度形式了——和线性回归中 MSE 的梯度"预测值减真实值"如出一辙。这不是巧合：任何指数族分布模型的极大似然梯度都有这种形式。实现起来既方便又不易出错。

### 信息论视角：交叉熵即"惊异度"

交叉熵有一个深刻的信息论诠释，理解它可以让损失选择从"跟着教材抄"变为"知其所以然"。

**熵（Entropy）** 衡量一个概率分布的不确定性：$H(P) = -\sum_j P(j) \log P(j)$。举个例子，如果你总是知道接下来会发生什么（概率全部集中在某一类），熵就为 0——零惊异。如果你完全不确定（均匀分布），熵达到最大值。

**交叉熵 $H(P, Q)$** 的含义是：真实分布是 $P$，但你用的是 $Q$ 来做预测——那么你看到数据时感受到的"惊异"有多大？公式依然是 $-\sum_j P(j) \log Q(j)$，和上面的损失函数完全一致。当 $P = Q$ 时交叉熵最小化，等于熵 $H(P)$；当 $Q$ 偏离 $P$ 时，交叉熵增大，增大的部分恰好是 **KL 散度**。

**一句话总结**：最小化交叉熵 = 最大化似然 = 最小化"看到真实数据时的惊异"。三种视角指向同一个损失函数，这也是交叉熵在分类问题中不可撼动的原因。

### 模型评估：精度

回归用 MSE 评估，分类用**精度（Accuracy）**——正确预测的样本数除以总样本数。精度的取值范围在 0 到 1 之间，值越大越好。

注意精度和交叉熵损失是两回事：损失是连续的、可微的，用于**训练时优化参数**；精度是离散的、不可微的，用于**评估时衡量表现**。一个模型可能损失在下降但精度不上升——这说明它变得更"自信"了，但并没有变得更"正确"。这种现象叫**过度自信**，在有标签噪声的数据中尤为常见。

## 3.5 图像分类数据集：Fashion-MNIST

理论讲完了，在动手实现 Softmax 回归之前，需要一个真实的分类数据集。MNIST 手写数字识别曾是分类任务的"Hello World"，但作为基准过于简单——现代模型几乎都能达到 99%+ 的精度，难以区分算法的优劣。我们将使用更具挑战性的 **Fashion-MNIST**，它由 Zalando 研究团队于 2017 年发布，用 10 类服装物品替代了 0~9 数字。

### 数据集概览

Fashion-MNIST 的 10 个类别分别为：T恤（t-shirt）、裤子（trouser）、套衫（pullover）、连衣裙（dress）、外套（coat）、凉鞋（sandal）、衬衫（shirt）、运动鞋（sneaker）、包（bag）和短靴（ankle boot）。训练集 60000 张，测试集 10000 张，每张图像是 $28 \times 28$ 的灰度图（单通道）。相比 MNIST，Fashion-MNIST 的类别间相似度更高（如衬衫和 T 恤、运动鞋和短靴），因此分类难度更大，更能反映真实场景下的模型能力。

PyTorch 的 `torchvision` 提供了开箱即用的加载方式：

```python
import torch
import torchvision
from torch.utils import data
from torchvision import transforms

trans = transforms.ToTensor()                      # PIL → float32 张量，像素值 /255 归一化到 [0,1]
mnist_train = torchvision.datasets.FashionMNIST(
    root="../data", train=True, transform=trans, download=True)
mnist_test = torchvision.datasets.FashionMNIST(
    root="../data", train=False, transform=trans, download=True)
```

`transforms.ToTensor()` 做了两件事：将 PIL 图像转为 `float32` 张量，并将像素值从 $[0, 255]$ 缩放到 $[0, 1]$。这个归一化对训练至关重要——未经归一化的大数值输入会导致梯度爆炸，而框架内置的权重初始化通常假设输入在 $[0, 1]$ 范围内。

### 从图像到特征向量

每个样本是一张 $28 \times 28$ 的图像，但 Softmax 回归只能接受向量输入。我们需要将图像**展平（Flatten）**为长度为 $28 \times 28 = 784$ 的向量，把每个像素位置当作一个独立特征。这显然丢失了空间结构——像素之间的位置关系完全被忽略了——但它简单有效，能作为后续卷积网络保留空间结构的**对比基线**。

### 数据迭代器

使用 `DataLoader` 批量加载数据。这里和线性回归中完全一样，但多了一个实用参数 `num_workers`：指定用多少个子进程来并行加载数据。Windows 上通常设为 0（多进程在 Windows 上有兼容性问题），Linux/Mac 上可以设为 4 来加速：

```python
batch_size = 256

def get_dataloader_workers():
    return 0 if sys.platform.startswith('win') else 4

train_iter = data.DataLoader(mnist_train, batch_size, shuffle=True,
                             num_workers=get_dataloader_workers())
test_iter = data.DataLoader(mnist_test, batch_size, shuffle=False,
                            num_workers=get_dataloader_workers())
```

> **测试集为什么不打乱？** 和线性回归中的逻辑一致——测试时不更新参数，打乱没有意义，且保持顺序方便对账和结果复现。

## 3.6 Softmax 回归：从零开始实现

现在有了数据集和理论基础，可以动手了。Softmax 回归的从零实现和线性回归的从零实现（3.2 节）结构几乎完全一致——这是因为两者的训练模板是通用的。下面按步骤展开，焦点放在与回归的不同之处。

### 第一步：初始化模型参数

输入是 784 维的展平图像，输出是 10 个类别的 logits。因此权重 $\mathbf{W} \in \mathbb{R}^{784 \times 10}$，偏置 $\mathbf{b} \in \mathbb{R}^{10}$。初始化策略和线性回归一样：权重从 $\mathcal{N}(0, 0.01)$ 随机采样，偏置全零。

```python
num_inputs = 784
num_outputs = 10

W = torch.normal(0, 0.01, size=(num_inputs, num_outputs), requires_grad=True)
b = torch.zeros(num_outputs, requires_grad=True)
```

### 第二步：实现 Softmax 运算

回顾 Softmax 的定义：对矩阵的每一行，先对每个元素求 $\exp$，再除以该行所有 $\exp$ 之和。关键点是 `sum(1, keepdim=True)`——对轴 1（行方向）求和但保持维度，这样广播除法（`/`）才能正确地将每一行除以其对应的和：

```python
def softmax(X):
    X_exp = torch.exp(X)
    partition = X_exp.sum(1, keepdim=True)   # 每行的配分函数（规范化常数）
    return X_exp / partition                  # 广播除法
```

> **配分函数（Partition Function）** 的名字来自统计物理学——它描述了粒子在不同能级上的概率分布。在深度学习中，它就是把"打分"转化为"概率"的那个分母。其对数称为**对数配分函数**，是许多生成模型的基础概念。

### 第三步：定义模型

模型本身只有两步：将输入的 $28 \times 28$ 图像展平成 $1 \times 784$ 向量，然后做矩阵乘法 + 偏置 + Softmax：

```python
def net(X):
    return softmax(torch.matmul(X.reshape((-1, W.shape[0])), W) + b)
```

这里 `-1` 让 PyTorch 自动推断批量大小。`W.shape[0]` 取的是 `num_inputs = 784`。和线性回归唯一的不同是多了一个 `softmax()` 包裹——模型从输出标量变为输出概率向量。

### 第四步：实现交叉熵损失

交叉熵只关心模型对**真实类别**预测的概率。实现时不需要用 for 循环遍历每个样本——巧用 PyTorch 的**高级索引**（Advanced Indexing）一行搞定。举个简单例子理解原理：`y_hat[[0, 1], [0, 2]]` 取出第 0 行第 0 列（样本 0 的真实类别 0）和第 1 行第 2 列（样本 1 的真实类别 2）的概率：

```python
y = torch.tensor([0, 2])                         # 两个样本的真实标签
y_hat = torch.tensor([[0.1, 0.3, 0.6],          # 样本0对3类的预测
                      [0.3, 0.2, 0.5]])         # 样本1对3类的预测
y_hat[[0, 1], y]                                  # → tensor([0.1, 0.5])
```

推广到整个小批量：

```python
def cross_entropy(y_hat, y):
    return -torch.log(y_hat[range(len(y_hat)), y])
```

`range(len(y_hat))` 生成行索引 `[0, 1, 2, ..., batch_size-1]`，`y` 是每个样本真实类别的列索引，两者组合精确选出每个样本在正确类别上的预测概率，取负对数即得交叉熵。

### 第五步：分类精度

回归用 MSE 评估，分类用**精度（Accuracy）**。实现时用 `argmax` 取每行概率最大的列索引作为预测类别，与真实标签逐元素比较，统计正确的占比：

```python
def accuracy(y_hat, y):
    """计算预测正确的数量"""
    if len(y_hat.shape) > 1 and y_hat.shape[1] > 1:
        y_hat = y_hat.argmax(axis=1)            # 每行取 argmax
    cmp = y_hat.type(y.dtype) == y               # 逐元素比较
    return float(cmp.type(y.dtype).sum())         # 统计正确数
```

在整个数据集上评估精度需要遍历所有小批量并累加。这里用一个通用的 `Accumulator` 工具类来维护多个累加变量（正确预测数、样本总数），遍历完数据后二者相除即得整体精度：

```python
class Accumulator:
    """在 n 个变量上累加"""
    def __init__(self, n):
        self.data = [0.0] * n
    def add(self, *args):
        self.data = [a + float(b) for a, b in zip(self.data, args)]
    def __getitem__(self, idx):
        return self.data[idx]

def evaluate_accuracy(net, data_iter):
    if isinstance(net, torch.nn.Module):
        net.eval()                               # 切换到评估模式
    metric = Accumulator(2)                      # [正确数, 总数]
    with torch.no_grad():
        for X, y in data_iter:
            metric.add(accuracy(net(X), y), y.numel())
    return metric[0] / metric[1]
```

> **`net.eval()` 的作用**：某些层（如 Dropout、BatchNorm）在训练和评估时行为不同。`eval()` 告诉模型"现在是评估时间"，这些层会自动切换到对应的行为模式。这里虽然只有一个线性层不受影响，但养成习惯很重要。

随机初始化的模型精度大约在 0.1（10 个类别，随机猜测的水平），这符合预期——没训练过的模型不应该比瞎猜更准。

### 第六步：训练循环

训练循环和线性回归**几乎完全一致**。D2L 把它抽象为 `train_epoch_ch3` 和 `train_ch3` 两个通用函数，以后各章都能复用。核心逻辑依然是四步：前向 → 清零 → 反向 → 更新：

```python
def train_epoch_ch3(net, train_iter, loss, updater):
    """训练一个迭代周期"""
    if isinstance(net, torch.nn.Module):
        net.train()                              # 切换到训练模式
    metric = Accumulator(3)                      # [损失总和, 正确数, 样本数]
    for X, y in train_iter:
        y_hat = net(X)
        l = loss(y_hat, y)
        if isinstance(updater, torch.optim.Optimizer):
            updater.zero_grad()                  # 框架版：优化器清零
            l.mean().backward()                  # 框架自动求均值损失
            updater.step()
        else:
            l.sum().backward()                   # 从零版：总和损失求导
            updater(X.shape[0])
        metric.add(float(l.sum()), accuracy(y_hat, y), y.numel())
    return metric[0] / metric[2], metric[1] / metric[2]
```

这里的 `updater` 对框架版优化器是 `trainer.step()`，对从零实现是我们之前写的 `sgd` 函数。同一个训练函数同时支持两种模式——通过 `isinstance` 检查来分支处理。

训练 10 个 epoch，学习率 0.1：

```python
lr = 0.1
def updater(batch_size):
    return d2l.sgd([W, b], lr, batch_size)

num_epochs = 10
train_ch3(net, train_iter, test_iter, cross_entropy, num_epochs, updater)
```

训练曲线会显示三条线：训练损失（持续下降）、训练精度（持续上升）、测试精度（略低于训练精度且趋于平稳）。如果测试精度显著低于训练精度，说明出现了过拟合——这也是后续章节要解决的核心问题。

## 3.7 Softmax 回归：框架的简洁实现

和线性回归的 3.3 节一样，当理解了从零实现的每个步骤后，框架的高层 API 让你聚焦于模型设计而非重复性工程。

### 模型：nn.Flatten + nn.Linear

和线性回归的关键区别：这里多了一层 `nn.Flatten()`。它把 $28 \times 28$ 的图像自动展平为 784 维向量——你不再需要手动 `reshape`：

```python
from torch import nn

net = nn.Sequential(
    nn.Flatten(),          # 28×28 → 784
    nn.Linear(784, 10)     # 784 → 10 类 logits
)

def init_weights(m):
    if type(m) == nn.Linear:
        nn.init.normal_(m.weight, std=0.01)     # N(0, 0.01) 初始化

net.apply(init_weights)
```

`net.apply(fn)` 对模型中的每个子层递归调用 `fn`，只对 `nn.Linear` 类型的层进行自定义初始化——这是一种模块化的参数初始化策略。

### 数值稳定性：LogSumExp 技巧

从零实现的 `softmax` 函数存在一个危险：如果某个 $o_k$ 很大，$\exp(o_k)$ 会直接上溢为 `inf`；如果所有 $o_k$ 都很小，$\exp(o_k)$ 会下溢为 0，取其对数后变成 `-inf`。这两种情况都会导致 `nan` 梯度，让训练直接崩溃。

**解决方法很简单也很巧妙**：在求指数前，先让所有 $o_k$ 减去它们的最大值 $\max(o_k)$。因为：

$$
\text{softmax}(\mathbf{o})_j = \frac{\exp(o_j - \max o)}{\sum_k \exp(o_k - \max o)}
$$

减去常数不改变 Softmax 的结果（分子分母同时除以 $\exp(\max o)$ 就消掉了），但所有输入被平移到 $\leq 0$ 的范围，最大值为 0（$\exp(0)=1$），其他为 $\exp(\text{负数})$——永不溢出。

更进一步，**将 Softmax 和交叉熵合并计算**可以彻底绕过 $\exp$ 的数值问题：

$$
\log \hat{y}_j = o_j - \max o - \log\left(\sum_k \exp(o_k - \max o)\right)
$$

这个技巧叫 **LogSumExp**——先做上面的减法平移，再在 log 空间完成归一化和求和。PyTorch 的 `nn.CrossEntropyLoss(reduction='none')` 在内部就用了这个技巧：它接收**未归一化的 logits**（不需要你手动调 `softmax`），自动完成 Softmax → log → NLL 三步，且全程数值稳定。

```python
loss = nn.CrossEntropyLoss(reduction='none')
```

> **这是实践中最容易错的地方**：如果你自己算了 `softmax` 再传给 `CrossEntropyLoss`，相当于做了两次 Softmax，模型不会报错但梯度会完全错误。"CrossEntropyLoss 吃 logits，不吃概率"——记住这一条。

### 优化器与训练

优化器和训练循环与线性回归的 3.3 节完全一致——SGD 学习率 0.1，10 个 epoch，同一个 `train_ch3` 函数：

```python
trainer = torch.optim.SGD(net.parameters(), lr=0.1)
num_epochs = 10
d2l.train_ch3(net, train_iter, test_iter, loss, num_epochs, trainer)
```

这正是"训练模板"概念的有力体现：同样的 `train_ch3`，同样的四步循环，只是换了 `net` 和 `loss`，就从回归切换到了 10 类分类。

## 小结

本章用两个模型覆盖了深度学习最基础的两类问题：回归和分类。整章按"理论 → 数据 → 从零实现 → 框架实现"的对称结构组织。

- **线性回归**（3.1~3.3）：$\hat{y} = \mathbf{w}^{\top}\mathbf{x} + b$，平方损失，SGD 优化。回答"预测多少"。
- **Softmax 回归**（3.4~3.7）：$\hat{\mathbf{y}} = \text{softmax}(\mathbf{W}^{\top}\mathbf{x} + \mathbf{b})$，交叉熵损失。回答"预测哪个"。
- **共同本质**：两者都是单层全连接神经网络。平方损失和交叉熵损失都等价于各自的极大似然估计。SGD 的梯度都取"预测值 − 真实值"的简洁形式。
- **关键机制**：Softmax 将 logits 映射为合法概率；交叉熵 = 真实类别负对数概率；LogSumExp 技巧通过在指数前减去最大值，避免了 $\exp$ 上溢/下溢导致的 `nan` 梯度，生产级代码中 `CrossEntropyLoss` 内部自动完成此操作。
- **Fashion-MNIST**：10 类服装图像数据集，$28 \times 28$ 灰度图，训练 60k/测试 10k。展平为 784 维向量后输入 Softmax 回归，随机初始化精度约 0.1，训练后达到 0.80+。
- **训练循环** = `前向 → 反向 → 更新`，这个模板在 ResNet 和 Transformer 中依然不变。`train_epoch_ch3` 同时兼容从零实现（手动 SGD）和框架实现（`optim.SGD`），通过 `isinstance` 检查自动选择分支。
- **梯度清零**（`trainer.zero_grad()`）是最容易被遗忘的一步——梯度存于参数而非损失，PyTorch 默认累加而非覆盖。在复杂网络（GAN、部分冻结）中用 `trainer` 清零可以只清零"归它管"的参数。
