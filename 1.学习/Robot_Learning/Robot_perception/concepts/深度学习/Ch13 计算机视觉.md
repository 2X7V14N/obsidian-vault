# Ch13 计算机视觉

> 来源：《动手学深度学习 2.0》第 13 章（13.1~13.2）

Ch06 和 Ch07 覆盖了从 LeNet 到 DenseNet 的架构演进，但你可能会注意到一个问题：所有这些网络都在 Fashion-MNIST（6 万张 $28 \times 28$ 灰度图）上训练，而真实世界的视觉任务——比如识别椅子、检测热狗、区分不同品种的狗——面临的是**数据稀缺**和**领域差异**。你有 100 张训练图片而不是 60000 张；你的目标类别从未出现在 ImageNet 中。第 13 章解决的就是这两个实际问题：**如何在小数据集上训练出好模型？** 答案是两条互补的技术路线——图像增广和迁移学习。

## 13.1 图像增广：用数据生成数据

### 为什么需要增广？

Ch07 中 AlexNet 的成功有三个支柱——ReLU、Dropout、以及**数据增强**。在一个理想的世界里，你可以收集更多的数据来防止过拟合。但在现实世界中，标注数据昂贵、耗时，甚至不可行（如医学影像）。图像增广（Image Augmentation）提供了一种聪明得多的方法：**不收集新数据，而是对已有数据施加随机变换，生成"相似但不同"的训练样本**。

增广做的是两件事：（1）扩大训练集的有效规模；（2）注入**先验知识**——告诉模型哪些变化是无关紧要的。例如，水平翻转一只猫的图片，它仍然是猫。如果模型在原图和翻转图上被要求做出相同的预测，它就学会了"猫不依赖于左右朝向"。同理，随机裁剪让模型对物体位置的敏感度降低，颜色抖动让模型不过度依赖特定的光照条件。

> **数据增强 = 免费的正则化**：每张图在训练时都被随机变换，模型永远不会连续两次看到完全相同的样本。这本身就是一种强正则化——比 Dropout 和权重衰减更直接。

### 常用增广方法

**翻转（Flip）**——最早、最广泛使用的增广：

```python
RandomHorizontalFlip()   # 50% 概率左右翻转
RandomVerticalFlip()     # 50% 概率上下翻转（慎用：猫倒过来可能不像猫）
```

**随机裁剪与缩放（RandomResizedCrop）**——同时改变位置和尺度：

```python
RandomResizedCrop((200, 200), scale=(0.1, 1), ratio=(0.5, 2))
# 随机裁剪原图 10%~100% 面积，宽高比 0.5~2，再缩放到 200×200
```

这个操作极其强大：它让猫出现在画面的不同位置、不同大小、不同比例——模型被迫学会识别"猫的本质特征"而非"猫总是在画面正中央、占据 60% 面积"这种虚假关联。这也呼应了 Ch06 中汇聚层的作用——两者都在增强平移不变性，但增广在数据层面做，汇聚层在架构层面做，双管齐下。

**颜色抖动（Color Jitter）**——改变亮度、对比度、饱和度、色调：

```python
ColorJitter(brightness=0.5, contrast=0.5, saturation=0.5, hue=0.5)
```

这强迫模型不依赖特定的颜色或光照来分类——一只猫在黄昏和正午都应该是猫。

**组合使用**：实际部署中，以上变换总是叠加在一起：

```python
augs = Compose([
    RandomHorizontalFlip(),
    ColorJitter(brightness=0.5, contrast=0.5, saturation=0.5, hue=0.5),
    RandomResizedCrop((200, 200), scale=(0.1, 1), ratio=(0.5, 2))
])
```

### 训练时的关键原则

**增广只在训练时使用，测试时不做随机变换。** 测试时只做必要的预处理（缩放到固定尺寸、归一化），确保每次对同一张图的预测是一致的。这和 Dropout（训练时随机丢弃，测试时原样通过）、BN（训练时用批统计，测试时用全局统计）的行为模式完全一致——训练时注入的随机性是一种**噪声正则化**，推理时需要确定性。

### CIFAR-10 实战

与 Fashion-MNIST 不同，CIFAR-10 的物体在颜色、大小、角度上有显著差异——更能体现增广的价值。使用 ResNet-18 + 随机水平翻转在 CIFAR-10 上训练，测试精度达到约 **85~94%**（不同框架差异较大），比不使用增广有显著提升。

训练流程：

```python
train_augs = Compose([RandomHorizontalFlip(), ToTensor()])
test_augs = Compose([ToTensor()])

train_with_data_aug(train_augs, test_augs, net)  # ResNet-18 + Adam
```

## 13.2 微调：站在巨人的肩膀上

### 从零训练的现实困境

假如你想做一个"椅子分类器"，能够区分 100 种不同款式的椅子。你能为每种椅子拍摄约 1000 张照片，总共 10 万张——比 Fashion-MNIST 的 6 万张多，但比 ImageNet 的 1000 万张差了 100 倍。在这个规模上，从零训练一个 ResNet-152 必定严重过拟合。

解决思路非常朴素：**不需要从零学什么是"边缘"、"纹理"、"形状"**——这些通用视觉特征已经在 ImageNet 上被充分学习了。你只需要教会模型"椅子的特殊形状"即可。这就是**迁移学习（Transfer Learning）**的核心思想——把在源数据集中学到的知识迁移到目标数据集。

### 微调的四步流程

![[attachments/finetune.svg]]

1. **预训练**：在源数据集（如 ImageNet，1000 类）上训练一个源模型。
2. **复制骨干**：创建一个目标模型，复制源模型的架构和参数——**除了输出层**。源模型的输出层是 1000 类的，你的任务可能只有 2 类（热狗 vs 非热狗）或 100 类（椅子款式）——不可能直接复用。
3. **替换输出层**：为目标模型新建一个随机初始化的输出层，输出数 = 目标类别数。
4. **微调**：在目标数据集上训练目标模型。关键细节：**输出层从头训练（用大学习率），骨干层只微调（用小学习率）。**

> **为什么输出层要更大学习率？** 骨干层（卷积层）的参数已经在大规模数据上学到了很好的通用特征表示——大幅度更新它们会破坏这些宝贵的知识。输出层是随机初始化的，必须快速收敛到有效值。通常的比例：骨干层学习率 $\eta$，输出层学习率 $10\eta$。

### 热狗识别：一个完整的微调案例

数据集：1400 张"热狗"图像 + 等量的"非热狗"图像，共 2800 张。1000 张训练，其余测试。

**第一步：加载预训练模型**：

```python
pretrained_net = torchvision.models.resnet18(pretrained=True)
# pretrained_net.fc → Linear(512, 1000)  # ImageNet 的 1000 类输出
```

**第二步：替换输出层**：

```python
finetune_net = torchvision.models.resnet18(pretrained=True)
finetune_net.fc = nn.Linear(finetune_net.fc.in_features, 2)   # 512 → 2
nn.init.xavier_uniform_(finetune_net.fc.weight)
```

**第三步：分组学习率**。输出层参数以 10 倍学习率训练，骨干层参数以基础学习率微调：

```python
params_1x = [p for name, p in finetune_net.named_parameters()
             if name not in ["fc.weight", "fc.bias"]]
trainer = torch.optim.SGD([
    {'params': params_1x},                              # 骨干：lr
    {'params': finetune_net.fc.parameters(), 'lr': lr * 10}  # 输出层：10×lr
], lr=5e-5, weight_decay=0.001)
```

**第四步：训练**。5 个 epoch 后：

| 方法 | 学习率 | 测试精度 |
|------|:------:|:------:|
| **微调**（ImageNet 预训练） | $5 \times 10^{-5}$ | **93.9%** |
| 从零训练（随机初始化） | $5 \times 10^{-4}$ | 84.3% |

**微调以 10 倍更小的学习率、更少的训练步数，达到了近 10 个百分点的精度提升**——这就是迁移学习的威力。2800 张图片对于从零训练 ResNet 远远不够，但却足以微调一个 ImageNet 预训练模型。学到的边缘检测器、纹理识别器、形状分析器直接复用，只需要在顶层学习"热狗特有的形状组合"。

### 微调的变体策略

实践中，微调有三种常见策略，根据目标数据集的大小来选择：

| 策略 | 适用场景 | 做法 |
|------|---------|------|
| **全微调** | 目标数据量大（>10K）且与源分布差异大 | 所有层都更新，输出层大学习率 |
| **部分微调** | 目标数据量中等（1K~10K） | 冻结浅层，只更新深层 + 输出层 |
| **特征提取** | 目标数据量极小（<1K）或与源分布相似 | 冻结所有骨干层，只训练输出层 |

**冻结**操作：`param.requires_grad = False` 后，该参数不参与梯度计算，不会被优化器更新。这本质上把预训练模型当成了一个**固定特征提取器**——只把输出层换成自己的分类器。这是最极端的迁移学习形式，适用于目标数据集极小的情况。

### 为什么微调有效？

这一节和前六章的核心信息一脉相承：Ch04 告诉我们深层网络的前几层学习通用特征（边缘→纹理→形状）而最后几层学习任务特异的特征组合。ImageNet 预训练让前几层的滤波器收敛到极为通用的视觉基元——它们在任何自然图像任务中都有用。微调只是在这个坚固的地基上搭建自己的小房子，而不用从挖地基开始。

## 小结

第 13 章是前 7 章的"实战落地"——把你学会的 CNN 架构部署到真实的、数据稀缺的场景中。

- **图像增广**：对训练数据施加随机变换（翻转、裁剪、颜色抖动）来生成"新"样本。只在训练时使用，推理时关闭。本质是注入先验知识——告诉模型哪些变化无关紧要。
- **迁移学习与微调**：复用在大规模数据集（ImageNet）上预训练的模型参数，在小数据集上微调。四步流程：预训练→复制骨干→替换输出层→分组学习率训练。
- **微调变体**：全微调（数据多+分布不同）、部分微调（冻结浅层）、特征提取（只训练输出层）。
- **微调 vs 从零训练**：热狗识别任务中，微调以 1/10 的学习率达到 **93.9%** vs 从零训练的 **84.3%**——用更少的训练成本获得大幅提升。

## 13.3 目标检测与边界框

从图像分类到目标检测，是从"整张图是什么"到"哪里有东西、有什么东西"的跨越。目标检测不仅识别物体类别，还要输出它们在图像中的精确位置。

### 边界框：目标的空间描述

边界框（Bounding Box）是矩形，有两种等价表示：

- **角点表示**：$(x_1, y_1, x_2, y_2)$ — 左上角 + 右下角
- **中心表示**：$(c_x, c_y, w, h)$ — 中心坐标 + 宽度 + 高度

两者可双向转换：

```python
# 角点 → 中心
cx, cy = (x1 + x2) / 2, (y1 + y2) / 2
w, h = x2 - x1, y2 - y1
# 中心 → 角点
x1, y1 = cx - w/2, cy - h/2
x2, y2 = cx + w/2, cy + h/2
```

图像坐标原点在**左上角**，$x$ 向右增大，$y$ 向下增大。

## 13.4 锚框：采样整个图像空间

### 为什么要锚框？

目标检测需要同时回答两个问题：物体的**类别**是什么？物体的**位置**在哪里？但直接预测任意位置和形状的框极其困难。锚框（Anchor Box）的解决思路是：**先大量采样候选框，再判断每个框里有没有东西并微调位置**。

### 生成锚框

以图像每个像素为中心，生成不同缩放比 $s$ 和宽高比 $r$ 的框。给定 $n$ 个缩放比和 $m$ 个宽高比，每像素生成 $n + m - 1$ 个锚框（组合数）。对于 $561 \times 728$ 的图、5 个锚框/像素 → 超过 200 万锚框。

锚框的宽度和高度：$w = hs\sqrt{r}$，$h = hs / \sqrt{r}$（$h$ 为图像高度）。

### 交并比 IoU：衡量两个框的相似度

![[attachments/iou.svg]]

$$
\text{IoU}(\mathcal{A}, \mathcal{B}) = \frac{|\mathcal{A} \cap \mathcal{B}|}{|\mathcal{A} \cup \mathcal{B}|}
$$

IoU ∈ [0, 1]，0 = 完全不重叠，1 = 完全重合。它是目标检测中最重要的指标——既用于分配真实框给锚框，也用于 NMS 去重。

### 给锚框分配标签

![[attachments/anchor-label.svg]]

训练时，每个锚框需要两种标签：

1. **类别**：与哪个真实框匹配就标为该类，否则标为"背景"（负类锚框）
2. **偏移量**：真实框相对于锚框的中心位置偏移和宽高缩放（做了标准化以便学习）

分配算法：贪心匹配。在 IoU 矩阵里依次取最大值配对 → 每行每列只匹配一次 → 剩余锚框中，IoU 低于 0.5 的标为背景。

**偏移量标准化**（使回归更稳定）：

$$
\left(\frac{\frac{x_b - x_a}{w_a} - \mu_x}{\sigma_x}, \frac{\frac{y_b - y_a}{h_a} - \mu_y}{\sigma_y}, \frac{\log(w_b/w_a) - \mu_w}{\sigma_w}, \frac{\log(h_b/h_a) - \mu_h}{\sigma_h}\right)
$$

### 非极大值抑制 NMS

锚框数量巨大（十万级），同一物体会被多个高度重叠的预测框包围。NMS 是去重方案：

1. 按置信度降序排列所有预测框
2. 取置信度最高的框作为基准，移除所有与它 IoU > 阈值（如 0.5）的框
3. 取第二个还不被移除的框重复步骤 2
4. 直到所有框都当过基准或已被移除

最终保留的框数量大幅减少，每个物体通常只剩一个最优框。NMS 是贪心算法——存在"过度抑制"的风险（Soft-NMS 用衰减代替硬删除来缓解）。

## 13.5 多尺度目标检测

200 万锚框中大多数是冗余的。多尺度检测的核心思路：**在 CNN 不同层的特征图上生成不同尺度的锚框**。

- **浅层特征图**（分辨率高，感受野小）→ 锚框间距密、尺度小 → 检测小物体
- **深层特征图**（分辨率低，感受野大）→ 锚框间距疏、尺度大 → 检测大物体

例如：$4 \times 4$ 特征图 → 16 个锚框中心（间距密，尺度 0.15 = 小物体），$2 \times 2$ 特征图 → 4 个中心（尺度 0.4 = 中物体），$1 \times 1$ 特征图 → 1 个中心（尺度 0.8 = 大物体）。

感受野的定义（Ch06 中已介绍）在此处发挥关键作用：特征图上一个像素"看到"输入图的哪块区域，它的锚框就应该覆盖那个区域。深层特征图每个像素的感受野覆盖了更大的输入区域，自然适合预测更大的物体。

## 13.6 目标检测数据集

目标检测的标注比分类贵得多——不是标一张图是什么，而是要在每张图中画出所有物体的边界框并标记类别。

d2l 提供了香蕉检测数据集（1000 张训练 + 100 张验证，每图一张香蕉，各种角度和位置）。标签格式为 `[类别, x1, y1, x2, y2]`（坐标归一化到 [0, 1]）。数据加载器的输出批量形状为 $(B, m, 5)$，$m$ 是每张图最大目标数（不足用 -1 填充）。

## 13.7 单发多框检测（SSD）

SSD 是将前面 13.3~13.6 的所有组件组装成一个完整的目标检测模型。它是**单阶段检测器**——一次前向传播同时输出类别和边界框，速度快，广泛使用。

### SSD 架构

![[attachments/ssd.svg]]

SSD 由一个基础网络（截断的 VGG 或 ResNet）+ 多个多尺度特征块串联而成。

**类别预测层**：一个 `Conv2d(in_channels, num_anchors × (num_classes + 1), 3×3, p=1)`。保持特征图空间尺寸不变，每个空间位置输出该类所有锚框的类别 logits。

**边界框预测层**：`Conv2d(in_channels, num_anchors × 4, 3×3, p=1)`。每个锚框 4 个偏移量。

**多尺度特征块**：基础网络输出 $32 \times 32$ 特征图 → 3 个高宽减半块 → GlobalMaxPool → 共 5 个尺度。每个尺度有自己的锚框尺寸范围（如 0.2~0.96），每个位置 4 个锚框（3 宽高比 + 1 额外缩放比）。总计 5444 个锚框/图。

### SSD 训练

损失 = 类别损失（交叉熵）+ 边界框损失（$L_1$ 平滑损失）。负类锚框的偏移量通过掩码排除。

在香蕉检测数据集上：20 epoch → 分类误差 < 0.4%，边界框 MAE < 0.004（坐标归一化后）。

### SSD 推理

前向传播 → 对每个锚框预测类别和偏移 → `offset_inverse` 将偏移还原为实际坐标 → NMS 去重 → 置信度过滤（通常 0.9）→ 最终输出。

## 13.8 R-CNN 系列：两阶段检测

SSD 一次前向传播出所有结果（单阶段）。R-CNN 家族先提出候选区域，再对候选区域精细分类（两阶段）。精度通常更高，但速度较慢。

### R-CNN：CNN 第一次用于检测

![[attachments/r-cnn.svg]]

四步骤：(1) 选择性搜索生成 ~2000 个候选区域；(2) 每个区域单独过 CNN 提取特征；(3) SVM 分类；(4) 回归器微调边界框。

**致命缺陷**：2000 次 CNN 前向传播 → 极慢。

### Fast R-CNN：共享卷积

![[attachments/fast-rcnn.svg]]

核心改进：**整张图只过一次 CNN**，所有候选区域在共享的特征图上通过 RoI Pooling 提取固定尺寸的特征。RoI Pooling 将任意形状的候选区域划分为固定网格（如 $2 \times 2$），每格取最大值，无论输入框多大都输出统一维度。

![[attachments/roi.svg]]

### Faster R-CNN：让 CNN 自己提候选区域

![[attachments/faster-rcnn.svg]]

用**区域提议网络（RPN）** 取代选择性搜索。RPN 在 CNN 特征图的每个位置生成锚框，预测"有没有物体"（二分类）和边界框偏移。RPN 与检测网络共享骨干 CNN，端到端训练。候选区域从 ~2000 减到 ~300，速度飞跃。

### Mask R-CNN：像素级检测

![[attachments/mask-rcnn.svg]]

在 Faster R-CNN 的基础上增加一个**全卷积分支**，同时预测每个 RoI 的像素级掩码。RoI Align（双线性插值）代替 RoI Pooling（最大池化），保留空间精度。Mask R-CNN 在目标检测之外同步完成**实例分割**。

| 模型 | 年份 | 核心创新 | 速度 |
|------|:--:|---------|:----:|
| R-CNN | 2014 | CNN + 候选区域 | 极慢 |
| Fast R-CNN | 2015 | 共享卷积 + RoI Pooling | 慢 |
| Faster R-CNN | 2015 | RPN 产生候选区域 | 中等 |
| Mask R-CNN | 2017 | RoI Align + 掩码分支 | 中等 |

语义分割比目标检测更进一步：**为每个像素分配类别标签**。输出是一张与输入同尺寸的"类别地图"。

### Pascal VOC2012 数据集

21 个类别（20 物体 + 背景）。标签是 RGB 图像——每种颜色映射到一个类别索引。图像分辨率各异，输入和标签需要裁剪到固定尺寸（如 $320 \times 480$），而不是缩放——因为缩放会破坏像素级的标签对应关系。

## 13.10 转置卷积：从小图还原大图

普通卷积将输入降采样（$n_h \to n_h - k_h + 1$）。语义分割需要逐像素输出——必须把降采样后的特征图"放大"回来。转置卷积就是做这件事的。

### 基本操作

![[attachments/trans_conv.svg]]

普通卷积：滑动窗口 → 局部乘加 → 输出一个标量（"多到一"）。转置卷积：输入标量 × 卷积核 → 分散到一个 $k_h \times k_w$ 的块 → 所有块累加（"一到多"）。

输入 $2 \times 2$，卷积核 $2 \times 2$ → 输出 $3 \times 3$。核 `[[0,1],[2,3]]`：

```
X[0,0]×K → [[0,0],[0,0]]  +  X[0,1]×K → [[0,0,1],[0,0,3],[0,0,0]]
+ X[1,0]×K → [[0,0,0],[0,0,0],[2,3,0]]  +  X[1,1]×K →
最终 = [[0,0,1],[0,4,6],[4,12,9]]
```

### 填充与步幅的"反转"

- **填充**：在转置卷积中，填充作用于**输出**。`padding=1` 意味着从输出中删除最外一圈。
- **步幅**：步幅 s 将中间结果的间距拉大，产生 $(n_h-1) \times s + k_h$ 的输出。

![[attachments/trans_conv_stride2.svg]]

### 为什么叫"转置"？

如果将卷积表示为矩阵乘法 $\mathbf{y} = \mathbf{W}\mathbf{x}$（$\mathbf{W}$ 是稀疏的卷积矩阵），则转置卷积的正向传播是 $\mathbf{W}^{\top}\mathbf{y}$——恰好是 $\mathbf{W}$ 的转置。这个名字来自矩阵转置，不是矩阵求逆。它不保证数值逆转（$\text{conv\_transpose}(\text{conv}(X)) \neq X$），但保证**形状逆转**。

## 13.11 全卷积网络（FCN）

FCN 将语义分割的所有组件组装为一个端到端模型：用 CNN 下采样提取特征 → 用 $1 \times 1$ 卷积将通道数变为类别数 → 用转置卷积放大回原始分辨率。

![[attachments/fcn.svg]]

### FCN 的核心设计

以 ResNet-18 为骨干：(1) 去掉最后的全局平均池化和全连接层，保留卷积部分作为特征提取器；(2) 接 $1 \times 1$ 卷积将 512 通道变为 21 通道（VOC 类别数）；(3) 接转置卷积层（kernel=64, stride=32, pad=16）将 $10 \times 15$ 的特征图放大 32 倍回到 $320 \times 480$。

$$320 \div 32 = 10,\quad 480 \div 32 = 15$$

**双线性插值初始化**：转置卷积层的初始权重来自双线性插值核——这确保训练开始时上采样至少是"合理的模糊放大"，而非随机噪声。随后通过训练逐步优化。

### 训练与精度

训练时损失函数是每个像素的交叉熵。在 VOC2012 上训练 5 epoch，测试精度约 **84~85%**（像素级分类准确率）。

> **FCN 的深远影响**：它是"全卷积"范式的开山之作——将 CNN 从"输出一个向量"（分类）改造成"输出一张图"（像素级预测）。这一设计直接衍生出 U-Net（医学图像分割）、DeepLab（空洞卷积分割）、以及现代目标检测中的特征金字塔。从 FCN 开始，"下采样→特征提取→上采样"的模式成为所有像素级视觉任务的通用架构。

## 小结

第 13 章覆盖了计算机视觉中从数据增强到像素级预测的完整链路：

**数据与迁移**：图像增广是对训练数据的"免费扩容"；微调让大模型在小数据上快速收敛。

**目标检测**：边界框 + 锚框 → IoU 匹配 → NMS 去重 → 多尺度检测。SSD（单阶段，快）和 R-CNN 系列（两阶段，准）是两条主线。

**语义分割**：像素级分类，CNN 提取特征 → $1 \times 1$ 卷积 → 转置卷积还原尺寸。转置卷积 = 矩阵乘法的转置，负责"形状逆转"而非数值逆转。FCN 开创了全卷积范式。
