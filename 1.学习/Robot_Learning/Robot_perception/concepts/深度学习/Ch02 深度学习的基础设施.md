# Ch02 深度学习的基础设施

> 来源：《动手学深度学习 2.0》第 2 章 · 预备知识（2.1 数据操作 + 2.2 数据预处理 + 2.3 线性代数）

在正式进入模型构建之前，必须先掌握三项基础技能：如何用张量存储和操作数据、如何将原始数据清洗为张量格式、以及支撑所有运算的线性代数。这三者构成深度学习的"预备知识"——没有它们，后续的每一行代码都会寸步难行。

---

## 2.1 数据操作：张量

**张量（Tensor）** 是深度学习的数据载体。你可以把它理解为多维数组——一个具有任意数量轴的数值阵列。虽然 NumPy 的 `ndarray` 也能表示数组，但张量多了两个关键能力：**GPU 加速**和**自动微分**。各框架的张量类名称不同（PyTorch 的 `Tensor`、TensorFlow 的 `Tensor`、MXNet 的 `ndarray`），但核心语义高度一致。本文以 PyTorch 为主线。

### 张量的维度与形状

不同维度的张量在数学中有不同的对应：

- **标量（0 阶张量）**：单个数值，如 `torch.tensor(3.0)`
- **向量（1 阶张量）**：一组有序标量，如 `torch.arange(4)` → `[0, 1, 2, 3]`
- **矩阵（2 阶张量）**：有行和列的二维数组，如形状 `(5, 4)` 表示 5 行 4 列
- **高阶张量**：三维以上。图像数据是最典型的三阶张量：三个轴分别对应高度、宽度和颜色通道（RGB）。处理小批量训练数据时，通常用四阶张量 `(batch_size, channels, height, width)`

张量的**形状（shape）** 是一个元组，描述沿每个轴的长度。`numel()` 返回元素总数，即形状各维度的乘积。

### 创建张量

```python
import torch

torch.arange(12)                  # 从 0 开始的整数序列
torch.arange(12).reshape(3, 4)    # 改变形状，元素值不变
torch.zeros((2, 3, 4))            # 全 0 张量
torch.ones((2, 3, 4))             # 全 1 张量
torch.randn(3, 4)                 # 标准正态分布 N(0,1) 随机采样
torch.tensor([[2,1,4,3], [1,2,3,4], [4,3,2,1]])  # 从 Python 列表创建
```

`reshape` 可以使用 `-1` 让框架自动推断该维的大小——例如 `x.reshape(-1, 4)` 自动算出需要多少行。神经网络的参数通常用 `randn` 随机初始化，以避免对称性导致的梯度一致更新。

### 按元素运算

张量的默认运算模式是按元素（element-wise）：对两个形状相同的张量，`+`、`-`、`*`、`/`、`**` 都对对应位置逐一计算：

```python
x = torch.tensor([1.0, 2, 4, 8])
y = torch.tensor([2.0, 2, 2, 2])
x + y    # tensor([3., 4., 6., 10.])
x * y    # tensor([2., 4., 8., 16.])  ← 按元素乘，不是矩阵乘法！
x ** y   # tensor([1., 4., 16., 64.])
torch.exp(x)   # 一元运算符也是按元素的
```

> ⚠️ **最容易混淆的点**：`*` 是**按元素乘（Hadamard 积）**，`@` 才是矩阵乘法。这是 NumPy 迁移者最常犯的错误。

### 连结

`torch.cat` 沿指定轴拼接多个张量：

```python
torch.cat((X, Y), dim=0)   # 沿行堆叠，行数增加
torch.cat((X, Y), dim=1)   # 沿列堆叠，列数增加
```

### 广播机制

当两个形状不同的张量做按元素运算时，**广播（Broadcasting）** 机制会在可能的情况下自动扩展维度。规则是：从右向左对齐形状，每个维度要么相等、要么其中一个为 1。广播不是真的复制数据，而是概念上的虚拟扩展——高效且内存友好。

```python
a = torch.arange(3).reshape((3, 1))    # (3, 1)
b = torch.arange(2).reshape((1, 2))    # (1, 2)
a + b                                   # (3, 2)，自动广播
```

广播在深度学习中无处不在：偏置向量加到小批量矩阵的每一行、预测值标准化等场景都依赖它。

### 索引、切片与内存节省

张量的索引从 0 开始，`-1` 表示最后一个元素，`start:end` 为左闭右开区间。支持写入：

```python
X[1, 2] = 9          # 修改单个元素
X[0:2, :] = 12       # 前两行全部赋值为 12
```

⚠️ TensorFlow 中 `Tensor` 默认不可变，需用 `tf.Variable` 包装。

**内存节省**是工程实践中的关键细节。`Y = X + Y` 会**创建新内存**而非原地更新——对于百万参数、每秒多次更新的模型来说，这不可接受。使用切片赋值 `Z[:] = X + Y` 或 `X += Y` 可以做到原地更新，避免不必要的内存分配。在训练循环中，每次参数更新都应原地完成。

### 与 NumPy 互转

PyTorch 张量与 NumPy 数组**共享底层内存**——修改一个会影响另一个，零拷贝：

```python
A = X.numpy()             # Tensor → NumPy
B = torch.tensor(A)       # NumPy → Tensor
a.item()                  # 单元素张量 → Python 标量
```

## 2.2 数据预处理

现实世界的数据很少以规整的张量格式出现。数据散布在 CSV 文件、数据库、网页和传感器日志中，充满缺失值、非数值类别和不同量纲的混合属性。**数据预处理就是将原始数据转化为张量的桥梁**。

### 读取与缺失值处理

pandas 是 Python 数据处理的标配。以 CSV 为例：

```python
import pandas as pd
data = pd.read_csv('house_tiny.csv')
```

缺失值（`NaN`）需要处理。两种基本策略：

- **插值法**：用替代值填补。最常见的是用同列均值（数值型）或最常见值（分类型）。`inputs.fillna(inputs.mean())` 一行搞定。更高级的方法包括 KNN 插值、回归预测插值和多重插值。
- **删除法**：直接丢弃含缺失值的行或列。简单粗暴但缺失比例 < 5% 时通常无害。需警惕：如果缺失不是完全随机的，删除可能引入系统性偏差。

### 独热编码（One-hot Encoding）

分类型变量（如"颜色"取值为"红/蓝/绿"）无法直接输入数值模型。独热编码将每个类别展开为独立的一列，该样本属于该类为 1、否则为 0：

```python
inputs = pd.get_dummies(inputs, dummy_na=True)
```

`dummy_na=True` 确保 `NaN` 也被视为有效类别——如果"缺失"本身可能是信号（如用户未填写 = 不满意），就不能丢弃这一信息。

> **扩展**：独热编码在类别数很大时会导致维度爆炸（如数千个产品 ID）。此时需要**嵌入（Embedding）**——将高维稀疏的独热向量映射到低维稠密的连续向量空间。这是深度学习的核心创新之一。

### 转换为张量

清洗完成后，所有列都是数值型，无缝转为张量：

```python
X = torch.tensor(inputs.to_numpy(dtype=float))
y = torch.tensor(outputs.to_numpy(dtype=float))
```

**完整管线**：加载 → 拆分特征/标签 → 缺失值处理 → 离散值编码 → 数值标准化 → 转为张量。在实际项目中通常封装为可复用的 `Dataset` 类。

## 2.3 线性代数

线性代数是深度学习的数学根基。从数据表示到模型运算到优化目标，线性代数的概念贯穿整个深度学习管线。

### 数学对象层级

| 对象 | 轴数 | 数学符号 | 代码示例 |
|------|:----:|------|------|
| **标量** | 0 | $x \in \mathbb{R}$ | `torch.tensor(3.0)` |
| **向量** | 1 | $\mathbf{x} \in \mathbb{R}^n$ | `torch.arange(4)` |
| **矩阵** | 2 | $\mathbf{A} \in \mathbb{R}^{m \times n}$ | `torch.arange(20).reshape(5,4)` |
| **张量** | ≥3 | $\mathsf{X}$ | `torch.arange(24).reshape(2,3,4)` |

向量默认是列向量。矩阵的行通常对应数据样本、列对应特征——这个约定贯穿所有深度学习框架。

### 矩阵运算

**转置**将行和列互换：$\mathbf{A}^{\top}$ 满足 $(\mathbf{A}^{\top})_{ij} = \mathbf{A}_{ji}$。`A.T` 一行搞定。**对称矩阵**满足 $\mathbf{A} = \mathbf{A}^{\top}$，在协方差矩阵和 Hessian 矩阵中常见。

**Hadamard 积** $\mathbf{A} \odot \mathbf{B}$ 是按元素乘法（代码中的 `A * B`），与矩阵乘法（`A @ B`）完全不同。

### 降维求和

对张量沿指定轴求和可以消除该轴维度：

- `A.sum(axis=0)` — 沿行方向求和，保留列维度
- `A.sum(axis=1)` — 沿列方向求和，保留行维度
- `A.sum(axis=[0,1])` — 所有维度求和，得标量

`keepdims=True` 保留被求和轴（变成大小为 1 的维度），这对后续广播至关重要。"非降维求和"还有一种特殊形式——**累积和**（`cumsum`），沿轴逐元素累加。

**平均值**本质上是求和除以元素个数：`A.mean()` 等价于 `A.sum() / A.numel()`。

### 点积

两个向量的**点积**是对应位置元素乘积的和：

$$
\mathbf{x}^{\top}\mathbf{y} = \sum_{i=1}^d x_i y_i
$$

```python
torch.dot(x, y)         # 等价于 torch.sum(x * y)
```

点积的几何意义丰富：当权重非负且和为 1 时表示加权平均；当两个向量归一化后表示夹角的余弦。神经网络的全连接层本质上就是输入向量与权重向量的点积（加上偏置和非线性激活）。

### 矩阵-向量积与矩阵乘法

**矩阵-向量积** $\mathbf{A}\mathbf{x}$ 将矩阵的每一行与向量做点积，得到一个长度为输出行数的向量。它把矩阵看作从 $\mathbb{R}^n$ 到 $\mathbb{R}^m$ 的线性变换——神经网络每一层都在做这样的映射。

**矩阵乘法** $\mathbf{C} = \mathbf{A}\mathbf{B}$ 是深度学习中计算量最大的运算。每个元素 $c_{ij}$ 是 $\mathbf{A}$ 的第 $i$ 行与 $\mathbf{B}$ 的第 $j$ 列的点积。$\mathbf{A}$ 的列数必须等于 $\mathbf{B}$ 的行数——这是调试形状报错时的第一检查点。

从几何视角看，$\mathbf{A}\mathbf{B}$ 等价于先应用 B 的变换再应用 A 的变换——**变换的复合**。这揭示了神经网络前向传播的本质：$\mathbf{x} \rightarrow \mathbf{W}_1\mathbf{x} \rightarrow \mathbf{W}_2(\mathbf{W}_1\mathbf{x}) \rightarrow \cdots$，整个前向传播就是一系列矩阵乘法的复合。

### 范数

**范数（Norm）** 衡量向量或矩阵的"大小"。一个合格的范数必须满足绝对齐次性、三角不等式和非负性。深度学习中最重要的三种范数：

| 范数 | 公式 | 特点与应用 |
|------|------|------|
| **$L_1$ 范数** | $\|\mathbf{x}\|_1 = \sum \vert x_i\vert$ | 对异常值不敏感，产生稀疏解（权重被推到 0），用于特征选择和模型压缩 |
| **$L_2$ 范数** | $\|\mathbf{x}\|_2 = \sqrt{\sum x_i^2}$ | 欧几里得距离，可微、旋转不变。$L_2$ 正则化（权重衰减）是防止过拟合的标配 |
| **Frobenius 范数** | $\|\mathbf{X}\|_F = \sqrt{\sum\sum x_{ij}^2}$ | $L_2$ 范数在矩阵上的推广，用于衡量矩阵规模和参数初始化 |

> **范数与深度学习目标**：深度学习本质是求解优化问题——最大化真实数据的概率、最小化预测与真实值的距离。这些"距离"几乎都以范数表达：分类用交叉熵（概率分布间距离），回归用 $L_2$ 损失，正则化用 $L_1$/$L_2$。除了数据本身，范数（以损失函数的形式）是深度学习算法中最重要的设计元素。

## 小结

- 张量是深度学习的数据载体，支持 GPU 加速和自动微分。按元素运算（`+`、`-`、`*`、`/`、`**`）是最基本的操作模式，`*` 不是矩阵乘法。
- 广播机制让不同形状的张量在按元素运算时自动扩展，内存高效且无处不在。
- 数据预处理将原始数据转化为张量：`pandas` 读取 → 缺失值填补/删除 → 独热编码 → 张量转换。
- 标量 → 向量 → 矩阵 → 张量构成线性代数对象的层级。矩阵乘法是神经网络前向传播的核心计算。
- $L_1$ 范数鼓励稀疏性，$L_2$ 范数有良好可微性，两者是正则化的基石。Frobenius 范数将 $L_2$ 推广到矩阵。
