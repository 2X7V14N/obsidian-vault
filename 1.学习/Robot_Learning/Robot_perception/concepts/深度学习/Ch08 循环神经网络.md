# Ch08 循环神经网络

> 来源：《动手学深度学习 2.0》第 8 章（8.1~8.7 完整）

从 Ch03 到 Ch07，我们处理的都是**独立同分布**的数据——每张图片都是独立样本，图像之间没有顺序关系。但现实世界的数据大量是**序列**：股票价格、语音信号、文本、视频帧、地震余震。这些数据有一个共同特点——**顺序就是信息本身**。"狗咬人"和"人咬狗"由完全相同的字组成，但意义天差地别；把一段音乐的音符打乱，它就不再是音乐了。

第 8 章引入**循环神经网络（RNN）**，它通过"隐状态"这一机制，让网络能够记住过去，从而处理任意长度的序列。这是从"静态数据"到"动态时序"的关键跨越。

---

## 8.1 序列模型：处理顺序数据

### 序列的普遍性

序列数据无处不在：电影评分随时间的漂移（奥斯卡获奖后评分上升的"锚定效应"）、用户的作息习惯、股价预测、地震余震的相关性。它们的共同点是：**时间步 $t$ 的观测依赖之前所有时间步的历史**。

序列建模的核心问题是估计条件概率：

$$
x_t \sim P(x_t \mid x_{t-1}, \ldots, x_1)
$$

但这里有一个根本困难：随着 $t$ 增长，输入 $x_{t-1}, \ldots, x_1$ 的长度不断增加。我们需要**近似方法**。

### 两种解决策略

**自回归模型（Autoregressive Model）**：假设当前值只依赖最近 $\tau$ 个观测，而非全部历史。参数数量固定，可以用 Ch03 的线性回归或 MLP 训练。这是"截断历史"的策略。

**隐变量自回归模型（Latent Autoregressive Model）**：维护一个不断更新的"总结" $h_t$，它编码了所有历史信息：

$$
\hat{x}_t = P(x_t \mid h_t), \quad h_t = g(h_{t-1}, x_{t-1})
$$

![[attachments/sequence-model.svg]]

$h_t$ 从未被直接观测到，它是对过去信息的压缩。**RNN 就是隐变量自回归模型的具体实现**——隐状态 $h_t$ 就是那个"总结"。

### 关键概念

**马尔可夫模型**：如果 $P(x_t \mid x_{t-1}, \ldots, x_1) = P(x_t \mid x_{t-1})$，则序列满足一阶马尔可夫条件。高阶马尔可夫模型可以用 $\tau$ 阶近似。

**内插 vs 外推**：在已有观测之间估计（内插）远比预测未来（外推）容易。多步预测会**误差累积**——每一步的预测误差会作为输入进入下一步，误差像滚雪球一样放大。这正是序列预测的根本难点。

### 单步 vs 多步预测

在正弦波 + 噪声的序列上训练一个 MLP 自回归模型（$\tau = 4$），会发现：

- **单步预测**（用真实值预测下一时刻）：效果很好，几乎完美贴合
- **多步预测**（用模型自己的预测递归预测）：几个时间步后迅速衰减为常数

这就是误差累积的直观体现。$k$ 步预测的误差会随着 $k$ 增大而指数放大。

## 8.2 文本预处理：把文字变成数字

文本是最常见的序列数据形式。要让模型处理文本，需要四个步骤：

1. **加载**：将文本读入内存
2. **词元化（Tokenization）**：将文本拆分为词元（单词或字符）
3. **构建词表（Vocabulary）**：将词元映射到数字索引
4. **转换**：将文本转换为数字索引序列

### 词元化

```python
def tokenize(lines, token='word'):
    if token == 'word':
        return [line.split() for line in lines]   # 按单词
    elif token == 'char':
        return [list(line) for line in lines]     # 按字符
```

单词级词元化保留语义但词表大；字符级词元化词表小（只有几十个字符）但序列更长。

### 词表

词表（Vocabulary）是"词元 → 索引"的映射字典，按词频降序分配索引。高频词获得小索引，低频词可以过滤掉（`min_freq` 参数）。所有未见过的词元映射到 `<unk>`（索引 0）。

```python
vocab = Vocab(tokens)
# [('<unk>', 0), ('the', 1), ('i', 2), ('and', 3), ...]
```

## 8.3 语言模型与数据集

### 语言模型

语言模型的目标是估计一个词元序列的联合概率：

$$
P(x_1, x_2, \ldots, x_T) = \prod_{t=1}^{T} P(x_t \mid x_1, \ldots, x_{t-1})
$$

用链式法则分解。理想的语言模型可以生成自然文本、解决语音识别的歧义（"to recognize speech" vs "to wreck a nice beach"）。

### n 元语法：经典但受限

**n 元语法（n-gram）** 用马尔可夫假设截断依赖：一元语法假设词独立，二元语法只看前一个词，三元语法看前两个词。它的问题是**维数灾难**——$n$ 越大，可能组合越多（词表 $\mathcal{V}$ 有 $|\mathcal{V}|^n$ 种），绝大多数组合在数据中从未出现。

**拉普拉斯平滑**给所有计数加一个小常数来避免零概率，但正如齐普夫定律所示——这注定失败。

### 齐普夫定律

![[attachments/timemachine-5gram.svg]]

词频满足幂律分布：第 $i$ 常见的词频 $n_i \propto \frac{1}{i^\alpha}$。双对数坐标下是一条直线。这意味着**低频词是海量的**——用计数和平滑来建模它们会严重高估尾部。这为深度学习语言模型提供了根本动机：神经网络可以**泛化**到未见过的组合，而计数模型不能。

### 读取长序列数据

序列可以任意长（整本《时光机器》有 17 万字符），需要切成固定长度的小批量子序列。两种策略：

- **随机采样**：随机起始偏移，子序列在原始序列中不保证相邻。每个 batch 重新初始化隐状态。
- **顺序分区**：子序列按原始顺序相邻。上一个 batch 的隐状态可以传递给下一个 batch（但需要 `detach` 截断梯度）。

![[attachments/timemachine-5gram.svg]]

## 8.4 循环神经网络：带记忆的神经网络

### 隐状态 vs 隐藏层

这是初学者最容易混淆的概念。**隐藏层**是神经网络中位于输入和输出之间的层；**隐状态**是 RNN 在每个时间步维护的"记忆"，它编码了到当前时间步为止的序列历史。两者是截然不同的概念。

### 有隐状态的循环计算

无隐状态的 MLP：$\mathbf{H} = \phi(\mathbf{X} \mathbf{W}_{xh} + \mathbf{b}_h)$——每个输入独立处理。

有隐状态的 RNN：

$$
\mathbf{H}_t = \phi(\mathbf{X}_t \mathbf{W}_{xh} + \mathbf{H}_{t-1} \mathbf{W}_{hh} + \mathbf{b}_h)
$$

与 MLP 相比，多了一项 $\mathbf{H}_{t-1} \mathbf{W}_{hh}$——前一个时间步的隐状态。这实现了 Ch08.1 中的隐变量自回归模型 $h_t = g(h_{t-1}, x_{t-1})$。因为计算是"循环"的（当前步的隐状态用于下一步的计算），所以叫**循环**神经网络。

![[attachments/rnn.svg]]

输出层：$\mathbf{O}_t = \mathbf{H}_t \mathbf{W}_{hq} + \mathbf{b}_q$

**关键性质**：RNN 的参数（$\mathbf{W}_{xh}, \mathbf{W}_{hh}, \mathbf{W}_{hq}$）在**所有时间步共享**。无论序列多长，参数数量不变——这就是 RNN 能处理任意长度序列的原因。

### 字符级语言模型

用 RNN 预测下一个字符。输入序列 "machin"，标签 "achine"（整体右移一位）：

![[attachments/rnn-train.svg]]

每个时间步的输出经过 softmax + 交叉熵计算损失，所有时间步的损失求和。

### 困惑度（Perplexity）

如何度量语言模型好坏？用**困惑度**：

$$
\text{perplexity} = \exp\left(-\frac{1}{n} \sum_{t=1}^{n} \log P(x_t \mid x_{t-1}, \ldots, x_1)\right)
$$

困惑度的直观理解："下一个词元的实际选择数的调和平均数"。完美模型的困惑度 = 1；均匀随机猜测的困惑度 = 词表大小。困惑度越低，模型越好。

## 8.5 从零实现 RNN

### 独热编码

把词元索引转换为向量。词表有 $N$ 个词元，索引 $i$ 的独热向量是长度为 $N$、第 $i$ 位为 1 的向量。独热编码是最简单的词元表示，但没有语义信息（"cat" 和 "feline" 的独热向量完全正交）——这是后面词嵌入要解决的问题。

### RNN 前向传播

```python
def rnn(inputs, state, params):
    W_xh, W_hh, b_h, W_hq, b_q = params
    H, = state
    outputs = []
    for X in inputs:   # 逐时间步循环
        H = torch.tanh(torch.mm(X, W_xh) + torch.mm(H, W_hh) + b_h)
        Y = torch.mm(H, W_hq) + b_q
        outputs.append(Y)
    return torch.cat(outputs, dim=0), (H,)
```

用 `tanh` 作为激活函数（输出均值为 0，适合隐状态的循环传播）。

### 梯度裁剪：防止梯度爆炸

RNN 在 $T$ 个时间步上展开，反向传播产生长度为 $O(T)$ 的矩阵乘法链。当 $T$ 大时，梯度可能爆炸。**梯度裁剪**（Gradient Clipping）是简单有效的应对方法：

$$
\mathbf{g} \leftarrow \min\left(1, \frac{\theta}{\|\mathbf{g}\|}\right) \mathbf{g}
$$

如果梯度范数超过阈值 $\theta$，就按比例缩小，保持方向不变。它快速修复梯度爆炸，但不能应对梯度消失。

### 预测：预热期

生成文本时，先用用户提供的前缀（prefix）"预热"隐状态——把前缀字符逐一喂给模型但不生成输出，让隐状态积累上下文。预热结束后，用最后一个字符的预测（argmax）作为下一步输入，递归生成。

### 训练结果

在《时光机器》上训练字符级 RNN（500 epoch，512 隐藏单元），困惑度降到 1.0 左右，能生成：

```
time traveller for so it will be convenient to speak of himwas e
travelleryou can show black is white by argument said filby
```

生成的文本虽然不连贯，但已经学会了拼写和基本的语法结构——这正是字符级语言模型的意义。

## 8.6 简洁实现

PyTorch 提供 `nn.RNN`：

```python
rnn_layer = nn.RNN(len(vocab), num_hiddens)  # 单隐藏层 RNN
state = torch.zeros((1, batch_size, num_hiddens))
Y, state_new = rnn_layer(X, state)
```

`rnn_layer` 只处理隐状态的循环计算，返回每个时间步的隐状态 `Y` 和最终隐状态 `state_new`。还需要自己加一个输出层（`nn.Linear`）把隐状态映射到词表大小。

简洁实现的优势：代码更短，且高级 API 的循环计算用 C++/CUDA 优化，训练速度大幅提升（从零实现的 ~67k 词元/秒 → 简洁实现的 ~400k 词元/秒）。

## 8.7 通过时间反向传播（BPTT）

### 为什么 RNN 训练难？

RNN 的反向传播 = 在时间维度上展开的反向传播（Backpropagation Through Time）。核心问题是隐状态梯度的递归计算：

$$
\frac{\partial L}{\partial \mathbf{h}_t} = \mathbf{W}_{hh}^{\top} \frac{\partial L}{\partial \mathbf{h}_{t+1}} + \mathbf{W}_{qh}^{\top} \frac{\partial L}{\partial \mathbf{o}_t}
$$

展开后，$\frac{\partial L}{\partial \mathbf{h}_t}$ 包含 $\mathbf{W}_{hh}^{\top}$ 的 $(T-t)$ 次幂：

$$
\frac{\partial L}{\partial \mathbf{h}_t} = \sum_{i=t}^{T} (\mathbf{W}_{hh}^{\top})^{T-i} \mathbf{W}_{qh}^{\top} \frac{\partial L}{\partial \mathbf{o}_{T+t-i}}
$$

这就是**梯度消失/爆炸的数学根源**（与 Ch04 的 4.9 节一脉相承）：$\mathbf{W}_{hh}$ 的特征值小于 1 时，高次幂消失（梯度消失）；大于 1 时，高次幂发散（梯度爆炸）。

![[attachments/rnn-bptt.svg]]

### 三种梯度计算策略

![[attachments/truncated-bptt.svg]]

1. **完全计算**：计算全部 $T$ 个时间步的梯度。计算不可行，且对长序列数值不稳定——实践中几乎不用。
2. **常规截断**：在 $\tau$ 步后截断（就是我们用 `detach` 做的）。是真实梯度的近似，偏向短期依赖，训练更稳定。**实践中最常用**。
3. **随机截断**：用随机变量在期望意义上保持正确，但截断长度随机。理论上优雅，实践中不比常规截断好。

> **截断 = 轻量正则化**：截断让模型只关注短期交互，这恰好符合大多数序列任务的真实需求——当前的预测主要受最近的上下文影响，遥远的历史贡献微乎其微。

## 小结

第 8 章将深度学习从"静态样本"扩展到"时序数据"：

- **序列模型**：估计 $P(x_t \mid x_{t-1}, \ldots, x_1)$。自回归模型截断历史，隐变量自回归模型用隐状态总结历史。多步预测误差累积。
- **文本预处理**：词元化 + 词表 + 索引化，把文字变成数字序列。齐普夫定律说明计数模型不可行，深度学习是必然选择。
- **RNN 核心**：$\mathbf{H}_t = \phi(\mathbf{X}_t \mathbf{W}_{xh} + \mathbf{H}_{t-1} \mathbf{W}_{hh} + \mathbf{b}_h)$。隐状态承载记忆，参数跨时间步共享。困惑度是标准评价指标。
- **训练技巧**：梯度裁剪防止爆炸；顺序分区 + detach 截断梯度；预热期改善生成质量。
- **BPTT**：RNN 的反向传播沿时间展开，梯度含 $\mathbf{W}_{hh}^k$ 项——这是梯度消失/爆炸的根源，截断是标准应对。
