# 深度学习课程学习计划

> 课程来源：[李沐《动手学深度学习》Bilibili](https://www.bilibili.com/video/BV1EY6FBwE8P) | 实际 197 集
>
> 定位：以机器人感知为主，为后续计算机视觉和多模态方向保留基础。
>
> ✅ 已完成 🔄 进行中 ⬜ 未开始

---

## 主线课程（必看，共 8 个阶段）

| 阶段 | 集数 | 主题 | 状态 |
|:----:|:----:|------|:----:|
| 1 | 6–18 | 数据操作、线性代数、矩阵计算、自动求导 | 🔄 |
| 2 | 19–29 | 线性回归、基础优化、Softmax 回归 | 🔄 |
| 3 | 32–49 | 感知机、多层感知机、过拟合、正则化、初始化与激活函数 | ✅ |
| 4 | 53–60 | 模型构造、参数管理、自定义层、文件读写、GPU | ✅ |
| 5 | 63–98 | CNN 基础与经典卷积网络（LeNet→ResNet） | 🔄 |
| 6 | 111–116 | 数据增广与微调 | ✅ |
| 7 | 122–144 | 目标检测、锚框、SSD、语义分割、FCN | ✅ |
| 8 | 181–195 | 注意力机制、自注意力、Transformer | ✅ |

**推荐观看顺序**：`6–18 → 19–29 → 32–49 → 53–60 → 63–98 → 111–116 → 122–144 → 181–195`

---

## 选看内容

| 集数 | 主题 | 什么时候看 |
|:----:|------|-----------|
| 1–5 | 课程介绍、环境安装 | 初次接触或需重配环境时 |
| 30–31 | CUDA、PyTorch 和云端 GPU | 需要 GPU 训练时 |
| 50–52 | 房价预测实战 | 想了解完整项目流程时 |
| 100–110 | 多 GPU、分布式训练 | 训练大模型或关注工程效率时 |
| 117–121 | 图像分类竞赛案例 | 想增加视觉项目经验时 |
| 196–197 | BERT 与代码实现 | 准备深入多模态或语言模型时 |

## 阶段性完成标准

| 完成节点 | 能力 |
|---------|------|
| 阶段 1–4（集 6–60） | 独立编写简单的 PyTorch 模型和训练循环 |
| 阶段 5–6（集 63–116） | 理解并修改图像分类、数据增广和微调代码 |
| 阶段 7（集 122–144） | 理解目标检测和语义分割模型的基本结构 |
| 阶段 8（集 181–195） | 读懂注意力机制和 Transformer 的基础实现 |

> 不要看完再动手。完成阶段 1–4 后开始练基础模型；完成 5–6 后做图像分类；完成 7 后做检测分割；最后学 8 为多模态做准备。
