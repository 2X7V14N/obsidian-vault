# Ch07 现代卷积神经网络

> 来源：《动手学深度学习 2.0》第 7 章（7.1~7.7，无 7.3）

Ch06 的 LeNet 在 1989 年证明了卷积神经网络可以端到端训练，但在随后的二十多年里，CNN 始终不是主流。直到 2012 年，AlexNet 在 ImageNet 上以碾压性的优势夺冠，计算机视觉一夜之间从"手工特征+SVM"变成了"深度学习统领一切"。本章从 AlexNet 出发，沿着"更深、更宽、更聪明"的演进轨迹，依次讲解 VGG、GoogLeNet、批量规范化、ResNet 和 DenseNet——这七项创新共同构成了现代 CNN 的"标准工具箱"。

---

## 7.1 AlexNet：深度 CNN 的奠基者

### 2012 年之前：手工特征的时代

在 AlexNet 之前，计算机视觉的主流范式是**两阶段流水线**：先用 SIFT、SURF 或 HOG 等手工设计的特征提取器从图像中抽取"有意义"的信息，再将这些特征送入 SVM 或其它分类器。你并不"训练"一个端到端系统——你训练的是一个分类器，而特征提取器是固定不变的。计算机视觉研究者普遍相信：推动领域进步的是**更好的特征**，而不是更好的学习算法。

深度学习阵营的研究者——Hinton、LeCun、Bengio 等人——持有相反的观点：**特征本身也应该被学习**。但直到 2012 年，这个信念缺乏有力的证据。原因很具体：没有足够大的标注数据集、没有足够强的硬件、缺乏有效的训练技巧（好的初始化、ReLU、Dropout）。

### 两个缺失的成分

**数据**。2009 年，李飞飞团队发布了 ImageNet——100 万张图像、1000 个类别，前所未有。它直接推动了大规模视觉识别的竞赛。

**硬件**。GPU 拥有数百到数千个简单的小核心，擅长做 $4 \times 4$ 矩阵乘法——恰好就是卷积层的核心操作。2012 年，Alex Krizhevsky 和 Ilya Sutskever 用两块 NVIDIA GTX580 GPU（各 3GB 显存）实现了快速的 GPU 卷积，他们的 `cuda-convnet` 代码库此后多年是行业标准。

> **GPU vs CPU 的本质差异**：一个 CPU 核心主频高、缓存大、擅长复杂分支预测——但只有 4~64 核，昂贵且功耗高。一个 GPU 有 100~1000 个弱核心，每个时钟不到 1GHz，但靠数量取胜。NVIDIA Ampere 架构提供 312 TFLOPS，而 CPU 还没突破 1 TFLOPS——差距来自物理定律：功耗随频率二次方增长，所以多弱核比少强核更节能。

### AlexNet 架构

![[attachments/alexnet.svg]]

AlexNet 由 8 层组成——5 个卷积层 + 3 个全连接层。和 LeNet 相比：

| 对比维度 | LeNet | AlexNet |
|---------|-------|---------|
| 层数 | ~5 | 8 |
| 激活函数 | Sigmoid | **ReLU** |
| 正则化 | 无 | **Dropout**（全连接层） |
| 数据增强 | 无 | 翻转、裁剪、变色 |
| 卷积核 | 5×5 单一 | 11×11 → 5×5 → 3×3 |
| GPU | 不需要 | 双 GPU（原版） |

逐层数据流（输入 $224 \times 224$）：

```
Conv(1→96, 11×11, s=4) + ReLU → 54×54×96
MaxPool(3×3, s=2) → 26×26×96
Conv(96→256, 5×5, p=2) + ReLU → 26×26×256
MaxPool(3×3, s=2) → 12×12×256
Conv(256→384, 3×3, p=1) + ReLU → 12×12×384
Conv(384→384, 3×3, p=1) + ReLU → 12×12×384
Conv(384→256, 3×3, p=1) + ReLU → 12×12×256
MaxPool(3×3, s=2) → 5×5×256
Flatten → 6400
Linear(6400→4096) + ReLU + Dropout(0.5)
Linear(4096→4096) + ReLU + Dropout(0.5)
Linear(4096→10)
```

**三个设计亮点**：（1）大卷积核 11×11 在第一层捕获大尺度结构（ImageNet 图像比 MNIST 大得多）；（2）中间的三个 $3 \times 3$ 卷积层连续堆叠且不降采样——相当于增大了感受野而不增加参数量；（3）两个 4096 维全连接层拥有近 1GB 参数——所以原始论文用了双 GPU 拆分存储。

![[attachments/filters.png]]

> AlexNet 第一层学到的滤波器令人惊叹：有各种方向的边缘检测器、颜色检测器、频率检测器——它们和手工设计的 Gabor 滤波器惊人相似，但完全是**从数据中自动涌现的**。这正是"学特征"战胜"手工特征"的最直观证据。

### 训练与性能

在 Fashion-MNIST 上（resize 到 224×224）：10 epoch 后测试精度约 **88~89%**，比 LeNet 的 ~82% 有显著提升。代价是计算量大得多——每秒钟只能处理约 4000 个样本（LeNet 约 55000）。

## 7.2 VGG：块设计的艺术

AlexNet 证明了深度有用，但它没有提供**可复用的设计模板**。VGG（2014，牛津大学视觉几何组）的最大贡献是引入**VGG 块**的概念——将网络从"手工编排每一层"升级为"重复使用标准化的积木块"。这种模块化思维直接启发了后续所有 CNN 架构。

### VGG 块：统一的 $3 \times 3$ 卷积

一个 VGG 块由以下序列组成：

```
[ n 个 Conv2d(3×3, padding=1) + ReLU ] → MaxPool2d(2×2, stride=2)
```

核心设计原则非常简单：**只使用 $3 \times 3$ 卷积核（填充 1 保持尺寸不变），后接 $2 \times 2$ 最大池化（分辨率减半），同时每过一个块就将通道数翻倍**。多个 $3 \times 3$ 卷积堆叠等价于一个更大的卷积核（两个 $3 \times 3$ = 一个 $5 \times 5$ 的感受野，三个 $3 \times 3$ = 一个 $7 \times 7$），但参数更少、非线性更多——这是 VGG 性能出色的数学根源。

```python
def vgg_block(num_convs, in_channels, out_channels):
    layers = []
    for _ in range(num_convs):
        layers.append(nn.Conv2d(in_channels, out_channels, kernel_size=3, padding=1))
        layers.append(nn.ReLU())
        in_channels = out_channels
    layers.append(nn.MaxPool2d(kernel_size=2, stride=2))
    return nn.Sequential(*layers)
```

### VGG-11：5 个块 + 3 个全连接

![[attachments/vgg.svg]]

```python
conv_arch = ((1, 64), (1, 128), (2, 256), (2, 512), (2, 512))
# 5 个块：前两块各 1 个卷积，后三块各 2 个卷积 → 共 8 卷积层 + 3 FC = 11 层
```

数据流（$224 \times 224$）：

```
Block1: Conv×1(64) → 224×224 → Pool → 112×112×64
Block2: Conv×1(128) → 112×112 → Pool → 56×56×128
Block3: Conv×2(256) → 56×56 → Pool → 28×28×256
Block4: Conv×2(512) → 28×28 → Pool → 14×14×512
Block5: Conv×2(512) → 14×14 → Pool → 7×7×512
Flatten → 25088
FC(4096) + ReLU + Dropout
FC(4096) + ReLU + Dropout
FC(10)
```

> **VGG 的根本问题**：三个全连接层（尤其是第一个 25088→4096）占用了海量参数和计算——VGG-16 的总参数约 138M，其中 FC 层占了约 120M。这既是计算瓶颈，也是后来的 GoogLeNet 和 ResNet 着力解决的问题。

由于 VGG 比 AlexNet 更重，训练时通常将通道数除以 4（`ratio=4`）来适配 Fashion-MNIST。即便如此，VGG 在测试精度（~92%）上仍然稳定超越 AlexNet（~89%）。

## 7.4 GoogLeNet：并行的智慧

2014 年 ImageNet 冠军是 GoogLeNet（致敬 LeNet），它的核心创新是**Inception 块**——在同一层内并行运行多种尺寸的卷积，让网络自己"选择"哪种尺寸最合适。

### Inception 块：四条并行路径

![[attachments/inception.svg]]

一个 Inception 块同时执行四条路径，最后在通道维度上拼接：

| 路径 | 操作 | 作用 |
|------|------|------|
| 1 | $1 \times 1$ 卷积 | 提取逐点特征 |
| 2 | $1 \times 1$ → $3 \times 3$ 卷积 | $1 \times 1$ 先降维再在 $3 \times 3$ 提取局部模式 |
| 3 | $1 \times 1$ → $5 \times 5$ 卷积 | $1 \times 1$ 先降维再在 $5 \times 5$ 提取更大范围 |
| 4 | $3 \times 3$ MaxPool → $1 \times 1$ 卷积 | 池化捕获空间最大值，再接 $1 \times 1$ 调通道 |

**$1 \times 1$ 卷积在这里扮演了关键的角色——降维**。路径 2 和 3 先用 $1 \times 1$ 卷积把通道数压缩到原来的 1/2~1/12，再执行昂贵的 $3 \times 3$ 或 $5 \times 5$ 卷积。假设输入有 256 个通道，直接做 $5 \times 5 \times 128$ 卷积需要 $256 \times 5 \times 5 \times 128$ 次乘法；改成 $1 \times 1 \times 32$ → $5 \times 5 \times 128$ 后，计算量降到 $256 \times 1 \times 1 \times 32 + 32 \times 5 \times 5 \times 128$——大约减少了 5 倍。

> **这个名字很有趣**：Inception 得名于电影《盗梦空间》（Inception），片中有一句台词"We need to go deeper"——Google 的研究者们也用这个名字表达他们让网络"更深"的决心。

### GoogLeNet 整体架构

![[attachments/inception-full.svg]]

GoogLeNet 由 9 个 Inception 块堆叠而成，分为 5 个模块：

| 模块 | 内容 | 输出（$96 \times 96$ 输入） |
|------|------|:---:|
| b1 | Conv(7×7) + MaxPool | $24 \times 24 \times 64$ |
| b2 | $1 \times 1$→$3 \times 3$ + MaxPool | $12 \times 12 \times 192$ |
| b3 | 2× Inception + MaxPool | $6 \times 6 \times 480$ |
| b4 | 5× Inception + MaxPool | $3 \times 3 \times 832$ |
| b5 | 2× Inception + GlobalAvgPool | $1024$ 维向量 |
| Output | Linear(1024→10) | 10 类 |

**关键创新：用全局平均池化取代全连接层**。在 b5 的最后一个 Inception 块之后，GoogLeNet 使用 `GlobalAvgPool` 将每个通道的空间维度直接压到 1×1，得到 1024 维向量送入分类器。这个设计消除了 VGG 中庞大的 FC 参数（AlexNet/VGG 的 FC 层占模型参数的 90%+），大幅减少了参数量，同时也增强了泛化能力——像素空间的平均值天然具有平移不变性。

## 7.5 批量规范化：训练深网的稳定器

深层网络的训练面临着"各层输入分布不断漂移"的困扰——前面层的参数一更新，后面层接收到的信号分布就变了，学习率必须保守，收敛极慢。**批量规范化（Batch Normalization, BN）** 在每一层的激活之前进行标准化，让训练可以用**大得多的学习率**快速收敛，同时自带正则化效果。它是让 100+ 层网络得以训练的关键技术。

### 原理：标准化 + 可学习的缩放与偏移

对一个小批量 $\mathcal{B}$，批量规范化的计算分三步：

1. **计算批统计量**：$\hat{\mu}_\mathcal{B} = \frac{1}{|\mathcal{B}|} \sum_{\mathbf{x} \in \mathcal{B}} \mathbf{x}$，$\hat{\sigma}_\mathcal{B}^2 = \frac{1}{|\mathcal{B}|} \sum (\mathbf{x} - \hat{\mu}_\mathcal{B})^2 + \epsilon$
2. **标准化**：$\hat{\mathbf{x}} = \frac{\mathbf{x} - \hat{\mu}_\mathcal{B}}{\hat{\sigma}_\mathcal{B}}$
3. **缩放与偏移**：$\text{BN}(\mathbf{x}) = \gamma \odot \hat{\mathbf{x}} + \beta$

其中 $\gamma$ 和 $\beta$ 是**可学习的参数**——它们让网络可以恢复任何想要的分布（如果 $\gamma = \sigma$，$\beta = \mu$，则 BN 退化为恒等映射）。$\epsilon$ 防止除零。

### 全连接层 vs 卷积层的 BN

- **全连接层**：在特征维度上做 BN。形状 $(m, d)$，对 $d$ 个特征各自计算均值和方差。
- **卷积层**：在通道维度上做 BN。形状 $(m, c, h, w)$，对每个通道的所有 $m \cdot h \cdot w$ 个元素一起计算均值和方差。每个通道有自己独立的 $\gamma$ 和 $\beta$（都是标量）。

### 训练 vs 推理

BN 在训练和推理时的行为不同：

- **训练**：使用当前小批量的 $\hat{\mu}$ 和 $\hat{\sigma}$，同时用指数移动平均更新全局统计量。
- **推理**：使用训练期间累积的全局均值和方差（移动平均），不再依赖批量统计。

```python
# PyTorch 框架实现只需一行
nn.BatchNorm2d(num_channels)  # 卷积层
nn.BatchNorm1d(num_features)  # 全连接层
```

### BN + LeNet

将 BN 插入 LeNet 的标准位置——Conv/FC 之后、激活函数之前。效果惊人：学习率可以从 0.1 提到 **1.0**（10 倍！），训练速度大幅加快（~32000 examples/sec vs 原来 ~55000 examples/sec 但后者是简单得多的 LeNet 5 层网络）。

> **关于"内部协变量偏移"的争议**：原论文将 BN 的有效性归因于"减少内部协变量偏移（Internal Covariate Shift）"，但这个解释后来受到广泛质疑——Santurkar 等人的研究发现 BN 的实际作用是**让损失曲面更平滑**，从而允许更大的学习率。这个争议在 2017 年 NeurIPS 上引发了对"深度学习理论过度宣称"的大讨论。实用主义的结论是：**BN 有效，但原因可能不是原论文声称的那个。**

## 7.6 ResNet：跳跃连接革命

### 为什么更深不一定更好？

直觉上，越深的网络应能学得越好。但事实上，**更深的网络训练误差反而更高**——这不是过拟合（测试误差也高），而是优化困难。何恺明等人用严格的"函数类嵌套"论证来解释：

如果我们有一个较浅的网络，再给它增加额外的层，**至少应能学出恒等映射**（$f(\mathbf{x}) = \mathbf{x}$）来保证性能不退化。但 SGD 无法轻易找到这个解——让一堆权重精确地学成"什么都不做"非常困难。所以我们需要一种架构设计，让**恒等映射成为默认行为**。

![[attachments/functionclasses.svg]]

### 残差块：学习残差而非原始函数

![[attachments/residual-block.svg]]

传统卷积块试图直接学习目标映射 $f(\mathbf{x})$。残差块则改为学习**残差** $f(\mathbf{x}) - \mathbf{x}$，然后通过跳跃连接将输入加回来：$\mathbf{y} = \mathcal{F}(\mathbf{x}) + \mathbf{x}$。

关键洞察：如果最优函数接近恒等映射，残差 $\mathcal{F}(\mathbf{x}) \approx 0$ 是很容易学到的——只需把权重推向零。而传统块需要精确地学出 $\mathbf{x}$ 本身，难得多。**加法门（element-wise addition）让梯度可以沿着跳跃连接直接回流到浅层**——这是 ResNet 能训练 152 层的物理基础。

#### 为什么残差有效（一）：前向传播——把"重写"变成"微调"

普通网络要求权重层**直接学习目标特征** $H(\mathbf{x})$；残差网络让权重层只学**残差（变化量）** $\mathcal{F}(\mathbf{x}) = H(\mathbf{x}) - \mathbf{x}$。

**用具体数字理解**——假设目标是把分数从 80 分提升到 85 分：

| | 输入 $\mathbf{x}$ | 目标 $H(\mathbf{x})$ |
|:--:|:---:|:---:|
| 数值 | 80（目前已有的水平） | 85（最终需要的输出） |

**普通网络：「从头重写」**

- 做法：权重层要**直接学习整个目标函数** $H(\mathbf{x})$
- 难度：网络必须凭空算出 **85** 这个完整的数值
- 风险：层数很深、参数初始化不好时，很容易算歪（比如算成 60 分）→ 输出质量反而变差
- **这就是「网络退化」**——网络越深，效果反而不如浅层网络

**残差网络：「只学差值」**

- 做法：输入 $\mathbf{x} = 80$ 原封不动地通过旁边那条「备用通道」（跳跃连接）直接送到终点；权重层 $\mathcal{F}(\mathbf{x})$ 只专注计算**微调量**：

$$
\mathcal{F}(\mathbf{x}) = H(\mathbf{x}) - \mathbf{x} = 85 - 80 = +5
$$

- 最终输出：$\mathcal{F}(\mathbf{x}) + \mathbf{x} = 5 + 80 = 85$ ✅

**两个优势**：

1. **降低拟合难度**：比起在一个很大且复杂的数值空间里瞎摸索，只学增量 $\Delta = +5$ 要简单容易得多
2. **兜底机制**：如果这一层实在太深、学不出任何好东西（相当于 $+0$），它只需要把权重设为 0（即 $\mathcal{F}(\mathbf{x}) = 0$），输出就自动变成 $0 + \mathbf{x} = \mathbf{x}$（保持原来的 80 分不变）

> 这就是**恒等映射（Identity Mapping）**。残差连接确保了：**即使深层网络没有学到新知识，至少也能「复制」浅层网络的效果，绝不会越学越差。**

#### 为什么残差有效（二）：反向传播——梯度高速公路

残差结构的输出为 $\mathbf{y} = \mathcal{F}(\mathbf{x}) + \mathbf{x}$。对输入求导：

$$
\frac{\partial \mathbf{y}}{\partial \mathbf{x}} = \frac{\partial \mathcal{F}(\mathbf{x})}{\partial \mathbf{x}} + \mathbf{1}
$$

**注意这个关键的 $+1$！**

> [!info] 严格说，向量形式下这里是单位矩阵
> 标量情形下是 $+1$；向量情形下，$\partial \mathbf{y}/\partial \mathbf{x} = \partial \mathcal{F}/\partial \mathbf{x} + \mathbf{I}$（$\mathbf{I}$ 为单位矩阵）。直观上都起到「保留原信号」的作用。

在反向传播展开链式法则连乘时，由于每一层都包含 $+1$ 项，导数不再是**纯粹的矩阵相乘**（$\prod \mathbf{W}$），而是变成了类似这样的形式：

$$
\text{总梯度} = \underbrace{\text{传统连乘项}}_{\prod \mathbf{W}} + \ 1
$$

**关键**：就算前面的「传统连乘项」因为网络太深、或 $\mathbf{W} < 1$ 而衰减到了 0，由于常数 $1$ 的存在，**梯度信号依然能以 $1.0$ 的系数不衰减地无损直通最前层**。

> **这就是 ResNet 能训练 152 层的物理基础**——它给梯度修了一条「高速公路」，绕开了层层衰减的普通通道。
>
> **和 [[Ch04 多层感知机]] 4.9 节对照**：普通深层网络的梯度是 $\prod_i \mathbf{M}^{(i)}$，连乘下指数衰减（消失）或指数增长（爆炸）；残差的 $+1$ 提供了一个**恒为 1 的通路**，让梯度无论多深都能传回浅层。

残差块的 PyTorch 实现：

```python
class Residual(nn.Module):
    def __init__(self, input_channels, num_channels, use_1x1conv=False, strides=1):
        super().__init__()
        self.conv1 = nn.Conv2d(input_channels, num_channels, 3, padding=1, stride=strides)
        self.conv2 = nn.Conv2d(num_channels, num_channels, 3, padding=1)
        self.bn1 = nn.BatchNorm2d(num_channels)
        self.bn2 = nn.BatchNorm2d(num_channels)
        if use_1x1conv:
            self.conv3 = nn.Conv2d(input_channels, num_channels, 1, stride=strides)
        else:
            self.conv3 = None

    def forward(self, X):
        Y = F.relu(self.bn1(self.conv1(X)))
        Y = self.bn2(self.conv2(Y))
        if self.conv3:
            X = self.conv3(X)      # 1×1 卷积调整输入形状以匹配 Y
        Y += X                       # 关键：跳跃连接相加
        return F.relu(Y)
```

![[attachments/resnet-block.svg]]

当通道数或空间分辨率发生变化时，跳跃连接通过 $1 \times 1$ 卷积（`use_1x1conv=True`）来匹配形状。这保证了在任何情况下输入和输出都可以相加。

### ResNet-18 架构

![[attachments/resnet18.svg]]

```python
b1: Conv(7×7, s=2) + BN + ReLU + MaxPool(3×3, s=2)
b2: [ResBlock(64→64)] × 2          # 56×56×64
b3: [ResBlock(64→128, s=2)] × 2    # 28×28×128
b4: [ResBlock(128→256, s=2)] × 2   # 14×14×256
b5: [ResBlock(256→512, s=2)] × 2   # 7×7×512
GlobalAvgPool → 512
Linear(512→10)
```

**18 层 = 1（初始卷积）+ 4×2×2（8 个残差块各含 2 卷积）+ 1（全连接）**。通过增加每个模块中残差块的个数，可以扩展到 ResNet-34、ResNet-50、ResNet-101、ResNet-152。

残差块的设计规范后来成为所有现代 CNN 的标配：Conv → BN → ReLU → Conv → BN → **+ input** → ReLU。这种 "Pre-activation" 设计也被发现比原始的 "Post-activation"（Conv → BN → ReLU → Conv → BN → ReLU → + input）有更好的梯度流动。

在 Fashion-MNIST 上，ResNet-18 的训练精度达到惊人的 **99.7%**，测试精度约 **92.4%**。训练精度几乎完美——残差连接让深网络可以几乎零误差地拟合训练集，同时泛化能力保持强劲。

## 7.7 DenseNet：全部连起来

ResNet 将输入和输出相加：$f(\mathbf{x}) = \mathbf{x} + g(\mathbf{x})$。DenseNet 把这个想法推向极致——不是加，而是**在通道维度上拼接**。

### 从 ResNet 到 DenseNet：泰勒展开的类比

ResNet 将一个函数分解为恒等项 + 残差项，类似于泰勒展开的一阶近似：

$$f(x) = f(0) + f'(0)x$$

DenseNet 则继续这个类比：把每一层都看作一个"高阶项"，然后**把所有阶数拼在一起**：

$$f(x) = [x, f_1(x), f_2([x, f_1(x)]), f_3([x, f_1(x), f_2([x, f_1(x)])]), \ldots]$$

![[attachments/densenet-block.svg]]

实际操作中，DenseNet 的稠密块（Dense Block）内部，每一层的输入是**之前所有层的输出在通道维度上的拼接**。如果输入有 $c$ 个通道、每层输出 $k$ 个通道（$k$ 称为**增长率**），经过 $n$ 层后通道数变为 $c + nk$。

### 稠密块 + 过渡层

![[attachments/densenet.svg]]

```python
def conv_block(input_channels, num_channels):
    return nn.Sequential(
        nn.BatchNorm2d(input_channels), nn.ReLU(),
        nn.Conv2d(input_channels, num_channels, kernel_size=3, padding=1))

class DenseBlock(nn.Module):
    def __init__(self, num_convs, input_channels, num_channels):
        super().__init__()
        layer = []
        for i in range(num_convs):
            layer.append(conv_block(num_channels * i + input_channels, num_channels))
        self.net = nn.Sequential(*layer)

    def forward(self, X):
        for blk in self.net:
            Y = blk(X)
            X = torch.cat((X, Y), dim=1)   # 拼接而非相加
        return X
```

**过渡层**控制复杂度：用 $1 \times 1$ 卷积将通道数减半，再通过平均池化将空间分辨率减半。

```python
def transition_block(input_channels, num_channels):
    return nn.Sequential(
        nn.BatchNorm2d(input_channels), nn.ReLU(),
        nn.Conv2d(input_channels, num_channels, kernel_size=1),
        nn.AvgPool2d(kernel_size=2, stride=2))
```

### DenseNet vs ResNet：核心对比

| 特性 | ResNet | DenseNet |
|------|--------|----------|
| 连接方式 | 元素相加（$+$） | 通道拼接（concat） |
| 特征复用 | 隐式（梯度路径短） | 显式（每一层直接访问所有浅层特征） |
| 参数量 | 标准 | 更少（增长率通常很小，如 $k=32$） |
| 显存消耗 | 低 | **高**（每层都要存所有之前层的输出） |
| 数学类比 | $f(x) = x + g(x)$ | 泰勒展开的高阶项 |

**DenseNet 的核心优势**：由于每一层都直接连接到之前的所有层，梯度可以沿着极其丰富的路径回流——**深层监督**让网络非常容易训练。同时，极小的增长率意味着参数利用率极高。**核心劣势**：通道拼接让显存爆炸——每经过一层，中间结果就堆积更多，必须在反向传播期间全部保留在显存中。

### 架构概要

```
Conv(7×7) + BN + ReLU + MaxPool
DenseBlock(4 conv, k=32) + Transition(通道减半)
DenseBlock(4 conv, k=32) + Transition(通道减半)
DenseBlock(4 conv, k=32) + Transition(通道减半)
DenseBlock(4 conv, k=32)
BN + ReLU + GlobalAvgPool + Linear(→10)
```

## 小结

第 7 章覆盖了从 2012 到 2017 年深度学习在计算机视觉中的五个关键转折：

- **AlexNet（2012）**：CNN 首次在 ImageNet 上碾压传统方法。三大支柱——ReLU、Dropout、GPU。学习到的滤波器与传统手工设计惊人相似，但完全自动涌现。
- **VGG（2014）**：引入块的抽象——统一 $3 \times 3$ 卷积 + 通道翻倍 + 池化减半。简洁但计算量大（FC 层吃掉了大部分参数）。
- **GoogLeNet（2014）**：Inception 块并行运行多种卷积尺寸，$1 \times 1$ 降维是关键效率技巧。全局平均池化取代全连接层是参数削减的先驱。
- **批量规范化（2015）**：标准化 + 可学习缩放。训练更快、学习率可放大 10 倍、自带正则化。虽原论文的"内部协变量偏移"解释被质疑，但技术本身已成为标配。
- **ResNet（2015）**：残差连接——学习残差而非原始映射，使 152 层网络可训练。两个机制：**前向**把"重写目标"变成"只学增量"，且恒等映射作为兜底（权重置 0 即可保底）；**反向**的 $\partial \mathbf{y}/\partial \mathbf{x} = \partial \mathcal{F}/\partial \mathbf{x} + 1$ 提供了恒为 1 的梯度通路，让梯度不衰减地直达浅层。
- **DenseNet（2017）**：将 ResNet 的加法换成通道拼接——每一层直接访问所有之前层的特征。参数利用率极高但显存消耗大。
