# 第4章 双目相机与 RGB-D 相机

> 单目相机只能获得二维投影——深度信息丢失了。要恢复深度，有两种主流方案：用两个相机模拟人眼的**双目视觉**，或主动发射光线测量距离的 **RGB-D 相机**。

## 1. 双目相机模型

### 1.1 结构与原理

双目相机由两个**水平放置、参数相同**的相机组成。左右相机光心的距离称为**基线 `b`**（Baseline），这是双目系统最关键的设计参数。

双目测距的原理与人眼完全一致：同一空间点在左右相机中成像的位置不同（视差），视差越大意味着物体越近。

### 1.2 深度计算

设空间点 `P` 在左右图像中的水平像素坐标分别为 `u_L` 和 `u_R`，**视差**定义为：

$$d = u_L - u_R$$

根据相似三角形关系，深度 `z` 为：

$$z = \frac{f b}{d}$$

其中 `f` 是焦距（像素为单位），`b` 是基线长度。

### 1.3 关键特性

**测距极限**：视差 `d` 的最小理论值是 1 个像素（再小就无法区分了），因此双目能测量的**最大深度**为：

$$z_{max} = f \cdot b$$

基线越长、分辨率越高，就能看得越远。

**精度衰减**：双目深度精度与深度 `z` 的**平方成反比**——距离翻倍，误差变为原来的 4 倍。远处的物体深度估计极不可靠。

**计算代价**：视差计算本身（立体匹配）是双目系统最核心也是最困难的一步——需要在左右图像中找到同一个点，这涉及特征匹配或密集搜索，计算量大且容易出错（如弱纹理区域、重复纹理区域）。

## 2. RGB-D 相机模型

RGB-D 相机不依赖被动视觉，而是**主动发射光线**直接测量深度。同时输出彩色图（RGB）和深度图（Depth），深度图中每个像素的值代表该点到相机的物理距离（单位通常为毫米）。

### 2.1 两种主流技术

| 技术 | 原理 | 代表产品 |
|------|------|---------|
| **结构光** | 发射已知图案的红外光，分析图案在物体表面的变形来计算深度 | Kinect v1、RealSense D400 系列 |
| **飞行时间 (ToF)** | 发射光脉冲，测量往返时间来计算距离 | Kinect v2、iPhone LiDAR |

### 2.2 优点

- **直接获得稠密深度**：不需要像双目那样做复杂的视差匹配，每个像素都有深度值
- **对弱纹理场景鲁棒**：白墙、纯色桌面等双目会失败的区域，RGB-D 依然能测深
- **简化 SLAM 建图**：有了逐像素深度，单帧就能生成局部点云

### 2.3 缺点

- **功耗大**：需要主动发射光线
- **量程有限**：通常最远几米，且误差随距离增加而增大
- **怕阳光**：环境光中的红外成分会干扰结构光和 ToF，**室外基本不可用**
- **多机互扰**：多个 RGB-D 相机同时工作会互相干扰

## 3. 单目 vs 双目 vs RGB-D：选型指南

| | 单目 | 双目 | RGB-D |
|--|:--:|:--:|:--:|
| 深度获取 | 无法直接获取 | 视差计算（被动） | 直接测量（主动） |
| 室外可用 | ✅ | ✅ | ❌（红外干扰） |
| 远距离 | — | 精度随距离急剧下降 | 量程有限（几米） |
| 功耗 | 低 | 低 | 高 |
| 弱纹理场景 | — | ❌ | ✅ |
| 成本 | 低 | 中 | 中高 |

## 4. 从图像生成点云

如果已知深度图和相机内参，可以恢复每个像素的三维坐标。步骤：

1. 从深度图中获取像素 `(u, v)` 的深度值 `d`
2. 用内参 K 的逆矩阵，将像素坐标反投影到相机坐标系：`P_c = d · K⁻¹ · (u, v, 1)^T`
3. 如果有相机外参 T，再变换到世界坐标系：`P_w = T · P_c`
4. 从彩色图中获取该像素的颜色，组合成带颜色的 3D 点

这适用于双目生成的视差深度图，也适用于 RGB-D 自带的深度图。在 PCL 中可以用 `PointCloud` 结构存储。
