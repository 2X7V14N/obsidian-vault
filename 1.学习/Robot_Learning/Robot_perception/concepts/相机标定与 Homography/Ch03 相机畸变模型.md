# 第3章 相机畸变模型

> 针孔相机模型假设光线直线穿过光心——但真实镜头不是完美的。畸变让直线在图像中变弯，标定必须把它校回来。

## 1. 畸变从哪来

实际相机使用透镜而非针孔来汇聚光线，这带来两个问题：

- **透镜的球面形状**：透镜表面是球面而非理想抛物面，导致离光轴越远的点**放大率越不一致**——边缘处光线弯得比中心处厉害。这产生桶形或枕形的**径向畸变**。
- **装配误差**：透镜平面与传感器平面没有严格平行，光线穿过透镜后产生切向偏移。这产生**切向畸变**。

畸变的存在意味着针孔模型的直线投影假设被打破——三维空间中的直线在图像上可能变成曲线。好在畸变可以用数学模型描述，标定时一并求解畸变参数，后续所有像素坐标都先"去畸变"再使用。

## 2. 径向畸变

### 2.1 两种形态

| 类型 | 现象 | 出现场景 |
|------|------|---------|
| **桶形畸变** | 直线向外弯曲（像木桶鼓起） | 广角镜头常见 |
| **枕形畸变** | 直线向内弯曲（像枕头凹陷） | 长焦镜头常见 |

### 2.2 数学模型

径向畸变用多项式建模。设畸变前的归一化坐标为 `(x, y)`，到光心的距离为 `r = √(x² + y²)`，畸变校正后的坐标为：

$$x_{corrected} = x(1 + k_1 r^2 + k_2 r^4 + k_3 r^6)$$

$$y_{corrected} = y(1 + k_1 r^2 + k_2 r^4 + k_3 r^6)$$

三个系数 `(k₁, k₂, k₃)` 是径向畸变参数。对于大多数普通镜头，`k₁` 和 `k₂` 就够了；鱼眼等严重畸变镜头才需要 `k₃`。

公式的直觉：括号里的 `(1 + k₁r² + k₂r⁴ + k₃r⁶)` 是一个和距离 `r` 有关的缩放因子——离光心越远的像素，`r` 越大，校正量越大。这符合"镜头边缘畸变更严重"的物理事实。

## 3. 切向畸变

切向畸变来自透镜与成像平面的**装配误差**——如果透镜没有严格平行于传感器平面，光线穿过透镜后的方向会产生切向偏移。

数学模型：

$$x_{corrected} = x + 2p_1 xy + p_2(r^2 + 2x^2)$$

$$y_{corrected} = y + p_1(r^2 + 2y^2) + 2p_2 xy$$

两个系数 `(p₁, p₂)` 是切向畸变参数。

切向畸变通常比径向畸变小得多，但在精密测量应用中不能被忽略。

## 4. 联合畸变模型

实践中将径向和切向合并使用：

$$x_{corrected} = x(1 + k_1 r^2 + k_2 r^4 + k_3 r^6) + 2p_1 xy + p_2(r^2 + 2x^2)$$

$$y_{corrected} = y(1 + k_1 r^2 + k_2 r^4 + k_3 r^6) + p_1(r^2 + 2y^2) + 2p_2 xy$$

OpenCV 的 `calibrateCamera` 默认输出 5 个畸变参数 `(k₁, k₂, p₁, p₂, k₃)`，可通过标定 flag 选择启用哪些。

## 5. 在标定流程中的位置

畸变校正在**归一化坐标**上进行——即投影到 `Z=1` 平面之后、乘内参 K 之前。完整管道：

```
世界坐标 Pw
    ↓ R, T（外参）
相机坐标 Pc
    ↓ 除以 Z
归一化坐标 (x, y)
    ↓ 畸变校正
校正后归一化坐标 (x', y')
    ↓ 乘内参 K
像素坐标 (u, v)
```

关键点：**先畸变、再内参**——畸变发生在物理投影阶段，是"光学的误差"，与像素的数字化无关。

## 6. 实践要点

- **标定时拍足够多、姿态足够丰富的棋盘格照片**（10–20 张），尤其要拍边角区域，因为这些地方的畸变最显著
- **OpenCV 的 `undistort`** 函数只需传入原始图像和标定得到的 K + 畸变系数，即可输出校正后的图像
- **对测量应用来说去畸变是必须的**——图像边缘的像素可能因为畸变偏移几个像素甚至几十个像素的物理位置
