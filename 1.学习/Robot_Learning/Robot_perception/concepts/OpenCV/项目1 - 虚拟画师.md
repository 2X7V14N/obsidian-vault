# 项目1 - 虚拟画师

**虚拟画师**（Virtual Painter）是第一个综合项目。目标：用摄像头追踪一支彩色笔，在屏幕上实时"绘画"。它整合了颜色检测、轮廓检测和绘图函数三大模块。

## 核心技术链

```
摄像头帧 → HSV转换 → inRange(多颜色) → findContours → 取轮廓顶部中心 → 在画布上绘制
```

## 关键设计

### 多颜色支持

用 `vector<vector<int>>` 存储多组 HSV 范围，`vector<Scalar>` 存储对应的绘制颜色：

```cpp
// 每种颜色一组 HSV 范围（Hmin,Smin,Vmin, Hmax,Smax,Vmax）
vector<vector<int>> myColors = {
    {0, 100, 100, 10, 255, 255},      // 红色（H=0∼10）
    {170, 100, 100, 179, 255, 255},   // 红色（H=170∼179）
    {40, 50, 50, 80, 255, 255},       // 绿色
    {100, 100, 100, 130, 255, 255},   // 蓝色
};

// 对应每组的绘制颜色（BGR）
vector<Scalar> drawColors = {
    Scalar(0, 0, 255),     // 红
    Scalar(0, 0, 255),     // 红
    Scalar(0, 255, 0),     // 绿
    Scalar(255, 0, 0),     // 蓝
};
```

### 找笔尖位置

`findColor()` 函数：遍历所有颜色，为每种颜色创建 mask 并查找轮廓。`getContours()` 返回轮廓的**顶部中心点** `Point(x, y)`——这被当作"笔尖"的位置。

### 持久画布

不同于每帧清空重画，"虚拟画师"维护一个全局 `newPoints` 向量持久存储所有历史点，实现"不擦除"的绘画效果。每次在摄像头帧上检测到新笔尖位置后，同时在新点画布和原图上绘制。

## 实现骨架

```cpp

        // findContours 找到笔的轮廓
        // getContours 返回笔尖的 Point
        // 将新点添加到 newPoints[i]
    }
    
    // 在画布上绘制所有历史点
    for (int i = 0; i < newPoints.size(); i++) {
        for (Point p : newPoints[i]) {
            circle(imgCanvas, p, 5, drawColors[i], FILLED);
        }

    imshow("Canvas", imgCanvas);
```
