# 第8章 - 人脸检测

> ⚠️ **OpenCV 5 用户必读**：本章包含两套方案。如果你使用 **OpenCV 5**，传统 `CascadeClassifier` 已从默认核心头文件中移除——请直接跳至 [[#第二部分：现代方法 — FaceDetectorYN YuNet（OpenCV 5 推荐）|第二部分]]。

人脸检测是计算机视觉中最经典的任务之一。本章覆盖两种路线：

|               | 传统方法（Haar 级联） | 现代方法（DNN / YuNet）    |
| ------------- | ------------- | -------------------- |
| **模型格式**      | `.xml`        | `.onnx`              |
| **输入要求**      | 必须转灰度图        | BGR 彩色图直接输入          |
| **输出**        | 仅矩形框          | 矩形框 + 5 个面部关键点 + 置信度 |
| **精度**        | 一般（正脸为主）      | 高（多角度、侧脸）            |
| **OpenCV 版本** | 4.x 可用，5 中已移除 | OpenCV 5 推荐          |
| **学习价值**      | 理解级联检测原理      | 掌握现代 DNN 接口          |

# 第一部分：传统方法 — Haar 级联分类器

> 这一部分适合在 **OpenCV 4.x** 环境下使用，或作为理解目标检测发展历史的参考。

**Haar 级联分类器**由 Viola 和 Jones 于 2001 年提出。它曾是第一代能在消费级硬件上实时运行的人脸检测算法，其核心思想至今仍有教育价值。

## Viola-Jones 框架的三个核心创新

### 1. 积分图（Integral Image）

传统方法计算 Haar 特征需要遍历矩形区域求和——$O(wh)$ 操作。积分图将任意矩形区域的和变为 $O(1)$（4 次查找 + 2 次加减），使特征计算不再与矩形大小相关。

### 2. AdaBoost 特征选择

Haar 特征数量巨大（24×24 窗口约 16 万个）。AdaBoost 贪心地选出最有效的少数特征，每个弱分类器对应一个 Haar 特征 + 一个阈值，最终分类器是它们的加权组合。

### 3. 级联结构（Attentional Cascade）

绝大多数检测窗口都不包含目标。级联结构将分类器按"简单→复杂"排成多级——前端用少量特征快速筛掉明显非目标的窗口，99% 的窗口在前几级就被淘汰。

## OpenCV 4.x 中的使用

```cpp
#include <opencv2/objdetect.hpp>

CascadeClassifier faceCascade;
faceCascade.load("haarcascade_frontalface_default.xml");   // 正脸

vector<Rect> faces;
faceCascade.detectMultiScale(
    grayImage,                    // 必须是灰度图！
    faces,
    1.1,                          // scaleFactor
    10,                           // minNeighbors
    0 | CASCADE_SCALE_IMAGE,
    Size(30, 30)                  // 最小检测尺寸
);
```

**关键参数**：

| 参数 | 怎么选 |
|------|--------|
| `scaleFactor` | 1.05~1.2。越小检测越密集但越慢 |
| `minNeighbors` | 3~6 中等严格度；10 高精度场景 |

## 优点与历史局限

**优点**：CPU 即可实时运行、无需 GPU、OpenCV 内置、适合嵌入式设备。

**局限**：角度敏感（侧脸检测率低）、光照敏感、精度落后现代 DNN 方法 20–50%。

在 OpenCV 5 中，`CascadeClassifier` 已从默认头文件 `objdetect.hpp` 中移除。因此，现代项目应转向 DNN 方案。

# 第二部分：现代方法 — FaceDetectorYN / YuNet（OpenCV 5 推荐）

`FaceDetectorYN` 是 OpenCV 5 内置的深度学习人脸检测接口，底层使用 **YuNet** 模型。它解决了 Haar 级联的所有短板——多角度、侧脸、遮挡场景表现更好，且输出信息更丰富。

## 与传统方法的对比

| 比较维度 | Haar 级联 | FaceDetectorYN (YuNet) |
|---------|----------|----------------------|
| 模型文件 | `haarcascade_*.xml` | `face_detection_yunet_2023mar.onnx` |
| 头文件 | `<opencv2/objdetect.hpp>` | `<opencv2/objdetect/face.hpp>` |
| 输入图像 | 必须先转灰度 | **BGR 彩色图直接输入** |
| 初始化时 | 不需要图像尺寸 | 需要 `img.size()` |
| 输出 | 仅矩形框 `Rect` | 矩形框 + 5 个面部关键点 + 置信度 |
| 内存管理 | 栈对象 | `Ptr<>` 智能指针自动管理 |
| 多角度支持 | 差 | 好 |

## 完整代码模板

```cpp
#include <opencv2/opencv.hpp>
#include <opencv2/objdetect/face.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    // 1. 读取图像（BGR 彩色图直接输入，不需要转灰度）
    string path = "Resources/test.png";
    Mat img = imread(path);

    if (img.empty()) {
        cout << "图像读取失败，请检查路径" << endl;
        return -1;
    }

    // 2. 加载 YuNet 深度学习模型
    string modelPath = "Resources/face_detection_yunet_2023mar.onnx";

    auto faceDetector = FaceDetectorYN::create(
        modelPath,       // .onnx 模型路径
        "",              // 配置文件（空 = 使用默认）
        img.size(),      // 输入图像尺寸（必须！）
        0.6f,            // scoreThreshold：置信度阈值
        0.3f,            // nmsThreshold：NMS 阈值
        5000             // topK：最多保留的检测数
    );

    // 3. 执行检测（输出参数模式）
    Mat faces;                           // 空表格，由 detect 填入结果
    faceDetector->detect(img, faces);    // 指针用 -> 调用

    // 4. 解析结果并绘制
    if (!faces.empty()) {
        cout << "检测到了 " << faces.rows << " 个人脸" << endl;

        for (int i = 0; i < faces.rows; i++) {
            // 提取矩形框
            int x = int(faces.at<float>(i, 0));
            int y = int(faces.at<float>(i, 1));
            int w = int(faces.at<float>(i, 2));
            int h = int(faces.at<float>(i, 3));

            // 提取置信度（第 14 列）
            float score = faces.at<float>(i, 14);

            // 画框 + 显示置信度
            rectangle(img, Rect(x, y, w, h), Scalar(0, 255, 0), 2);
            putText(img, format("%.2f", score),
                    Point(x, max(0, y - 5)),
                    FONT_HERSHEY_SIMPLEX, 0.6, Scalar(0, 255, 0), 2);
        }
    } else {
        cout << "未检测到人脸" << endl;
    }

    imshow("Face Detection (YuNet)", img);
    waitKey(0);
    return 0;
}
```

## faces 输出矩阵结构

`detect()` 的输出是一个 `Mat`，**每一行代表一张检测到的人脸**：

| 列索引 | 含义 |
|--------|------|
| `0` | 人脸框左上角 `x` |
| `1` | 人脸框左上角 `y` |
| `2` | 人脸框宽度 `w` |
| `3` | 人脸框高度 `h` |
| `4–5` | 右眼关键点坐标 |
| `6–7` | 左眼关键点坐标 |
| `8–9` | 鼻尖坐标 |
| `10–11` | 右嘴角坐标 |
| `12–13` | 左嘴角坐标 |
| `14` | **置信度得分**（最常用的额外列） |

最常用的是前 4 列（矩形框）和第 14 列（置信度）：

```cpp
int x = int(faces.at<float>(i, 0));
int y = int(faces.at<float>(i, 1));
int w = int(faces.at<float>(i, 2));
int h = int(faces.at<float>(i, 3));
float score = faces.at<float>(i, 14);
```

## 关键参数详解

### `FaceDetectorYN::create()` 的 6 个参数

```cpp
FaceDetectorYN::create(modelPath, config, inputSize, scoreThreshold, nmsThreshold, topK);
```

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `modelPath` | `.onnx` 模型文件路径 | `"face_detection_yunet_2023mar.onnx"` |
| `config` | 配置文件路径，留空使用默认 | `""` |
| `inputSize` | 输入图像尺寸 | `img.size()` |
| `scoreThreshold` | 置信度阈值（低于此值丢弃） | `0.6f`（调低=更多检测，更多误检） |
| `nmsThreshold` | NMS 重叠阈值 | `0.3f` |
| `topK` | 最多保留的检测框数量 | `5000` |

### 为什么初始化时需要 `img.size()`

DNN 模型底层需要根据输入尺寸预分配网络输入张量和内存结构。这与传统 `CascadeClassifier` 不同——后者在 `detectMultiScale` 时才处理尺寸。

## C++ 语法要点

### Ptr<> 智能指针

```cpp
Ptr<FaceDetectorYN> faceDetector = FaceDetectorYN::create(...);
// 或简写：
auto faceDetector = FaceDetectorYN::create(...);
```

`FaceDetectorYN` 内部包含深度学习网络结构和参数，内存开销大。`Ptr<>` 是 OpenCV 的智能指针——创建时分配内存，不再需要时**自动释放**，避免手动 `new`/`delete`。

### 作用域解析符 `::`

```cpp
FaceDetectorYN::create(...)   // :: 表示"FaceDetectorYN 类里的 create"
```

`create` 是静态工厂方法——此时还没有具体对象，不能用 `.`，必须用 `::`。

### 箭头 `->` vs 点号 `.`

```cpp
faceDetector->detect(img, faces);   // -> 用于指针/智能指针
img.size();                          // .  用于实体对象
```

`faceDetector` 是 `Ptr<FaceDetectorYN>`（智能指针），像一个"遥控器"指向真实对象。`->` 就是通过这个指针去调用真实对象的方法。

### 输出参数模式

```cpp
Mat faces;                          // 先创建空容器
faceDetector->detect(img, faces);   // 函数把结果填进去（不用 return）
```

OpenCV 中图像、矩阵等数据可能很大，直接通过输出参数写入可以减少不必要的数据复制。这相当于：准备一张空表格 → 交给 `detect` → `detect` 把结果填进去。
