# 第1章 - 读取图像、视频和摄像头

OpenCV 程序的起点永远是"把数据读进来"。本章覆盖三种最常见的输入源：静态图像文件、视频文件、实时摄像头流。

## 基础代码结构

每个 OpenCV C++ 程序需要的核心头文件：

```cpp
#include <opencv2/imgcodecs.hpp>   // imread, imwrite
#include <opencv2/highgui.hpp>     // imshow, namedWindow, VideoCapture
#include <opencv2/imgproc.hpp>     // cvtColor, GaussianBlur, Canny...
#include <iostream>

using namespace cv;
using namespace std;
```

- `imgcodecs`：图像编解码
- `highgui`：GUI 窗口和显示
- `imgproc`：图像处理（后续章节的主力头文件）

## 读取并显示图像

```cpp
string path = "Resources/test.png";
Mat image = imread(path);        // 读取图像到 Mat 对象
imshow("Window Name", image);    // 在窗口中显示
waitKey(0);                      // 0 = 无限等待按键；>0 = 等待指定毫秒
```

`imread` 支持常见格式：JPEG、PNG、BMP、TIFF 等。如果文件不存在，`image.empty()` 返回 `true`——**生产代码中务必检查**。

`waitKey(0)` 的核心作用是**让 GUI 事件循环运行**。不调用它，窗口不会显示或会立即消失。

## 播放视频

视频的本质是**连续图像帧的序列**：

```cpp
VideoCapture cap("Resources/test_video.mp4");
Mat frame;

while (true) {
    cap.read(frame);               // 逐帧读取
    if (frame.empty()) break;      // 视频结束
    imshow("Video", frame);
    waitKey(1);                    // 延迟毫秒，控制播放速度
}
```

`waitKey(1)` 中的参数控制帧间延迟——值越大播放越慢。1ms 意味着"尽可能快"（受限于解码和显示速度）。

## 读取摄像头

摄像头的 API 与视频文件完全相同——换一个 `VideoCapture` 的构造参数即可：

```cpp
VideoCapture cap(0);               // 0 = 默认摄像头
VideoCapture cap(1);               // 1 = 第二个摄像头
// 也支持 IP 摄像头 URL：VideoCapture cap("http://192.168.1.100:8080/video");
```

摄像头读取与视频播放的代码结构完全一致——从 `while(true)` 开始，`cap.read(frame)` 逐帧获取，`waitKey(1)` 控制帧率。

> 💡 **调试技巧**：摄像头程序可以加一个简单的退出条件——例如按 `q` 键退出（检查 `waitKey(1) == 'q'`）。

## 实践要点

- **路径**：推荐使用相对路径，并将资源放在项目目录下的 `Resources/` 文件夹中。跨平台时注意路径分隔符。
- **错误处理**：始终检查 `image.empty()` 或 `!cap.isOpened()`，不要让代码在无声中失败。
- **内存**：`VideoCapture` 的 `read()` 会复用 `Mat` 的内存，不需要手动释放。
