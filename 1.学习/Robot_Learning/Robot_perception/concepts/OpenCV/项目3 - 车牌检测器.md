# 项目3 - 车牌检测器

**车牌检测器**是第三个综合项目。目标：用摄像头实时检测车牌，并自动裁剪保存检测到的车牌图像。它展示了 Haar 级联分类器在真实场景中的使用。

## 核心技术

```
摄像头帧 → 灰度化 → Haar级联检测(russian_plate) → 绘制检测框 → 裁剪并保存
```

## 实现

```cpp
#include <opencv2/objdetect.hpp>

CascadeClassifier plateCascade;
plateCascade.load("Resources/haarcascade_russian_plate_number.xml");

VideoCapture cap(0);
Mat frame, imgGray;

while (true) {
    cap.read(frame);
    cvtColor(frame, imgGray, COLOR_BGR2GRAY);
    
    vector<Rect> plates;
    plateCascade.detectMultiScale(imgGray, plates, 1.1, 10);
    
    for (int i = 0; i < plates.size(); i++) {
        // 在原始帧上画绿色检测框
        rectangle(frame, plates[i].tl(), plates[i].br(), Scalar(0, 255, 0), 3);
        
        // 裁剪车牌区域
        Mat imgCrop = frame(plates[i]);
        
        // 保存到本地
        imwrite("Resources/Plates/" + to_string(plateCount++) + ".png", imgCrop);
        
        // 可选：显示裁剪的车牌
        imshow("Plate " + to_string(i), imgCrop);
    }
    
    imshow("Frame", frame);
    waitKey(1);
}
```

## 关键参数调优

| 参数 | 推荐值 | 效果 |
|------|--------|------|
| `scaleFactor` | `1.1` | 检测密度适中 |
| `minNeighbors` | `6`~`10` | 车牌检测需要较高严格度（减少误检） |
| `minSize` | `Size(30, 30)` | 过滤太小（太远）的车牌 |

> 💡 保存时建议加**去重逻辑**——同一车牌在多帧中重复检测会导致大量重复文件。可以在保存间隔上限制（如每 30 帧保存一次），或检查新检测框与已保存框的 IoU 重叠度。

## 扩展方向

### 车牌识别（OCR）

检测只是第一步。完整的车牌识别系统还需：
1. **字符分割**：将车牌区域进一步分割为独立字符
2. **字符识别**：用 OCR（如 Tesseract）或训练 CNN 识别每个字符
3. **校验逻辑**：利用车牌格式规则（如"省简称+字母+5位数字"）提升识别准确率

### 多国车牌

`haarcascade_russian_plate_number.xml` 针对俄式车牌。中国车牌、欧洲车牌可能需要不同的级联文件或训练自己的分类器。
