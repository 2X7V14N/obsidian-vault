# 项目2 - 文档扫描仪

**文档扫描仪**是第二个综合项目。目标：用摄像头拍一张纸（或任何矩形平面物体），自动检测四个角，通过透视变换将其矫正为平整的正面视图。

## 核心技术链

```
摄像头帧 → 预处理 → findContours → 找最大四边形 → 角点重排序 → 透视变换 → 裁剪输出
```

## 实现步骤

### 步骤 1：预处理

```cpp
Mat imgGray, imgBlur, imgCanny, imgDilate;
cvtColor(frame, imgGray, COLOR_BGR2GRAY);
GaussianBlur(imgGray, imgBlur, Size(7, 7), 5, 0);
Canny(imgBlur, imgCanny, 50, 150);

Mat kernel = getStructuringElement(MORPH_RECT, Size(5, 5));
dilate(imgCanny, imgDilate, kernel);
```

### 步骤 2：找最大四边形

```cpp
vector<vector<Point>> contours;
findContours(imgDilate, contours, RETR_EXTERNAL, CHAIN_APPROX_SIMPLE);

vector<Point> biggest;
int maxArea = 0;
for (auto& cnt : contours) {
    int area = contourArea(cnt);
    if (area > 1000) {
        vector<Point> approx;
        double peri = arcLength(cnt, true);
        approxPolyDP(cnt, approx, 0.02 * peri, true);
        
        if (approx.size() == 4 && area > maxArea) {  // 四边形 + 面积最大
            biggest = approx;
            maxArea = area;
        }
    }
}
```

### 步骤 3：角点重排序

轮廓检测返回的四个角点顺序是任意的。必须重排序为 [左上, 右上, 左下, 右下]：

```
算法（基于坐标的和与差）：
1. 按 x+y 排序：和最小 → 左上角，和最大 → 右下角
2. 剩余两点按 x-y 排序：差最小 → 右上角，差最大 → 左下角
```

### 步骤 4：透视变换

```cpp
float w = 420, h = 596;   // A4 比例 ≈ 1:1.414
vector<Point2f> dst = { {0.0f, 0.0f}, {w, 0.0f}, {0.0f, h}, {w, h} };

Mat matrix = getPerspectiveTransform(src, dst);
Mat imgWarp;
warpPerspective(frame, imgWarp, matrix, Point(w, h));

// 可选：裁剪进一步去除透视变换的边缘伪影
Rect cropRect(5, 5, w - 10, h - 10);
Mat imgCrop = imgWarp(cropRect);
```

### 步骤 5：循环检测

摄像头每帧都执行以上步骤，实时展示检测到的四角点和矫正结果。用户调整纸的角度时，矫正结果实时更新。

## 扩展方向

- **自动捕捉**：检测到稳定的四边形后自动拍照保存，无需手动按键
- **多页扫描**：连续扫描多页，自动编号保存
- **增强对比度**：矫正后对文本区域做自适应阈值化，提升可读性
- **非 A4 比例**：根据检测到的四边形真实宽高比动态调整输出尺寸
