# OpenCV 介绍

**OpenCV**（Open Source Computer Vision Library）是 Intel 于 1999 年启动的开源计算机视觉库，2000 年首次发布。二十多年来，它从最初的 C 语言图像处理工具箱，演变为覆盖图像 I/O、底层处理、特征提取、目标检测、深度学习推理的全面视觉库——C++、Python、Java 多语言支持，Windows、Linux、macOS、Android、iOS 全平台覆盖。

## 为什么学 OpenCV

在机器人感知领域，OpenCV 是"基础设施级"的存在。几乎所有的视觉任务——从简单的颜色检测到复杂的 3D 重建——都需要 OpenCV 提供的底层操作。它解决的问题是**让机器"看见"并理解物理世界**。
