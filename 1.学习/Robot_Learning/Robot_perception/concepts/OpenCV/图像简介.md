# 图像简介

在写任何 OpenCV 代码之前，需要理解一件事：图像在计算机里到底是什么。一张图像本质上是一个**数值矩阵**——每个像素对应一个或多个数值，值的范围和含义取决于图像类型。

## 像素与分辨率

一张数字图像由像素（pixel，picture element）组成的二维网格构成。**分辨率**（如 640×480、1920×1080）定义了网格的宽度（列数）和高度（行数）。分辨率越高，图像包含的细节越多，但处理和存储的成本也越大。

常见分辨率：
- VGA: 640×480
- HD: 1280×720
- Full HD: 1920×1080
- 4K: 3840×2160

## 三种图像类型

根据每个像素存储的信息量，图像分为三类：

**二值图像（Binary Image）**

每个像素只有两个值：0（黑色）和 1（白色）。没有中间灰度。二值图像通常不是原始输入，而是处理后的结果——如 Canny 边缘检测的输出、颜色检测的 mask、阈值化的分割结果。

**灰度图像（Grayscale Image）**

每个像素用一个 8 位无符号整数（`uint8`）存储，取值范围 0∼255，共 256 个灰度级。0 为纯黑，255 为纯白。大多数图像处理算法（边缘检测、轮廓检测、人脸检测）都要求输入为灰度图——单通道意味着计算量降到彩图的 1/3。

**彩色图像（Color Image）**

每个像素由三个通道叠加而成，每个通道本身是一张灰度图。OpenCV 默认使用 **BGR**（蓝、绿、红）顺序，而非更常见的 RGB。

```cpp
Scalar(255, 0, 0);    // 纯蓝色 (B=255, G=0, R=0)
Scalar(0, 255, 0);    // 纯绿色
Scalar(0, 0, 255);    // 纯红色
```

> ⚠️ **关键坑**：OpenCV 使用 BGR 而非 RGB 顺序。与 matplotlib、PIL、TensorFlow（默认 RGB）交互时，需要用 `cvtColor(image, image, COLOR_BGR2RGB)` 显式转换，否则红色和蓝色会互换。这是历史遗留问题——继承自 Intel 和某些相机硬件厂商的 BGR 输出格式。

## OpenCV 中的图像容器：Mat

`Mat`（Matrix 的缩写）是 OpenCV 最核心的类，所有图像在 OpenCV 中都以 `Mat` 对象表示：

```cpp
Mat image = imread("path/to/image.jpg");
// image.rows    — 图像高度（像素行数）
// image.cols    — 图像宽度（像素列数）
// image.channels() — 通道数（灰度=1, 彩色=3）
// image.type()  — 数据类型（如 CV_8UC3 = 8位无符号 × 3通道）
```

`Mat` 使用**引用计数**智能管理内存——赋值和拷贝只复制头部信息，像素数据共享，避免大图像的频繁深拷贝。
