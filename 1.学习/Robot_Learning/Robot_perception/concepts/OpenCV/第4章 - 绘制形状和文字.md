# 第4章 - 绘制形状和文字

OpenCV 提供了一套绘图函数，用于在图像上叠加形状、线条和文字。这些函数不仅是可视化工具——在项目实战中，它们是**将检测结果反馈给用户**的主要方式。

## 基础：创建画布

```cpp
// CV_8UC3 = 8位无符号 × 3通道（彩色图）
Mat canvas(512, 512, CV_8UC3, Scalar(255, 255, 255));  // 白色背景
Mat blackCanvas(512, 512, CV_8UC3, Scalar(0, 0, 0));   // 黑色背景
```

> ⚠️ `Scalar` 始终是 **BGR** 顺序：`Scalar(B, G, R)`。

## 圆

```cpp
circle(canvas, Point(256, 256), 155, Scalar(0, 69, 255), FILLED);
//      画布     圆心           半径   颜色(红色)         填充
```

- 圆心用 `Point(x, y)` 指定
- 最后一个参数：`FILLED`（或 `-1`）= 填充整个圆，正数 = 边框粗细（像素）

## 矩形

```cpp
rectangle(canvas, Rect(130, 226, 382, 286), Scalar(255, 255, 255), FILLED);
//        画布      矩形区域(x,y,宽,高)      颜色(白色)         填充
```

也可以使用两个对角点定义：
```cpp
rectangle(canvas, Point(130, 226), Point(512, 512), Scalar(0, 255, 0), 2);
```

## 线段

```cpp
line(canvas, Point(130, 296), Point(382, 296), Scalar(255, 255, 255), 2);
//    画布      起点            终点            颜色              线宽
```

## 文字

```cpp
putText(canvas, "Hello OpenCV", Point(137, 262),
        FONT_HERSHEY_PLAIN, 0.75, Scalar(0, 69, 255), 2);
//       文本              位置         字体          字号  颜色          粗细
```

常用字体：
- `FONT_HERSHEY_PLAIN` — 无衬线小字
- `FONT_HERSHEY_SIMPLEX` — 正常大小无衬线
- `FONT_HERSHEY_DUPLEX` — 略粗的无衬线

## 实战用法

绘图函数在项目中最常见的用法是**在原始图像上标注检测结果**：

```cpp
// 在检测到的人脸上画框
for (Rect face : faces) {
    rectangle(image, face, Scalar(255, 0, 255), 2);          // 紫色框
    putText(image, "Face", face.tl(),                         // 在框的左上角
            FONT_HERSHEY_PLAIN, 1, Scalar(0, 255, 0), 2);
}

// 在检测到的轮廓上画编号
for (int i = 0; i < contours.size(); i++) {
    drawContours(image, contours, i, Scalar(255, 0, 0), 2);  // 蓝色轮廓线
    putText(image, to_string(i), contours[i][0],              // 编号标在轮廓起点
            FONT_HERSHEY_PLAIN, 1, Scalar(0, 0, 255), 1);
}
```
