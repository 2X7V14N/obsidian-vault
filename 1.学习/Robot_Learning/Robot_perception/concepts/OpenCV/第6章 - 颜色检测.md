# 第6章 - 颜色检测

颜色检测是 OpenCV 中最直观的应用之一：在图像中找到"某种颜色的物体"。但直接用 BGR 做颜色检测效果很差——同一颜色在不同光照下 BGR 三通道值变化巨大。解决方案是换用 **HSV 颜色空间**。

## 为什么用 HSV 而非 BGR

BGR 将颜色信息混在三个通道中。光照变化时，三个通道**同时变亮或变暗**，很难定义一个稳定的"红色"范围。

HSV（Hue, Saturation, Value）解决了这个问题：

| 分量 | 含义 | 受光照影响 |
|------|------|-----------|
| **H（色调）** | 颜色类型，以角度表示 | **几乎不受影响**——红色物体在强光和阴影下 H 值基本一致 |
| **S（饱和度）** | 颜色的纯度/鲜艳度 | 轻度受影响 |
| **V（明度）** | 亮度 | 直接受影响 |

因此颜色检测时策略是：H 设窄范围（精确匹配颜色）、S 和 V 设宽范围（容忍光照变化）。

## HSV 范围（OpenCV 约定）

| 分量 | OpenCV 范围 | 说明 |
|------|-----------|------|
| H | 0∼179 | 对应 0°∼360° 的一半 |
| S | 0∼255 | 0=灰色，255=最鲜艳 |
| V | 0∼255 | 0=黑，255=最亮 |

## 检测流程

```cpp
// 1. 转换到 HSV
Mat imgHSV;
cvtColor(image, imgHSV, COLOR_BGR2HSV);

// 2. 定义颜色范围
Scalar lower(h_min, s_min, v_min);
Scalar upper(h_max, s_max, v_max);

// 3. 创建二值掩膜
Mat mask;
inRange(imgHSV, lower, upper, mask);
// mask 中白色(255) = 颜色范围内的像素，黑色(0) = 范围外的像素
```

`inRange` 对每个像素检查：`lower[0] ≤ H ≤ upper[0]` **且** `lower[1] ≤ S ≤ upper[1]` **且** `lower[2] ≤ V ≤ upper[2]`。三个条件同时满足才输出白色。

## 红色的特殊处理：Hue 环绕

HSV 的色相环是圆形的——0 和 179（对应 0° 和 360°）都是红色，在色环上相邻。这意味着红色跨越了 H 值的边界。

检测红色需要**两个范围然后合并**：

```cpp
// 红色在 H 的两端：0∼10 和 170∼179
Scalar lower1(0, 100, 100),   upper1(10, 255, 255);
Scalar lower2(170, 100, 100), upper2(179, 255, 255);

Mat mask1, mask2;
inRange(imgHSV, lower1, upper1, mask1);
inRange(imgHSV, lower2, upper2, mask2);

Mat mask = mask1 | mask2;   // 按位或——合并两个范围的检测结果
```

这是 HSV 颜色检测中最常见的陷阱之一。

## Trackbar 实时调参

手动猜测合适的 HSV 范围几乎不可能。OpenCV 的 `createTrackbar` 提供了图形化的实时调参能力：

```cpp
namedWindow("Trackbars", Size(640, 200));

int h_min = 0, s_min = 0, v_min = 0;
int h_max = 179, s_max = 255, v_max = 255;

createTrackbar("Hue Min", "Trackbars", &h_min, 179);
createTrackbar("Hue Max", "Trackbars", &h_max, 179);
createTrackbar("Sat Min", "Trackbars", &s_min, 255);
createTrackbar("Sat Max", "Trackbars", &s_max, 255);
createTrackbar("Val Min", "Trackbars", &v_min, 255);
createTrackbar("Val Max", "Trackbars", &v_max, 255);

while (true) {
    Scalar lower(h_min, s_min, v_min);
    Scalar upper(h_max, s_max, v_max);
    inRange(imgHSV, lower, upper, mask);
    imshow("Mask", mask);
    waitKey(1);
}
```

拖动滑块实时看到 mask 的变化，找到最佳范围后记录数值即可。

## 完整管道：颜色检测 → 轮廓检测

颜色检测通常不是终点——`inRange` 输出的 mask 是轮廓检测的理想输入：

```
原始图像 → cvtColor(BGR→HSV) → inRange → mask → findContours → 轮廓分析
```
