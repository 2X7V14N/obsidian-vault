# 第3章 - 调整大小和裁剪

图像的几何操作是最常用的预处理步骤之一。本章覆盖两个最基础的操作：缩放（统一改变尺寸）和裁剪（提取感兴趣区域）。

## 缩放：resize

OpenCV 提供两种缩放方式：

```cpp
// 方式一：指定目标尺寸（可能改变宽高比）
resize(src, dst, Size(640, 480));

// 方式二：按比例缩放（推荐——保持宽高比）
resize(src, dst, Size(), 0.5, 0.5);   // 宽高各缩小为原来的 50%
```

`Size()` 为空时，后两个参数 `fx` 和 `fy` 分别控制宽度和高度的缩放因子。`0.5, 0.5` 表示各缩小一半。

### 插值方式

`resize` 默认使用线性插值（`INTER_LINEAR`）。特殊场景可指定：

| 插值方式 | 效果 | 场景 |
|---------|------|------|
| `INTER_LINEAR` | 双线性插值（默认） | 通用，速度与质量平衡 |
| `INTER_NEAREST` | 最近邻 | 速度最快，但可能产生锯齿 |
| `INTER_AREA` | 区域插值 | **缩小图像时推荐**——质量最好 |
| `INTER_CUBIC` | 双三次插值 | **放大图像时推荐**——更平滑 |

```cpp
resize(src, dst, Size(), 0.5, 0.5, 0, 0, INTER_AREA);    // 缩小
resize(src, dst, Size(), 2.0, 2.0, 0, 0, INTER_CUBIC);   // 放大
```

> 💡 实践法则：缩小用 `INTER_AREA`，放大用 `INTER_CUBIC`。

## 裁剪：ROI

裁剪不是通过一个独立函数完成的——它利用 OpenCV 的 **ROI（Region of Interest）** 机制，直接在原始 `Mat` 上创建一个"窗口"：

```cpp
Rect roi(100, 100, 300, 250);    // x, y, width, height
Mat crop = image(roi);            // 创建一个指向原图子区域的 Mat
```

**重要**：`image(roi)` 创建的是**引用而非拷贝**——修改 `crop` 会影响 `image` 的对应区域（因为它们共享同一块内存）。如果需要一个独立的副本：

```cpp
Mat cropCopy = image(roi).clone();  // 深拷贝，修改不影响原图
```

### 使用场景

- **聚焦目标区域**：检测到人脸后，裁剪出人脸区域做进一步分析
- **移除无关背景**：在处理前缩小图像范围，减少计算量
- **数据增强**：在训练数据中随机裁剪不同区域
