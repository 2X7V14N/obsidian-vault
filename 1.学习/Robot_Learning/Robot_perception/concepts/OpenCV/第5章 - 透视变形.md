# 第5章 - 透视变形

**透视变换**（Perspective Transform）是一种将平面物体从任意视角"拉回"到正视视角的几何操作。与缩放、裁剪等简单变换不同，它处理的是**透视投影**造成的变形——矩形成任意四边形，平行线不再平行。

这是文档扫描器的核心技术。

## 原理

透视变换是一个从源平面到目标平面的**射影映射**（projective mapping），由一个 3×3 的**单应性矩阵**（homography matrix）H 定义：

$$
\begin{pmatrix} x' \\ y' \\ w' \end{pmatrix} = H \begin{pmatrix} x \\ y \\ 1 \end{pmatrix}
$$

实际像素坐标：$x_{dst} = x'/w'$, $y_{dst} = y'/w'$

H 有 8 个自由度（9 个元素减 1 个尺度因子），因此**最少需要 4 对对应点**来唯一确定该变换。

### 与仿射变换的区别

| | 仿射变换 | 透视变换 |
|---|---|---|
| 矩阵 | 2×3 | 3×3 |
| 最少点对 | 3 | 4 |
| 保持平行性 | 是 | 否 |
| OpenCV 函数 | `getAffineTransform` | `getPerspectiveTransform` |
| 应用函数 | `warpAffine` | `warpPerspective` |

## 四步操作

```cpp
// 1. 定义源四角点（从图像中选取）
vector<Point2f> src = { {529, 142}, {771, 190}, {405, 395}, {674, 457} };
// 顺序必须是：左上、右上、左下、右下

// 2. 定义目标四角点（输出矩形的四个角）
float w = 250, h = 350;
vector<Point2f> dst = { {0.0f, 0.0f}, {w, 0.0f}, {0.0f, h}, {w, h} };

// 3. 计算单应性矩阵
Mat matrix = getPerspectiveTransform(src, dst);

// 4. 应用变换
Mat imageWarp;
warpPerspective(image, imageWarp, matrix, Point(w, h));
```

### 关键注意事项

**角点顺序至关重要**。`getPerspectiveTransform` 假设 `src[0]` 对应 `dst[0]`、`src[1]` 对应 `dst[1]`……顺序打乱 → 图像严重扭曲。

**目标尺寸的宽高比**：如果输出尺寸的宽高比与原始平面物体的真实宽高比不一致，输出会被拉伸或压缩。A4 纸推荐 1:√2 ≈ 1:1.414。

**插值方式**：默认线性插值。文本扫描场景可选 `INTER_CUBIC` 获得更平滑的字形。

## 角点重排序算法

在文档扫描项目中，轮廓检测返回的四个角点顺序是**任意的**（取决于 `findContours` 的扫描方向）。使用前必须重排序为 [左上, 右上, 左下, 右下]：

```
输入：任意顺序的四个角点
1. 按 x+y 排序：和最小 = 左上(0)，和最大 = 右下(3)
2. 剩余两点按 x-y（或 y-x）排序：
   差最小 = 右上(1)，差最大 = 左下(2)
```

直觉解释：
- 左上角的 `x+y` 是四个角中最小的
- 右下角的 `x+y` 是四个角中最大的
- 右上角偏右偏上 → `x-y` 最大
- 左下角偏左偏下 → `x-y` 最小

## 单应性的更多应用

- **图像拼接**（Image Stitching）：对齐两幅重叠图像
- **增强现实**（AR）：在检测到的平面上投影虚拟物体
- **鸟瞰图变换**（Bird's Eye View）：自动驾驶中将前视图像变俯视图，用于车道线检测
- **相机标定**：棋盘格平面与图像平面之间的单应性是张正友标定法的基础
