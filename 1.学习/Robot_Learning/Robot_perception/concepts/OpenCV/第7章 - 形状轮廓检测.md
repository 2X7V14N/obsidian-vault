# 第7章 - 形状/轮廓检测

轮廓检测是 OpenCV 中最常用的操作之一——从二值图像中提取物体的边界，然后做几何分析和形状识别。它是预处理管道（灰度化 → 模糊 → Canny → 形态学）的最终消费者，也是许多高级应用（目标检测、文档扫描、手势识别）的起点。

本章分两个部分：**第一部分**讲轮廓的几何分析（面积、周长、形状分类），**第二部分**讲轮廓间的拓扑关系（Hierarchy：谁包裹谁、谁是孔洞）。

---

# 第一部分：轮廓检测与几何分析

## 预处理管道回顾

轮廓检测的输入必须是**二值图**（黑白分明）。标准做法是跑完整条预处理管道：

```
原始图像 → 灰度化 → 高斯模糊 → Canny → 膨胀（闭合边缘）→ findContours
```

```cpp
Mat imgGray, imgBlur, imgCanny, imgDilate;
cvtColor(image, imgGray, COLOR_BGR2GRAY);
GaussianBlur(imgGray, imgBlur, Size(7, 7), 5, 0);
Canny(imgBlur, imgCanny, 50, 150);

Mat kernel = getStructuringElement(MORPH_RECT, Size(5, 5));
dilate(imgCanny, imgDilate, kernel);
```

> ⚠️ **关键坑**：`findContours` 会**修改输入图像**。如果后续还需要原始二值图，传入 `binary.clone()`。

## findContours

```cpp
vector<vector<Point>> contours;      // 每个轮廓是一组点
vector<Vec4i> hierarchy;             // 轮廓间的父子关系（详见第二部分）

findContours(
    imgDilate,                       // 二值输入
    contours,
    hierarchy,
    RETR_EXTERNAL,                   // 检索模式
    CHAIN_APPROX_SIMPLE              // 压缩方式
);
```

**检索模式**：

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| `RETR_EXTERNAL` | 只取最外层轮廓 | 形状检测、目标计数、忽略内部纹理 |
| `RETR_LIST` | 所有轮廓，不建立层级 | 简单计数 |
| `RETR_CCOMP` | 两层结构（外层+孔洞） | 工业缺陷检测（判断有无打孔） |
| `RETR_TREE` | 完整父子树 | 需要分析嵌套关系时 |

不关心层级关系时，用 `RETR_EXTERNAL` 就够了——速度快，输出干净。

**压缩方式**：`CHAIN_APPROX_SIMPLE` 压缩水平/垂直/对角线线段，只保留端点。显著减少内存，对后续分析无影响。

## 轮廓的特征

提取轮廓后，可以计算各种几何特征：

### 面积与周长

```cpp
double area = contourArea(contour);
double peri = arcLength(contour, true);   // true = 闭合曲线
```

面积过滤是最常用的去噪手段——`if (contourArea(contours[i]) > 1000)` 筛掉小噪声。

### 边界框

```cpp
Rect boundRect = boundingRect(contour);
// boundRect.x, .y, .width, .height
```

边界框是"正立的矩形"，始终与坐标轴平行。适合目标粗定位和 ROI 裁剪。

### 最小外接矩形

```cpp
RotatedRect minRect = minAreaRect(contour);
```

可以旋转——给出任意角度下面积最小的包围矩形。适合检测倾斜物体。

### 凸包

```cpp
vector<Point> hull;
convexHull(contour, hull);
```

包含轮廓所有点的最小凸多边形。用于手势识别（分析凸缺陷判断手指数）。

## 多边形近似与形状识别

### approxPolyDP

```cpp
vector<Point> approx;
double peri = arcLength(contour, true);
approxPolyDP(contour, approx, 0.02 * peri, true);
```

Douglas-Peucker 算法：用最少的点近似轮廓，保证误差不超过 ε（第三个参数）。

**ε 的选择**：`0.02 * peri` 是经验值（允许误差不超过周长的 2%）。ε 太大 → 正方形被近似为三角形；ε 太小 → 保留太多噪点。

### 形状分类

```cpp
int corners = approx.size();

if (corners == 3)       { /* 三角形 */ }
else if (corners == 4)  {
    float aspRatio = (float)boundRect.width / (float)boundRect.height;
    if (aspRatio > 0.95 && aspRatio < 1.05)  { /* 正方形 */ }
    else                                     { /* 矩形 */ }
}
else if (corners > 4)   { /* 圆形或椭圆 */ }
```

### 圆度——更精确的圆形判断

`corners > 4` 太粗糙，用**圆度**（circularity）更鲁棒：

```cpp
double circularity = 4.0 * CV_PI * area / (perimeter * perimeter);
// 完美圆 ≈ 1.0，正方形约 0.79，偏离越多越不圆
```

# 第二部分：轮廓层级拓扑（Hierarchy）

## 为什么需要 Hierarchy

`findContours` 返回两个东西：`contours`（点集）和 `hierarchy`（轮廓间的关系）。如果你只拿到一堆轮廓却不知道谁包裹谁、谁是谁的孔洞——你拿到的是"一堆点"，而不是"一个有结构的场景"。

## Vec4i 数据结构

每条轮廓的层级信息存储在一个 `Vec4i`（4 个 int）中：

```cpp
hierarchy[i] = { Next, Previous, First_Child, Parent };
```

| 索引 | 字段 | 含义 |
|------|------|------|
| `[0]` | **Next** | 同层级下一个轮廓（下一个兄弟） |
| `[1]` | **Previous** | 同层级上一个轮廓（上一个兄弟） |
| `[2]` | **First_Child** | 直接包含的第一个子轮廓 |
| `[3]` | **Parent** | 外层父轮廓 |

不存在的关系统一用 **-1** 表示。

## 三种基本判断

```cpp
bool isOuter  = (hierarchy[i][3] == -1);   // 最外层轮廓
bool hasChild = (hierarchy[i][2] != -1);   // 内部有孔或子物体
bool isHole   = (hierarchy[i][3] != -1);   // 被其他轮廓包裹
```

这三个判断覆盖了工程中 90% 的 hierarchy 使用场景。

## 遍历子轮廓

同一父轮廓下的所有子轮廓通过 `Next` / `Previous` 形成双向链表：

```cpp
int child = hierarchy[parentId][2];       // 第一个孩子
while (child != -1) {
    // 处理 child...
    child = hierarchy[child][0];          // 下一个兄弟
}
```

## 实战：基于 Hierarchy 的典型任务

### 未打孔缺陷检测

```cpp
bool isOuter = hierarchy[i][3] == -1;
bool hasHole = hierarchy[i][2] != -1;

if (isOuter && !hasHole) { /* 缺陷件 */ }
if (isOuter && hasHole)  { /* 合格件 */ }
```

> 必须用 `RETR_TREE` 或 `RETR_CCOMP`，`RETR_EXTERNAL` 拿不到孔洞。

### 二维码定位

二维码角点的定位图案是三层嵌套（黑→白→黑）：

```cpp
int child   = hierarchy[i][2];
int grandson = (child != -1) ? hierarchy[child][2] : -1;
if (grandson != -1) { /* 可能是定位图案 */ }
```

### 字符孔洞统计

区分 `O`（1孔）和 `C`（0孔）、`8`（2孔）——遍历兄弟链表统计子轮廓数量。

## 总结：三层模型

```
第一层 像素 → 几何（contours）：把二值图转为点集，得到面积、周长
第二层 几何 → 拓扑（hierarchy）：用 Vec4i 描述包含关系
第三层 拓扑 → 业务判断：结合几何+拓扑，做质检/定位/分类
```

掌握 Hierarchy 后，轮廓检测不再只是"画框"，而是能回答具体业务问题。

## 常见陷阱

| 陷阱 | 后果 | 修复 |
|------|------|------|
| `RETR_EXTERNAL` 但需要孔洞 | 孔洞轮廓完全丢失 | 改为 `RETR_TREE` |
| 未传 `.clone()` | 原二值图被修改 | `findContours(binary.clone(), ...)` |
| 不检查 `hierarchy.empty()` | 数组越界 crash | `if (!hierarchy.empty())` |
| 单一特征判断 | 误判率高 | 组合面积+圆度+宽高比+层级 |
