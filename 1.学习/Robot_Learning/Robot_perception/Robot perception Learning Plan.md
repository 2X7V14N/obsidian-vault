### 与旧版的变化

| 变化 | 说明 |
|------|------|
| DL 从第 6 步提到第 3 步 | 深度学习是感知核心，要早学 |
| ROS2 拆成 3.5（浅尝）+ 7（补齐） | 先跑通节点建立体感，不深挖；后面再补 tf2/launch |
| 新增第 5 步：学习式抓取检测 | GG-CNN、Contact-GraspNet——拉开差距的关键项目 |
| 坐标系/手眼标定后移到第 6 步 | 先有 DL+3D 基础再学更有落点 |
| 新增第 8 步：总集成 | 把所有模块串成能演示的完整系统，是简历核心项目 |
| SLAM 降到第 9 步选学 | 抓取/操作感知非核心，时间够再碰 |
